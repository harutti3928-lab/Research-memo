自己エネルギーとGreen関数の自己無撞着計算

— Dyson方程式と松原周波数形式 —

松原（Matsubara）周波数形式

有限温度の Green 関数は、虚数時間 τ ∈ [0, β] 上の関数として定義し、フーリエ変換で松原周波数表示に移る：

フェルミオン（電子）：  iωₙ = iπ(2n+1)/β
ボソン（感受率など）：  iΩₘ = i2πm/β

β = 1/(k_B T)

Green 関数 G(k, τ) は以下のフーリエ変換で周波数表示 G(k, iωₙ) と対応する：

G(k, iωₙ) = ∫₀^β dτ e^{iωₙτ} G(k, τ)

非相互作用 Green 関数

ハバードモデルの非相互作用（U=0）Green 関数は解析的に書ける：

G₀(k, iωₙ) = 1 / (iωₙ - ξ_k)

ξ_k = ε_k - μ   （ε_k: バンド分散、μ: 化学ポテンシャル）

正方格子最近接ホッピングの場合：ε_k = -2t(cos kₓ + cos kᵧ)

Dyson 方程式

相互作用を入れた完全 Green 関数と自己エネルギー Σ(k, iωₙ) は Dyson 方程式で結ばれる：

G⁻¹(k, iωₙ) = G₀⁻¹(k, iωₙ) - Σ(k, iωₙ)
             = iωₙ - ξ_k - Σ(k, iωₙ)

∴ G(k, iωₙ) = 1 / [iωₙ - ξ_k - Σ(k, iωₙ)]

FLEX における自己エネルギー

自己エネルギーの式

FLEX 近似での自己エネルギーは、有効相互作用 V_eff を通じたフォック（Fock）型の積分で与えられる：

Σ(k, iωₙ) = T/N Σ_{q,m} V_eff(q, iΩₘ) G(k-q, iωₙ - iΩₘ)

ここで T は温度、N は k 点数。実際には k 空間での畳み込みをFFTで実行する。

有効相互作用の定義

V_eff(q, iΩₘ) = (3/2) U² χ_spin(q, iΩₘ)
              + (1/2) U² χ_charge(q, iΩₘ)
              - U² χ₀(q, iΩₘ)

χ_spin   = χ₀ / (1 - U χ₀)      ← スピン RPA
χ_charge = χ₀ / (1 + U χ₀)      ← 電荷 RPA

化学ポテンシャルの自己無撞着更新

各イテレーションで電子数 n を固定するため、μ を以下の条件を満たすよう調整する：

n = 2 T/N Σ_{k,n} G(k, iωₙ) e^{iωₙ 0⁺}
  = 1 - (2/N) Σ_k [T Σ_n G(k, iωₙ) e^{-iωₙ 0⁻}]

実装上は二分法または Newton 法で μ を更新する。

スペクトル関数と解析接続

実験と比較できるスペクトル関数 A(k, ω) を得るには、松原 Green 関数を実周波数に解析接続する必要がある：

A(k, ω) = -1/π Im G(k, ω + iδ)

G(k, iωₙ) → G(k, ω + iδ)  ← 解析接続

数値的には Padé 近似や最大エントロピー法（MaxEnt）が使われる。

自己無撞着計算では G と Σ を同時に更新するため、各イテレーションごとに感受率→有効相互作用→自己エネルギー→Dyson 方程式の順に計算する。収束判定は Σ(k, iωₙ) の差分ノルムで行うことが多い。
