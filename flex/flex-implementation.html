FFT による畳み込み

感受率の計算

Green 関数の積は k 空間で直接やると O(Nk⁴ × Nω²) になるが、FFT を使うと O(Nk² Nω log(Nk² Nω)) まで削減できる。

# Python/NumPy での実装イメージ
import numpy as np

# G(k, iωₙ) の形状: [Nk, Nk, Nω]
# τ 方向の逆 FFT で G(k, τ) を得る
G_tau = np.fft.ifft(G_iw, axis=-1).real * beta

# r 空間への FFT
G_r_tau = np.fft.ifft2(G_tau, axes=(0,1))

# χ₀(r, τ) = -G(r, τ) * G(-r, β-τ)
chi0_r_tau = -G_r_tau * np.flip(G_r_tau, axis=(0,1,2))

# q 空間・ボソン周波数への FFT
chi0_q_iOm = np.fft.fft2(chi0_r_tau, axes=(0,1))
chi0_q_iOm = np.fft.fft(chi0_q_iOm, axis=-1)

高周波成分の扱い

松原周波数の大きい成分で G(iωₙ) ≈ 1/(iωₙ) となる漸近挙動を陽に引き出すことで、数値収束を改善できる：

G(k, iωₙ) = G_asymp(k, iωₙ) + δG(k, iωₙ)

G_asymp = 1/(iωₙ - ξ_k)  ← 解析的に計算
δG     = G - G_asymp     ← 高周波で急速減衰 → FFT に適する

Padé 解析接続

松原周波数上の G(iωₙ) から実周波数上の G(ω + iδ) を求める。Padé 近似は低コストだが、ノイズに敏感。

# Padé 係数の計算（Vidberg-Serene アルゴリズム）
def pade_coefficients(z, f):
    # z = iωₙ の配列, f = G(iωₙ)
    N = len(z)
    a = np.zeros(N, dtype=complex)
    a[0] = f[0]
    g = f.copy()
    for i in range(1, N):
        g_new = np.zeros(N-i, dtype=complex)
        for j in range(N-i):
            g_new[j] = (g[j] - g[i]) / ((z[i+j] - z[j]) * g[i])
        g = g_new
        a[i] = g[0]
    return a
Padé は低温（大きい β）で Nω が多いとき精度が出やすい。高温・ノイズが多い場合は最大エントロピー法（MaxEnt）を使う。精度の確認は虚数軸上の G との一致をチェック。

収束判定と混合

収束判定の指標

err_G = max |G_new(k, iωₙ) - G_old(k, iωₙ)|
err_Σ = max |Σ_new(k, iωₙ) - Σ_old(k, iωₙ)|

通常 err_Σ < 1E-5 (eV 単位) を収束の目安とする

線形混合（damping）

振動を防ぐため、新旧 Green 関数を混合してから次のステップに進む：

G_mix = α G_new + (1-α) G_old    # α = 0.2 〜 0.5

数値的注意点

  • 電子数 n の保存：各イテレーションごとに μ を二分法で調整する。
  • Stoner 条件の監視：U * max(χ₀) が 1 に近いと感受率が発散するため、収束前に確認する。
  • τ = 0 / τ = β での G の符号：フェルミオンの反周期性 G(τ+β) = -G(τ) を FFT で正しく扱う。
  • ボソン周波数の和：感受率の松原周波数の数は Green 関数の 2 倍必要（Ωₘ = ωₙ - ωₙ' のレンジ）。
  • メモリ使用量：Nk=64, Nω=1024 の場合、G の配列は約 64×64×1024×16 byte ≈ 67 MB。
