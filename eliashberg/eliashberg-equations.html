Eliashberg方程式の導出と構造

— Matsubara 形式・Σ(iωₙ) と Δ(iωₙ) —

Nambu-Gor'kov 形式

超伝導状態を Green 関数で扱うため、Nambu スピノル表示を使う：

Ψ_k = (c_{k↑}, c†_{-k↓})^T

Nambu Green 関数：
G(k, iωₙ) = -⟨T_τ Ψ_k(τ) Ψ†_k(0)⟩

行列表示：
G = ( G_↑↑    F   )
    ( F†    -G_↓↓ )

G : 通常の Green 関数
F : 異常 Green 関数（ペアリング振幅）

Eliashberg 方程式（Matsubara 形式）

Migdal の定理のもと、電子–フォノン自己エネルギーを自己無撞着に計算すると以下の2本の方程式が得られる：

質量繰り込み関数 Z(iωₙ)

Z(iωₙ) ωₙ = ωₙ + πT Σ_{n'} λ(iωₙ - iωₙ') × ωₙ' / √(ωₙ'² + Δ²(iωₙ'))

λ(iΩ_m) = 2 ∫₀^∞ dω α²F(ω) ω / (Ω_m² + ω²)

超伝導ギャップ関数 Δ(iωₙ)

Z(iωₙ) Δ(iωₙ) = πT Σ_{n'} [λ(iωₙ - iωₙ') - μ*(ωc)] × Δ(iωₙ') / √(ωₙ'² + Δ²(iωₙ'))

μ* : クーロン擬ポテンシャル（通常 0.1–0.15）
ωc : クーロン遮断周波数

方程式の構造のまとめ

入力:  α²F(ω), μ*, T
未知量: Z(iωₙ), Δ(iωₙ)
出力:  Tc（Δ → 0 になる温度）
       Δ(0)（T=0 でのギャップ）

物理的意味

Z(iωₙ) の役割

質量繰り込み関数は準粒子の有効質量の増大を記述する。実軸上では Z(ω) ≈ m*/m に対応し、λ が大きいほど Z が大きくなる（Z ≈ 1 + λ）。

Δ(iωₙ) の周波数依存性

BCS では Δ が定数だが、Eliashberg では虚数周波数の関数になる。高周波（|ωₙ| ≫ ω_D）では Δ(iωₙ) → 0 に減衰する。

自己無撞着計算の手順

初期値: Δ(iωₙ) = Δ₀（定数）, Z = 1

ループ:
  1. λ(iΩ_m) を α²F(ω) から計算
  2. 繰り込み式から Z(iωₙ) を更新
  3. ギャップ方程式から Δ(iωₙ) を更新
  4. |Δ_new - Δ_old| < ε → 収束
     → NO → 1 に戻る

Tc の探索:
  温度 T を変えながら繰り返し、Δ(iω₀) → 0 となる T = Tc を探す
松原周波数の打ち切り数 N_c は ω_c ≈ N_c × πT が デバイ周波数 ω_D の 5–10 倍程度になるよう設定する。実用的には N_c = 100–500 程度。
