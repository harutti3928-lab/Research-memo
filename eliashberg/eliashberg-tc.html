Tc の見積もり

— McMillan 式・Allen-Dynes 式と μ* —

McMillan 式（1968）

Eliashberg 方程式を近似的に解いて得られる解析式：

Tc = (ω_D / 1.45) exp[ -1.04(1 + λ) / (λ - μ*(1 + 0.62λ)) ]

ω_D : デバイ周波数（K 単位）
λ   : 電子–フォノン結合定数
μ*  : クーロン擬ポテンシャル（0.1–0.15 が典型値）

λ ≲ 1.5 の範囲で比較的正確だが、強結合（λ > 1.5）では過小評価する。また ω_D の代わりに対数平均 ω_log を使う変形版もある。

Allen-Dynes 式（1975）

McMillan 式を強結合に拡張した、より精度の高い表式：

Tc = (f₁ f₂ ω_log / 1.20) exp[ -1.04(1 + λ) / (λ - μ*(1 + 0.62λ)) ]

強結合補正因子：
  f₁ = [1 + (λ/Λ₁)^(3/2)]^(1/3)
  f₂ = 1 + (ω₂/ω_log - 1) × λ² / (λ² + Λ₂²)

  Λ₁ = 2.46(1 + 3.8μ*)
  Λ₂ = 1.82(1 + 6.3μ*)(ω₂/ω_log)

  ω₂ = √[ 2 ∫₀^∞ dω α²F(ω) ω ]  ← 二乗平均フォノン周波数

f₁、f₂ は λ → 0 で 1 に近づき、McMillan 式に帰着する。強結合ではこれらが Tc を引き上げる補正として機能する。

クーロン擬ポテンシャル μ*

物理的意味

電子間のクーロン斥力は超伝導ペアリングを抑制する。しかしフォノンの時間スケール（ω_D⁻¹）と電子のそれ（E_F⁻¹）の違いにより、実効的な斥力（μ*）は裸のクーロン定数 μ より小さくなる：

μ* = μ / [1 + μ ln(E_F / ω_D)]

典型的な値：
  金属    : μ* ≈ 0.10–0.15
  高圧水素: μ* ≈ 0.10–0.13（理論的にはやや不定）

μ* の扱い方

μ* は cRPA（constrained RPA）で原理的に計算できるが、実用的には文献の典型値（0.10–0.15）を使うことが多い。μ* の不定性が Tc の見積もりに ±数 K の誤差をもたらすことに注意。

各手法の比較

手法精度計算コスト適用範囲
McMillan 式低〜中（λ ≲ 1.5）非常に低い弱〜中結合
Allen-Dynes 式中〜高低い弱〜強結合
Eliashberg 方程式（数値解）高中程度全結合域
ab initio SCDFT最高（μ* 不要）高い汎用（研究段階）

数値 Eliashberg 計算での Tc の求め方

方法1: 温度スキャン
  T = T_high から下げていき、Δ(iω₀) が有限になる温度 Tc を探す

方法2: 線形化方程式の固有値問題
  T = Tc で Eliashberg 方程式を線形化すると固有値問題になる：
  Δ(iωₙ) = Σ_{n'} K(n, n') Δ(iωₙ')

  最大固有値 = 1 となる T が Tc

方法2 の方が計算効率が高く、Tc 近傍での不安定性を直接調べられる
Allen-Dynes 式は λ・ω_log・μ* の3つのパラメータだけから Tc を素早く見積もれるため、第一原理計算のスクリーニングに最適。詳細な超伝導特性（ギャップの温度依存性、準粒子寿命など）が必要な場合に数値 Eliashberg 計算を行う。
