Eliashberg関数 α²F(ω) と λ の計算

— フォノン DOS から第一原理で計算する —

Eliashberg 関数の定義

α²F(ω) はフォノン状態密度 F(ω) と電子–フォノン結合の行列要素 g を組み合わせた量である：

α²F(ω) = (1/N_F) Σ_{k,k',ν} |g_{k,k'}^ν|² δ(ε_k) δ(ε_{k'}) δ(ω - ω_{k'-k,ν})

N_F   : フェルミ面の状態密度
g     : 電子–フォノン結合行列要素
ω_{qν}: 波数 q、モード ν のフォノン周波数

F(ω) だけではなく、電子のフェルミ面での結合強度 α² によって重み付けされているため、Tc に寄与するフォノンモードを直接反映する。

電子–フォノン結合定数 λ

α²F(ω) の第一モーメントとして定義される：

λ = 2 ∫₀^∞ dω α²F(ω) / ω

λ < 0.3  : 弱結合（BCS が適用可能）
λ ~ 1    : 中程度（Eliashberg が重要）
λ > 1.5  : 強結合（例：Pb: λ ≈ 1.5, H₃S: λ ≈ 2.2）

λ は Tc の大きさと直接対応する。λ が大きいほど Tc も高くなる傾向がある。

対数平均フォノン周波数 ω_log

McMillan / Allen-Dynes 式で使う代表的なフォノン周波数：

ω_log = exp[ (2/λ) ∫₀^∞ dω (α²F(ω)/ω) ln(ω) ]

第一原理計算による α²F(ω) の計算

VASP + DFPT の手順

1. 構造最適化
2. フォノン計算（IBRION = 6, NFREE = 4 などで変位法）
   または DFPT（IBRION = 8）
3. PHON または phonopy でフォノン分散・F(ω) を計算
4. 電子–フォノン行列要素の計算
   → vaspkit や EPW（Quantum ESPRESSO）で処理

Quantum ESPRESSO (EPW) の手順

1. pw.x : 自己無撞着計算（SCF）
2. ph.x : フォノン計算（DFPT）
3. q2r.x : 実空間フォノン力定数
4. matdyn.x : フォノン分散
5. epw.x : 電子–フォノン Wannier 補間 → α²F(ω) の出力

MgB₂ は λ が小さいが ω_log が高いため Tc が高い。H₃S は λ・ω_log 双方が大きい。

α²F(ω) は VESTA などで可視化するよりも、各フォノンモードがどの程度 Tc に寄与しているかを確認するため、モード分解した α²F を確認すると物理的洞察が得られる。例えば MgB₂ では B の面内振動モードが支配的に寄与する。
