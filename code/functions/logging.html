Logging — ログ整形と分数座標の表示

— バナー/見出し/key-value のログ整形と、k-path・q 点ラベル用の分数フォーマット  |  関数名をクリックで詳細 —

バッチ実行のログ出力を読みやすくするための、依存なし・軽量の整形ヘルパ群。水平線・バナー・ セクション見出し・key/value の桁揃え出力に加え、k-path や q 点ラベルで使う 分数座標の整形（整数演算での約分）を提供する。長時間まわるソルバの標準出力を ==== TITLE ==== や key : value のような一定の体裁に揃え、 軸ラベルには 0・1/4・-3/8 のような約分済み分数を出せるようにするのが役割。

このページの規約：外部依存なし（すべて println ベースで実装）、水平線／バナーの 既定幅は 78 桁、分数は gcd を使った整数演算で約分し、分母を正に正規化する （符号は必ず分子側へ寄せる）。この 3 点が全関数で共通の前提。

logging.jlJulia

ログ整形の 4 関数と、分数座標整形の 3 関数をまとめた小さなユーティリティ。using 文を一切持たない＝標準機能だけで動く。

logging.jl — 冒頭
# logging.jl
# バッチ出力を読みやすくするためのログ整形ヘルパー（依存なし・軽量）。

このファイルには using / import が無い点に注目。println・strip・ rpad・repeat・gcd・div といった Base の関数だけで完結しているので、 どのスクリプトからでも副作用なく読み込める。話題は大きく 2 つ——前半 4 つ（log_hr / log_banner / log_section / log_kv）がログの体裁づくり、 後半 3 つ（_reduce_fraction / _frac_str / format_grid_fraction）が 分数座標の整形で二分される。

log_hr▶ 水平線を 1 本引く — ch を n 個並べて println
log_hr(; ch::Char='-', n::Int=78) → nothing（標準出力に区切り線）

概要

指定した文字 ch を n 個つなげた 水平線を 1 行出力する、いちばん素朴なヘルパ。 既定は - を 78 個、つまり ------------------------------------------------------------------------------。 セクションの区切りや、後述 log_banner の空タイトル時のフォールバックとして使う。

コード

logging.jl · log_hr
"""水平線を引く。"""
function log_hr(; ch::Char='-', n::Int=78)
    println(repeat(string(ch), n))
    return nothing
end

読み方

  • 引数はすべてキーワード引数（; の後ろ）。位置引数を取らないので、呼ぶときは log_hr() か log_hr(ch='=', n=40) のように名前で渡す。
  • ch::Char='-' — 線に使う1 文字。既定はハイフン。Char なので '=' のようにシングルクォートで渡す（文字列 "=" ではない）。
  • n::Int=78 — 並べる個数。既定幅 78 桁という共通規約がここに現れる。
  • repeat(string(ch), n) — Char を string で 1 文字の文字列にしてから n 回繰り返す。結果を println でそのまま 1 行出力。
  • return nothing — 戻り値は使わない（副作用＝標準出力が目的）。以降のヘルパも同じ流儀。
使いどころ： 単独の区切り線としてはもちろん、log_banner にタイトルが渡されなかったときに log_hr(ch=ch) として内部で呼ばれる。ch を '=' にすれば太めの線、'-' なら細めの線と、太さを 1 文字で切り替えられる。
関連：log_banner（空タイトル時に log_hr へフォールバック）／ log_section
log_banner▶ ==== TITLE ==== 形のバナー行を 78 桁まで埋めて出力
log_banner(title::AbstractString; ch::Char='=') → nothing（==== TITLE ====…）

概要

タイトルを中央寄り（左寄せ）に置いた バナー行を出力する。左側は ch を 2 個＋空白＋ title＋空白、そして残りを 78 桁になるまで ch で右側を埋める。たとえば log_banner("run start") は == run start ============================================================== のような 1 行を出す。title が空（または空白のみ）なら log_hr にフォールバックして、ただの水平線になる。

コード

logging.jl · log_banner
"""'==== TITLE ====' のようなバナー行を出力する。"""
function log_banner(title::AbstractString; ch::Char='=')
    s = strip(title)
    if isempty(s)
        log_hr(ch=ch)
        return nothing
    end
    pad = 2
    inner = "$(repeat(string(ch), pad)) $(s) $(repeat(string(ch), pad))"
    nfill = max(0, 78 - lastindex(inner))
    println(inner * repeat(string(ch), nfill))
    return nothing
end

読み方

  • s = strip(title) — 前後の空白をトリム。以降はこの s を本文として扱う。
  • if isempty(s) … log_hr(ch=ch) — トリム後に中身が無ければ水平線へフォールバック。同じ ch を渡すので線の文字は揃う。ここで return して以降は実行しない。
  • pad = 2 — タイトルの左右に置く ch の個数（＝先頭の ==== でいう「2 個ぶん」）。
  • inner = "$(ch×2) $(s) $(ch×2)" — 中央部分を組み立てる。ch を 2 個＋空白＋タイトル＋空白＋ch を 2 個。ch='='・s="run start" なら == run start ==。
  • nfill = max(0, 78 - lastindex(inner)) — 78 桁に届かせるための残り個数。lastindex(inner) は inner の長さ相当。max(0, …) で、inner が既に 78 桁を超えていても負の繰り返し数にならないよう 0 で下限を切る。
  • println(inner * repeat(string(ch), nfill)) — 中央部分の右側だけを ch で埋めて 78 桁の帯にし、1 行出力。左は == title ==、右が伸びる非対称なバナーになる。
注意： 78 桁ちょうどになるとは限らない。title が長くて inner が 78 桁を超えると nfill=0 となり、埋め文字は付かず inner がそのまま出る（78 桁を超えた行になる）。あくまで「最低でも 78 桁まで右を埋める」挙動で、上限を切り詰めはしない。
関連：log_hr（空タイトル時のフォールバック先）／ log_section（軽い見出し版）
log_section▶ --- title --- のセクション見出しを（前に空行を入れて）出力
log_section(title::AbstractString) → nothing（\n--- title ---）

概要

log_banner より軽い セクション見出し。タイトルを --- で挟み、直前に空行を 1 つ入れて --- title --- の形で出力する。たとえば log_section("diagonalize") は空行のあと --- diagonalize --- を出す。ログの中で処理段階を区切るのに使う、桁揃えなしの手軽な見出し。

コード

logging.jl · log_section
"""'--- title ---' のようなセクション見出しを出力する。"""
function log_section(title::AbstractString)
    println("\n--- $(strip(title)) ---")
    return nothing
end

読み方

  • "\n--- … ---" — 先頭の \n で1 行ぶんの空行を作ってから見出しを出す。前の出力とのあいだに余白ができ、目で段落が追いやすくなる。
  • strip(title) — ここでも前後の空白をトリムしてから --- で挟む。余分な空白で --- title --- の体裁が崩れないようにする。
  • log_banner と違い 78 桁埋めはしない。--- はタイトルの長さちょうどに寄り添う、軽量な見出し。
使い分け： 大きな節の頭には log_banner（78 桁の帯）、その中の小段落には log_section（--- … ---）と、見出しの階層を 2 段で表現できる。
関連：log_banner（上位の見出し）／ log_hr／ log_kv（見出しの下に並べる key/value）
log_kv▶ key を key_width で桁揃えして key : value を出力
log_kv(key::AbstractString, value; key_width::Int=20) → nothing（ key : value）

概要

キーと値のペアを桁揃えして出力する。キーを key_width（既定 20）で右側を空白パディングし、 key : value のように : の位置を揃える。設定値やパラメータの一覧を 縦に並べたときに、値の開始列がそろって読みやすくなる。value は型を問わない（数値でも文字列でも可）。

コード

logging.jl · log_kv
"""key : value を桁揃えして出力する。"""
function log_kv(key::AbstractString, value; key_width::Int=20)
    k = rpad(String(key), key_width)
    println("  $(k) : $(value)")
    return nothing
end

読み方

  • value に型注釈が無い点に注目。Int でも Float64 でも文字列でも受け取り、$(value) の文字列補間でそのまま表示する。
  • k = rpad(String(key), key_width) — キーを key_width 桁まで右側に空白を足して揃える（rpad = 右パディング）。String(key) で AbstractString を素の String に確定させてから渡す。
  • キーが key_width より長ければ rpad は切り詰めずそのまま返すので、その行だけ : の位置がずれる（あくまで最小幅の指定）。
  • println(" $(k) : $(value)") — 先頭 2 スペースでインデントし、桁揃え済みキー＋ : ＋値。log_kv("kmesh", 8) なら kmesh : 8 のような 1 行になる。
関連：log_section（この key/value 群の見出し）／ log_banner
ここから下は話題が変わる。上の 4 つがログの体裁づくりだったのに対し、以下の 3 つ （_reduce_fraction / _frac_str / format_grid_fraction）は 分数座標の整形を担う。k-path や q 点のラベルを 0・1/4・-3/8 のような 約分済み分数で表示するための下請けと、その入口の関数だ。
_reduce_fraction▶ num/den を整数演算で約分し、分母を正に正規化（下請け）
_reduce_fraction(num::Int, den::Int) → (num', den')（既約・分母正）

概要

整数の分子・分母 num/den を、整数演算だけで約分する下請け関数（名前の先頭 _ は 「内部用」の目印）。分母が 0 ならエラー、分母が負なら符号を分子へ移して分母を正に正規化し、 最後に gcd（最大公約数）で割って既約分数にする。-2/-8 なら (1, 4) を、 3/-8 なら (-3, 8) を返す。浮動小数点を使わないので丸め誤差が入らないのが要点。

コード

logging.jl · _reduce_fraction
"""num/den を整数演算で約分する。"""
function _reduce_fraction(num::Int, den::Int)
    den == 0 && throw(ArgumentError("den must be nonzero"))
    if den < 0
        num = -num
        den = -den
    end
    g = gcd(abs(num), abs(den))
    return div(num, g), div(den, g)
end

読み方

  • den == 0 && throw(ArgumentError(...)) — 短絡評価によるガード。den が 0 のときだけ右辺の throw が走り、0 除算を未然に弾く。if を書かずに 1 行で前提条件を表す Julia のイディオム。
  • if den < 0 … num=-num; den=-den — 分母が負なら符号を分子側へ移す。これで戻り値の分母は常に正になり、符号は必ず分子が持つ（共通規約の「分母を正に正規化」）。
  • g = gcd(abs(num), abs(den)) — 分子・分母の絶対値の最大公約数。gcd に絶対値を渡して、公約数そのものは正の値として得る。
  • div(num, g), div(den, g) — div は整数除算。g は両者の公約数なので必ず割り切れ、既約な (num', den') をタプルで返す。num の符号は保たれる。
  • 例：_reduce_fraction(-2, -8) → 分母正規化で (2, 8) → gcd=2 → (1, 4)。_reduce_fraction(0, 5) → gcd(0,5)=5 → (0, 1)。
つまずきポイント： 入力は Int 限定。浮動小数点の座標（例 0.25）をそのまま渡すことはできず、あくまで「分子・分母がすでに整数で分かっている」格子座標に使う。den=0 は即エラーなので、呼び出し側は分母（＝格子分割数 N など）が 0 でないことを保証しておく。
関連：_frac_str（この結果を文字列化）／ format_grid_fraction（最終的な入口）
_frac_str▶ 約分した分数を文字列に — 分母 1 なら整数だけ、他は n/d
_frac_str(num::Int, den::Int) → String（例 "0"・"1/4"・"-3/8"）

概要

_reduce_fraction で約分してから、その結果を文字列に整形する下請け。分母が 1 なら分子だけ （整数に見せる）、そうでなければ n/d の形で返す。_frac_str(2, 8) → "1/4"、 _frac_str(0, 5) → "0"、_frac_str(-3, 8) → "-3/8"。 軸ラベルに載せられる、人が読める分数表現がここで完成する。

コード

logging.jl · _frac_str
"""約分した分数を文字列にする。例: '0', '1/4', '-3/8'。"""
function _frac_str(num::Int, den::Int)
    n, d = _reduce_fraction(num, den)
    return d == 1 ? string(n) : string(n, "/", d)
end

読み方

  • n, d = _reduce_fraction(num, den) — まず約分。以降は既約・分母正の (n, d) を扱う。約分の責務は下請けに委ね、この関数は「見せ方」だけに集中する。
  • d == 1 ? string(n) : string(n, "/", d) — 三項演算。分母が 1 なら string(n) で整数だけ（"3/1" ではなく "3"）。そうでなければ string(n, "/", d) で n/d。
  • 分母正規化のおかげでマイナス記号は必ず先頭の分子に付く。だから "3/-8" のような表記は生まれず、"-3/8" に揃う。
  • string(n, "/", d) は複数引数を連結する書き方（"$(n)/$(d)" と同義）。区切り文字 / を挟んで分子・分母を並べる。
ゼロの扱い： _frac_str(0, N) は約分で (0, 1) になり、分母 1 の分岐に入って "0" を返す。"0/1" や "0/N" にならないので、原点ラベルがすっきり 0 と表示される。
関連：_reduce_fraction（前段の約分）／ format_grid_fraction（この関数を呼ぶ入口）
format_grid_fraction▶ 格子インデックス i (1..N) を分数座標 (i-1)/N に整形（公開入口）
format_grid_fraction(i::Int, N::Int) → String（i=1→"0", i=2,N=4→"1/4"）

概要

1 始まりの格子インデックス i（1..N）を、分数座標 (i-1)/N の文字列に整形する 公開の入口関数。N=4 なら i=1,2,3,4 がそれぞれ "0"・"1/4"・ "1/2"・"3/4" になる。範囲外の i は ArgumentError で弾く。 q 点や k-path の高対称点ラベルを、割り切れる分数できれいに表示するために使う。

コード

logging.jl · format_grid_fraction
"""格子インデックス i (1..N) を分数座標 (i-1)/N に整形する。"""
function format_grid_fraction(i::Int, N::Int)
    (1 <= i <= N) || throw(ArgumentError("index out of range: i=$i (N=$N)"))
    return _frac_str(i - 1, N)
end

読み方

  • (1 <= i <= N) || throw(ArgumentError(...)) — 範囲ガード。i が 1..N の外なら短絡評価で throw。|| は「左が真ならそこで終わり、偽のときだけ右を評価」する Julia のイディオム。エラー文に i と N の実値を埋め込むので原因が分かりやすい。
  • i - 1 — 1 始まりを 0 始まりへ。i=1 が分子 0（＝原点）に対応する。物理側の 0 起点座標に合わせるためのオフセット。
  • _frac_str(i - 1, N) — 分子 i-1・分母 N を渡し、約分＋文字列化を下請けに任せる。i=3, N=4 なら _frac_str(2, 4) → "1/2"。
  • 戻り値は約分済み。N=8 の i=1..8 は "0", "1/8", "1/4", "3/8", "1/2", "5/8", "3/4", "7/8" と、割り切れるものは自動で約分されて並ぶ。
境界の約束： インデックスは 1 始まり・上限 N。i=0 や i=N+1 は範囲外エラーになる。返る座標は [0, 1) 側（i=N で (N-1)/N）で、1 ちょうどは出ない点に注意。格子分割 N と 1 始まりの反復インデックスをそのまま渡す設計。
関連：format_grid_fraction は _frac_str → _reduce_fraction を内部で使う連鎖（入口 → 文字列化 → 約分）。これら整形群と上のログ整形群は、setup / run のドライバスクリプトが実行ログや軸ラベルを出すのに使う。
全体像： 前半の log_hr / log_banner / log_section / log_kv が バッチ実行の進捗ログを ==== TITLE ====・--- title ---・ key : value の一定体裁に整え、後半の _reduce_fraction → _frac_str → format_grid_fraction の連鎖が k-path / q 点のラベルを 0・1/4・-3/8 のような約分済み分数で用意する。 どちらも外部依存なしで、setup / run のドライバから気軽に呼べる軽量ユーティリティとして働く。
