Interaction — 相互作用行列・mask・Stoner 指標

— Kanamori 相互作用 Uspin/Ucharge の構築、省メモリ mask、Uχ0 の評価  |  関数名をクリックで詳細 —

多軌道 FLEX/Eliashberg の入力となる局所相互作用行列 Uspin・Ucharge （Kanamori 型）を組み、自己無撞着に効かない全ゼロ成分を落とす mask（mask_inds）と、 Stoner 不安定性の指標 Uχ0 の評価をまとめたファイル。ここで作った U と mask_inds が、FLEX の calc_Veff!・calc_CHI0! や Eliashberg の calc_PairPotential! にそのまま渡る。 eval_Uchi0 は RPA 分母 1-Uχ0 が特異点に近づいていないか（is_Uchi0_scale が要るか）の事前チェックに使う。

このページの規約：複合添字 Nco=No² は軌道 4 つ組 (i1 i2 j1 j2) を (i1 i2)=行 / (j1 j2)=列 に畳んだもの（reshape(No⁴ → No²×No²)）。分解は i1=(c-1)÷No+1, i2=(c-1)%No+1（他ファイルと共通）。mask_inds は Uspin・Ucharge が共に全ゼロの列を落とした「効く」複合添字で、FLEX/Eliashberg の mask_inds 引数の出所。Uχ0 の最大固有値が 1 に近いほど Stoner 不安定 （χs=χ0(1-Usχ0)-1 が発散に近づく）。

# interaction.jl
# 相互作用行列 U_spin / U_charge、その省メモリ mask、
# および Uχ0（Stoner 不安定性の指標）。

using LinearAlgebra
get_interaction_matrices▶ Kanamori 型局所相互作用をサイトごとに組み (No²×No²) 行列に reshape
get_interaction_matrices(U, Uprime, Jhund, Jpair, Norb_each_site; Uweight_each_site=nothing) → (U_spin, U_charge)

概要

Kanamori パラメータ（軌道内 U、軌道間 U'、Hund 結合 J、ペアホッピング J'）から スピン/電荷チャンネルの局所相互作用テンソル (No,No,No,No) をサイトごとにブロック対角で組み、 (No²×No²) 行列に reshape して返す。多サイトのときは Uweight_each_site でサイト別に重み付けできる。

コード

interaction.jl · get_interaction_matrices
function get_interaction_matrices(U, Uprime, Jhund, Jpair, Norb_each_site; Uweight_each_site=nothing)
    No = sum(Norb_each_site)
    Nsite = length(Norb_each_site)
    Nco = No * No
    U_spin_tensor = zeros(No, No, No, No)
    U_charge_tensor = zeros(No, No, No, No)
    if Uweight_each_site === nothing
        Uweight_each_site = ones(Nsite)
    end

    s, e = 1, 0
    for (No_site, weight) in zip(Norb_each_site, Uweight_each_site)
        e += No_site
        Us_local = zeros(No_site, No_site, No_site, No_site)
        Uc_local = zeros(No_site, No_site, No_site, No_site)
        for j in 1:No_site, i in 1:No_site
            if i == j
                Us_local[i, i, i, i] = U
                Uc_local[i, i, i, i] = U
            else
                Us_local[i, i, j, j] = Jhund
                Uc_local[i, i, j, j] = 2 * Uprime - Jhund
                Us_local[i, j, i, j] = Uprime
                Uc_local[i, j, i, j] = 2 * Jhund - Uprime
                Us_local[i, j, j, i] = Jpair
                Uc_local[i, j, j, i] = Jpair
            end
        end
        U_spin_tensor[s:e, s:e, s:e, s:e] .= Us_local .* weight
        U_charge_tensor[s:e, s:e, s:e, s:e] .= Uc_local .* weight
        s += No_site
    end

    return reshape(U_spin_tensor, Nco, Nco), reshape(U_charge_tensor, Nco, Nco)
end

相互作用テンソルの成分（i≠j）

成分U_spinU_charge意味
i i i iUU軌道内（i=j の対角）
i i j jJ2U'-J密度–密度（軌道間）
i j i jU'2J-U'スピン反転・交換
i j j iJ'J'ペアホッピング

読み方

  • No = sum(Norb_each_site) — 全軌道数（各サイトの軌道数の総和）。Nco=No² が複合添字の次元。
  • if i == j … Us_local[i,i,i,i]=U — 軌道内成分。スピン・電荷とも U。
  • else の 3 対 — Kanamori の 4 成分（上表）。iijj/ijij/ijji にそれぞれ J, U', J' 系を割り当てる。電荷側は 2U'-J・2J-U' と符号・係数が変わる。
  • U_spin_tensor[s:e, s:e, s:e, s:e] .= Us_local .* weight — 各サイトのブロックを対角位置 s:e に置く（サイト間は局所 U で結ばれない）。weight でサイト別スケール。
  • reshape(U_spin_tensor, Nco, Nco) — (No,No,No,No) を (No²×No²) に畳む。前 2 軸が行、後 2 軸が列の複合添字。
添字の確認方法： どの複合添字がどの軌道 4 つ組かは get_orbital_subs で文字列表として出せる。多軌道で符号や配置を疑ったらまずこれで並びを確認するとよい。
関連：get_mask（ゼロ成分を落とす）／ get_orbital_subs（添字の確認）／ calc_Veff!・calc_PairPotential!（U を受ける）
get_mask▶ U が全ゼロの複合添字を落として省メモリ・高速化
get_mask(U_spin, U_charge) → (mask_inds, U_spin[mask,mask], U_charge[mask,mask])

概要

Uspin・Ucharge がともに全ゼロの複合添字（列）を落とし、 残った「効く」複合添字 mask_inds と、その部分に絞った U 行列を返す。単軌道や 「U のみ」等で多くの成分がゼロになるとき、χ0・Σ の計算量とメモリを大きく減らせる。

コード

interaction.jl · get_mask
function get_mask(U_spin::Array{Float64,2}, U_charge::Array{Float64,2})
    mask_inds = prod(iszero.(U_spin) .* iszero.(U_charge), dims=1)
    mask_inds = getindex.(findall(x -> x == 0, mask_inds), 2)
    return mask_inds, U_spin[mask_inds, mask_inds], U_charge[mask_inds, mask_inds]
end

読み方

  • iszero.(U_spin) .* iszero.(U_charge) — 要素ごとに「両方ゼロなら 1、どちらか非ゼロなら 0」の行列。
  • prod(…, dims=1) — 各列で総積。列が丸ごとゼロのときだけ 1、非ゼロ成分を含む列は 0 になる。
  • findall(x -> x == 0, …) — 積が 0＝残す列の位置を拾い、getindex.(…, 2) で列番号（複合添字）だけ取り出す。これが mask_inds。
  • U_spin[mask_inds, mask_inds] — 行・列とも mask_inds に絞った縮約版 U。以降の FLEX/Eliashberg はこの縮約 U と mask_inds で回る。
なぜ効くか： RPA の行列演算は複合添字 Nco=No² の Nco×Nco 行列を全 (q,iν) で扱う。U のゼロ列に対応する成分は結果に寄与しないので、落とすほど Nco が小さくなり行列積・逆行列・FFT が速くなる。mask_inds=nothing（マスク無し）だと全 No² 成分を計算する。
関連：get_interaction_matrices（入力 U）／ calc_CHI0!・calc_SIGMA!・calc_DELTA!（mask_inds を受ける）
get_orbital_subs▶ 複合添字 → 軌道 4 つ組 (i1 i2 j1 j2) の文字列表（デバッグ用）
get_orbital_subs(mask_inds, No; join_symbol="") → Matrix{String}（Nco×Nco）

概要

mask_inds の各複合添字が、どの軌道 4 つ組 (i1 i2 j1 j2) に対応するかを Nco×Nco の文字列表で返すデバッグ表示用ヘルパ。物理計算はしない。相互作用行列の並びや mask の中身を目で確認するときに使う。

コード

interaction.jl · get_orbital_subs
function get_orbital_subs(mask_inds, No; join_symbol="")
    Nco = length(mask_inds)
    i1 = j1 = (mask_inds .- 1) .÷ No .+ 1
    i2 = j2 = (mask_inds .- 1) .% No .+ 1
    orbital_subs_array = fill("", Nco, Nco)
    for jj in 1:Nco, ii in 1:Nco
        orbital_subs_array[ii, jj] = join(["$(i1[ii])" "$(i2[ii])" "$(j1[jj])" "$(j2[jj])"], join_symbol)
    end
    return orbital_subs_array
end

読み方

  • i1=(mask-1)÷No+1 / i2=(mask-1)%No+1 — 複合添字を軌道ペアに分解（他ファイルと同じ規約）。行側が (i1,i2)、列側が (j1,j2)。
  • join(["$(i1[ii])" "$(i2[ii])" "$(j1[jj])" "$(j2[jj])"], join_symbol) — 4 つ組を join_symbol で連結。既定は空文字（例："1212"）、join_symbol="-" なら "1-2-1-2"。
  • 返り値は Nco×Nco の文字列行列。行 ii・列 jj が相互作用行列の同じ位置に対応。
使いどころ： get_interaction_matrices の成分（iijj/ijij/ijji）が正しい位置に入っているか、mask で残った添字が期待どおりかを、この表と突き合わせて確認できる。
関連：get_interaction_matrices・get_mask（対象の添字を供給）
eval_Uchi0▶ Uχ0 の最大(spin)/最小(charge)固有値を全 (iω,q) で探す（Stoner 判定）
eval_Uchi0(CHI, U; eval_eigval=true, channel="spin", return_eigvec=false) → (best_val, best_ind[, best_vec])

概要

Uχ0 の固有値を全 (iω, q) にわたって走査し、スピンなら最大・電荷なら最小の 固有値と、その位置 best_ind=(w,x,y,z,mode) を返す。Stoner 判定（1 に近いほど磁気/電荷 不安定）の指標。return_eigvec=true で不安定モードの固有ベクトル（軌道キャラクター）も返す。

コード

interaction.jl · eval_Uchi0
function eval_Uchi0(CHI::Array{ComplexF64,6}, U::Array{Float64,2};
                   eval_eigval::Bool=true, channel::String="spin", return_eigvec::Bool=false)
    (channel == "spin" || channel == "charge") ||
        throw(ArgumentError("channel must be either \"spin\" or \"charge\"."))

    Nw2, Nqx, Nqy, Nqz, Nco, _ = size(CHI)
    Nw = Nw2 ÷ 2

    best_val = channel == "spin" ? -Inf : Inf
    best_ind = CartesianIndex(1, 1, 1, 1, 1)
    best_vec = return_eigvec ? zeros(Float64, Nco) : zeros(Float64, 0)

    tmp2 = Array{ComplexF64}(undef, Nco, Nco)
    for w in 1:Nw
        for z in 1:Nqz, y in 1:Nqy, x in 1:Nqx
            @views tmp2 .= U * CHI[w, x, y, z, :, :]
            if eval_eigval
                # 実固有値を安定に得るためエルミート部を取る
                Ah = (tmp2 .+ adjoint(tmp2)) .* 0.5
                e = eigen(Hermitian(Ah))
                vals = real.(e.values)
                mode = (channel == "spin") ? argmax(vals) : argmin(vals)
                val = vals[mode]
                if (channel == "spin" && val > best_val) || (channel == "charge" && val < best_val)
                    best_val = val
                    best_ind = CartesianIndex(w, x, y, z, mode)
                    return_eigvec && (best_vec .= real.(e.vectors[:, mode]))
                end
            else
                # レガシー: U*chi0 の成分そのものを直接見る
                R = real.(tmp2)
                v, idx = channel == "spin" ? findmax(R) : findmin(R)
                co1, co2 = Tuple(idx)
                val = Float64(v)
                if (channel == "spin" && val > best_val) || (channel == "charge" && val < best_val)
                    best_val = val
                    best_ind = CartesianIndex(w, x, y, z, co1)
                    return_eigvec && (best_vec .= 0.0)
                end
            end
        end
    end

    return return_eigvec ? (best_val, best_ind, best_vec) : (best_val, best_ind)
end

読み方

  • best_val = channel=="spin" ? -Inf : Inf — スピンは最大を探すので -Inf から、電荷は最小なので Inf から更新していく。
  • tmp2 .= U * CHI[w,x,y,z,:,:] — その (iω,q) の Uχ0（Nco×Nco）。
  • eval_eigval=true： Ah=(tmp2+tmp2†)/2 でエルミート部を取り eigen(Hermitian(Ah))。実固有値を安定に得るための処理。argmax(spin)/argmin(charge) で最不安定モードを選ぶ。
  • if (spin && val > best_val) || (charge && val < best_val) — チャンネルに応じて best を更新。位置 (w,x,y,z,mode) を 不安定が起きる周波数・波数・モードとして記録。
  • return_eigvec && (best_vec .= real.(e.vectors[:,mode])) — 不安定モードの固有ベクトル＝秩序の軌道キャラクターを保存。
  • eval_eigval=false（レガシー）： 固有値でなく real(Uχ0) の成分そのものを findmax/findmin で見る旧方式。
Stoner 不安定との関係： χs=χ0(1-Usχ0)-1 は Usχ0 の最大固有値が 1 に達すると発散（磁気秩序への不安定）。eval_Uchi0 の best_val が 1 に近い/超えるなら、 calc_Veff! の is_Uchi0_scale（固有値を maxeigval_tol≈0.99 に抑える）が必要になる。best_ind は秩序波数 Q の目安。
関連：calc_Veff!（is_Uchi0_scale／maxeigval_tol）／ get_interaction_matrices（U）／ calc_CHI0!（χ0）
全体の流れ： get_interaction_matrices で Uspin/Ucharge を作り → get_mask で効く複合添字 mask_inds に絞る（必要なら get_orbital_subs で並びを確認）→ FLEX の χ0→χs/χc→Veff と Eliashberg の Vpair に U・mask_inds を供給。SCF 中や事後に eval_Uchi0 で Uχ0 をチェックし、Stoner 不安定に近ければ is_Uchi0_scale で安定化する。
