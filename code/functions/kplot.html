KPlot — 充填ブリルアンゾーンのプロット下ごしらえ

— χ(q)・ギャップ φ(k) を六角形 BZ を埋めた形で描くための配列づくりとゲージ固定  |  関数名をクリックで詳細 —

FLEX / Eliashberg で得た逆空間データ — 感受率 χ(q) や超伝導ギャップ φ(k) — を、 逆格子ベクトルが張る平行四辺形（菱形）のままではなく、六角形ブリルアンゾーン(BZ)を埋めた形で 描くための下ごしらえを担うファイル。実際の pcolormesh や contour の描画は 各プロットスクリプト側が行い、ここはプロット用の配列（座標 X,Y・値 Z・BZ 外周ポリゴン bx,by）だけを返す。 そのため PyPlot には依存せず、純粋な配列操作に徹している。

このページの規約：依存は lattice.jl（_build_kmesh_cart / _build_bz_mask / _as3 を呼ぶ。通常は include("functions/nonint.jl") 経由で先に読み込まれている前提）、 q 空間データは q=0 が index 1（FFT と同じ並び）、circshift で BZ 中心へ寄せ、 repeat でタイル複製する（χ(q)・E(k) は逆格子周期を持つので単純複製で正しい）。 hex 格子ではポリゴンで六角形にマスクし、square 格子では mask は全 true（＝タイルした平行四辺形をそのまま表示）。

kplot.jl — 冒頭
# kplot.jl
# q/k 空間の「充填ブリルアンゾーン(BZ)」マップ用ヘルパ（PyPlot 非依存）。
#   依存: lattice.jl の _build_kmesh_cart / _build_bz_mask / _as3

using LinearAlgebra
_tile2d_to_Z▶ data[qx,qy]（q=0 が index 1）を BZ 中心へ寄せてタイル複製し、pcolormesh 向きの (Ny,Nx) に整える下請け
_tile2d_to_Z(data; shiftx, shifty, center_bz, supercell_range) → Z::(Ny,Nx)

概要

q 空間データ data[qx,qy]（q=0 が index 1）を、center_bz なら circshift で BZ 中心へ寄せ、(2·supercell_range+1) 倍に repeat でタイル複製し、最後に permutedims で pcolormesh 向きの (Ny,Nx) に転置して返す。 χ(q)・E(k) は逆格子周期を持つ量なので、周期の外側を単純な repeat で埋めても 物理的に正しい値になる（＝周期関数を並べているだけ）のがミソ。

コード

kplot.jl · _tile2d_to_Z
function _tile2d_to_Z(data::AbstractMatrix{<:Real}; shiftx::Int, shifty::Int, center_bz::Bool, supercell_range::Int)
    data_shift = center_bz ? circshift(data, (shiftx, shifty)) : data
    data_tile = repeat(data_shift, outer=(2 * supercell_range + 1, 2 * supercell_range + 1))
    return permutedims(data_tile, (2, 1))
end

読み方

  • data::AbstractMatrix{<:Real} — 入力は実数行列（χ(q) や E(k) のスカラー値マップ）。第1軸が qx、第2軸が qy で、q=0 が index 1 に載っている。
  • center_bz ? circshift(data, (shiftx, shifty)) : data — center_bz=true のとき、q=0 が端にある配列を circshift で中央へ巡回シフトし、BZ の中心が絵の真ん中に来るようにする。shiftx,shifty は呼び出し側（_build_kmesh_cart）が計算した量。
  • repeat(data_shift, outer=(2·supercell_range+1, 2·supercell_range+1)) — 縦横それぞれ (2·supercell_range+1) 枚にタイル状に複製。supercell_range=1 なら 3×3 枚で、平行四辺形セルを並べて六角形を覆えるだけの広さにする。
  • 単純複製で正しい理由： χ(q)・E(k) は逆格子周期 f(q+G)=f(q) を満たすので、隣のセルへコピーした値がそのまま真の値になる。位相を持つ量（例：固有ベクトル）ならこうは行かないが、ここで扱うのは実スカラーマップなので安全。
  • permutedims(data_tile, (2, 1)) — 軸を (qx,qy) から (qy,qx) に入れ替え、行=y・列=x の (Ny,Nx) 形にする。pcolormesh(X, Y, Z) が期待する Z の向きに合わせるための転置。
位置づけ： この関数は bz_map の内部下請け。値を「並べて・寄せて・向きを直す」だけを担当し、どこを表示するか（マスク）は次の _apply_nan_mask! が受け持つ、と役割が分かれている。
関連：bz_map（この結果にマスクを掛けて Z を仕上げる）／ lattice.jl の _build_kmesh_cart（shiftx,shifty の供給元）
_apply_nan_mask!▶ BZ 外（mask=false）の点を NaN にして透明化する破壊的ヘルパ
_apply_nan_mask!(Z::AbstractMatrix{Float64}, mask::AbstractMatrix{Bool}, use_mask::Bool) → Z # 破壊的

概要

タイル複製した値配列 Z のうち、BZ の外側にあたる点（mask が false の位置）を NaN に書き換える破壊的関数。NaN は pcolormesh では透明に、 contour では無視されるので、六角形の外へはみ出した部分を絵から消せる。 use_mask=false のときは何もせず Z をそのまま返す（square 格子など、全面表示でよい場合）。

コード

kplot.jl · _apply_nan_mask!
function _apply_nan_mask!(Z::AbstractMatrix{Float64}, mask::AbstractMatrix{Bool}, use_mask::Bool)
    use_mask && (Z[.!mask] .= NaN)
    return Z
end

読み方

  • 関数名末尾の ! は Julia の慣習で「引数を破壊的に書き換える（in-place）」合図。渡した Z そのものが更新される。
  • use_mask && (...) — 短絡評価のイディオム。use_mask が true のときだけ右側を実行し、false なら何もしない（if use_mask ... end の一行版）。
  • .!mask — mask の論理否定を要素ごとに取る（. はブロードキャスト）。mask=true＝BZ 内なので、.!mask はBZ 外の位置を true にした真偽行列になる。
  • Z[.!mask] .= NaN — そのBZ 外の位置だけを NaN で埋める。論理インデックスによる一括代入。
  • return Z — 破壊済みの同じ配列を返す（呼び出し側が続けて使えるように）。
なぜ NaN か： 0 で埋めるとカラースケールに 0 の色が乗って BZ 外が「見えて」しまう。NaN は matplotlib 側で描画対象から外れるため、外周ポリゴンの内側だけが綺麗に塗られる。
関連：bz_map（_tile2d_to_Z の結果にこれを適用）／ lattice.jl の _build_bz_mask（mask の供給元）
bz_map▶ q 空間データを六角形 BZ を埋める形にして返す — このファイルの主役
bz_map(data_qxqy, Nqx, Nqy; b1, b2, lattice_type="hex", axis_unit=:pi, supercell_range=1, center_bz=true, mask_to_bz=true, mask_dilate=1) → (X, Y, Z, bx, by)

概要

このファイルの主役。q 空間データ data[qx,qy]（q=0 が index 1）を、BZ を埋める形の プロット素材にして返す。戻り値は名前付きタプルで、 X,Y＝プロット座標（axis_unit=:pi なら 1/π スケール、shape (Ny,Nx)）、 Z＝マスク済みの値（BZ 外は NaN、shape (Ny,Nx)）、 bx,by＝BZ 外周ポリゴンの座標（scale 済み）。 hex 格子では primitive セルをタイル複製して六角形にマスクし、square 格子では mask を全 true にして 平行四辺形をそのまま表示する。

コード

kplot.jl · bz_map
function bz_map(
    data_qxqy::AbstractMatrix{<:Real}, Nqx::Int, Nqy::Int;
    b1, b2, lattice_type::AbstractString="hex",
    axis_unit::Symbol=:pi, supercell_range::Int=1,
    center_bz::Bool=true, mask_to_bz::Bool=true, mask_dilate::Int=1,
)
    (size(data_qxqy) == (Nqx, Nqy)) ||
        throw(ArgumentError("bz_map: data size $(size(data_qxqy)) != (Nqx,Nqy)=($Nqx,$Nqy)"))
    scale = axis_unit == :pi ? (1 / π) : 1.0
    b1p = _as3(b1) .* scale
    b2p = _as3(b2) .* scale
    km = _build_kmesh_cart(Nqx, Nqy; b1=b1p, b2=b2p, supercell_range=supercell_range, center_bz=center_bz)
    bz = _build_bz_mask(km.X, km.Y; lattice_type=lattice_type, b1=b1p, b2=b2p, mask_to_bz=mask_to_bz, mask_dilate=mask_dilate)
    Z = Float64.(_tile2d_to_Z(data_qxqy; shiftx=km.shiftx, shifty=km.shifty, center_bz=center_bz, supercell_range=supercell_range))
    _apply_nan_mask!(Z, bz.mask, bz.use_mask)
    return (X=km.X, Y=km.Y, Z=Z, bx=bz.bx, by=bz.by)
end

読み方

  • (size(data_qxqy) == (Nqx, Nqy)) || throw(ArgumentError(...)) — 冒頭でサイズ検証。データの形が (Nqx,Nqy) と一致しなければ、寸法の取り違えとして即エラー停止する（A || throw(...) は「A が false なら投げる」の短絡イディオム）。
  • scale = axis_unit == :pi ? (1/π) : 1.0 — 軸の単位を決める。:pi なら 1/π でスケールして座標が k/π 単位（＝±1 が BZ 端の目安）になり、そうでなければ生の逆格子座標のまま。
  • b1p = _as3(b1) .* scale / b2p = _as3(b2) .* scale — 逆格子ベクトル b1,b2 を _as3 で3成分ベクトルに正規化してから scale を掛ける。以降のメッシュ・外周計算をこのスケール済み基底で統一する。
  • km = _build_kmesh_cart(Nqx, Nqy; b1=b1p, b2=b2p, supercell_range, center_bz) — lattice.jl を呼び、デカルト座標のメッシュ km.X, km.Y と、中心寄せ用の km.shiftx, km.shifty を得る。
  • bz = _build_bz_mask(km.X, km.Y; lattice_type, b1=b1p, b2=b2p, mask_to_bz, mask_dilate) — 同じく lattice.jl で、BZ 外周ポリゴン bz.bx, bz.by・内外マスク bz.mask・マスク使用フラグ bz.use_mask を作る。mask_dilate は縁を少し膨らませて端の欠けを防ぐ調整。
  • Z = Float64.(_tile2d_to_Z(data_qxqy; shiftx=km.shiftx, shifty=km.shifty, center_bz, supercell_range)) — 値をタイル複製し (Ny,Nx) 向きの Float64 配列に。メッシュと同じ shiftx,shifty,supercell_range を渡すのが整合の鍵。
  • _apply_nan_mask!(Z, bz.mask, bz.use_mask) — BZ 外を NaN にして六角形の外を透明化（square で use_mask=false なら素通し）。
  • return (X=km.X, Y=km.Y, Z=Z, bx=bz.bx, by=bz.by) — 座標・値・外周を名前付きタプルで返す。あとはプロット側が pcolormesh(X,Y,Z) と plot(bx,by) を描くだけ。
組み立ての骨格： _build_kmesh_cart（座標）＋_build_bz_mask（外周とマスク）で「どこに何を描くか」を作り、_tile2d_to_Z＋_apply_nan_mask! で「値を並べて外を消す」。この 2 系統を突き合わせるのが bz_map の仕事で、返すのは配列だけ（描画はしない）。
関連：lattice.jl の _build_kmesh_cart / _build_bz_mask / _as3（メッシュ・外周・ベクトル正規化）／ 内部下請け _tile2d_to_Z・_apply_nan_mask!
fix_unitary_time_reversal_gauge!▶ U(-k) ≈ conj(U(k)) になるよう時間反転ゲージをそろえる（破壊的）
fix_unitary_time_reversal_gauge!(UNITARY::Array{ComplexF64,5}; eps=1e-12) # 破壊的

概要

時間反転ゲージの固定。各バンド b について U(-k) ≈ conj(U(k)) が成り立つよう、 U(-k) の U(1) 位相をそろえる（具体的には v(k)T v(-k) を実正にする）。 異常項のバンド変換 φband(k) = U†(k) φorb(k) conj(U(-k)) では U(k) と U(-k) の相対位相が効くため、これをそろえておかないとバンド表示のギャップが 位相のバラつきで汚くなる。前提として、先に fix_unitary_gauge!（各 k の U(1) 位相固定）を 済ませておくこと。

コード

kplot.jl · fix_unitary_time_reversal_gauge!
function fix_unitary_time_reversal_gauge!(UNITARY::Array{ComplexF64,5}; eps::Float64=1e-12)
    Nqx, Nqy, Nqz, Norb, _ = size(UNITARY)
    x_, y_, z_ = map(N -> [1; N:-1:2], (Nqx, Nqy, Nqz))
    for z in 1:Nqz, y in 1:Nqy, x in 1:Nqx
        xx, yy, zz = x_[x], y_[y], z_[z]
        # 各 (k, -k) ペアを一度だけ処理する（k=-k の固定点は処理する）
        (x > xx) && continue
        (x == xx && y > yy) && continue
        (x == xx && y == yy && z > zz) && continue
        for b in 1:Norb
            v_k = @view UNITARY[x, y, z, :, b]
            v_m = @view UNITARY[xx, yy, zz, :, b]
            overlap = sum(v_k .* v_m)          # v(k)^T v(-k)
            if abs(overlap) > eps
                phase = conj(overlap) / abs(overlap)
                @views UNITARY[xx, yy, zz, :, b] .*= phase
            end
        end
    end
    return nothing
end

読み方

  • x_, y_, z_ = map(N -> [1; N:-1:2], (Nqx,Nqy,Nqz)) — 各軸の「-k の折り返しインデックス」表。index 1（k=0）は自分自身、それ以外は N, N-1, …, 2 と逆順に並べ、x_[x] が「x 番目の k に対する -k の位置」を与える（fftfreq 並びで -k は末尾側に来るため）。
  • xx, yy, zz = x_[x], y_[y], z_[z] — 現在の k (x,y,z) に対する -k の格子インデックス (xx,yy,zz)。
  • (x > xx) && continue ほか 3 行 — 各 (k,-k) ペアを一度だけ処理するためのフィルタ。x が折り返し先より大きい／x が同じで y が大きい／x,y が同じで z が大きい、という場合は相方側で既に処理済みなので continue でスキップ。等号がすべて成り立つ点（k=-k の固定点）はスキップされず処理される。
  • v_k = @view UNITARY[x,y,z,:,b] / v_m = @view UNITARY[xx,yy,zz,:,b] — バンド b の固有ベクトル v(k) と v(-k)（@view でコピーせず参照）。
  • overlap = sum(v_k .* v_m) — 転置内積 v(k)T v(-k)（共役を取らない）。時間反転の関係 v(-k) ≈ conj(v(k)) が成り立てば、この量は Σ|vi|2 に近く実正になるはず。
  • if abs(overlap) > eps — 重なりがほぼ 0（バンドが直交・縮退などで基準に使えない）なら位相合わせをスキップする安全弁。
  • phase = conj(overlap) / abs(overlap) → UNITARY[xx,yy,zz,:,b] .*= phase — v(-k) 全体にこの単位位相を掛け、overlap を実正に回す。これで U(-k) ≈ conj(U(k)) の相対位相がそろう。
  • 末尾の ! と return nothing — 破壊的に UNITARY を書き換えるだけで、戻り値は持たない。
前提の順序： この関数は各 k の位相が既に整っていること（fix_unitary_gauge! 済み）を仮定して、k と -k の相対位相だけを合わせる。先に fix_unitary_gauge! を呼んでいないと、基準にする overlap の位相がそもそも安定せず効果が出ない。
関連：nonint.html の fix_unitary_gauge!（先に呼ぶ前提：各 k の U(1) 位相固定）／ 異常項のバンド変換 φband=U† φorb conj(U(-k))
global_phase_fix_mode!▶ mode ごとに全体位相を固定し、実部プロットの符号を安定させる（破壊的）
global_phase_fix_mode!(phi; iw_index=1, mode_index=1) # 破壊的

概要

7 階配列 phi[iw, kx, ky, kz, i, j, mode] の1 つの mode について、 iw_index スライスの中で最大 |φ| の成分が実正になるよう、 その mode 全体（全 iw, k, i, j）に同じ U(1) 位相を掛ける。 固有ベクトル的な量は全体位相 eiθ の分だけ不定なので、これを固定して 実部プロットの符号がフレームごとに反転しないようにする前処理。

コード

kplot.jl · global_phase_fix_mode!
function global_phase_fix_mode!(phi::AbstractArray; iw_index::Int=1, mode_index::Int=1)
    (1 <= iw_index <= size(phi, 1)) || return nothing
    (1 <= mode_index <= size(phi, 7)) || return nothing
    viewm = @view phi[iw_index, :, :, :, :, :, mode_index]
    ind = argmax(abs.(viewm))
    ref = viewm[ind]
    if !iszero(ref)
        phase = ref / abs(ref)
        @views phi[:, :, :, :, :, :, mode_index] .*= conj(phase)
    end
    return nothing
end

読み方

  • (1 <= iw_index <= size(phi, 1)) || return nothing — iw_index が第1軸の範囲内かを境界チェック。外れていれば何もせず戻る（A || return nothing の短絡）。次行の mode_index（第7軸）も同様。
  • viewm = @view phi[iw_index, :, :, :, :, :, mode_index] — 固定した iw_index・mode_index のスライス（kx,ky,kz,i,j の 5 次元ビュー）を切り出す。ここが位相の基準を探す範囲。
  • ind = argmax(abs.(viewm)) — スライス内で絶対値が最大の成分の位置。振幅が大きく数値的に安定な成分を位相基準に選ぶ。
  • ref = viewm[ind] — その基準成分の複素値。
  • if !iszero(ref) — 基準がちょうど 0（全成分ゼロなど）でなければ処理する安全弁。
  • phase = ref / abs(ref) — 基準成分の単位位相 eiθ（絶対値 1）。
  • phi[:, :, :, :, :, :, mode_index] .*= conj(phase) — その mode の全体（全 iw,k,i,j）に conj(phase)=e-iθ を掛け、基準成分を実正に回す。掛けるのは全域に共通の 1 個の位相なので、mode 内部の相対関係は保たれたまま符号だけが安定する。
  • 末尾 ! と return nothing — 破壊的に phi を書き換える。
効果： 実部 Re φ(k) をカラーマップで描くとき、全体位相が違うと同じ物理でも「赤と青が入れ替わる」ことがある。最大成分を実正に固定しておくと、mode ごとに符号の基準がそろい、複数フレーム・複数 mode を並べても見比べやすくなる。
関連：fix_unitary_time_reversal_gauge!（k,-k の相対位相をそろえる姉妹関数）／ 実部プロットの前処理として併用
全体の流れ： bz_map が χ(q) マップ描画の主役で、lattice.jl のメッシュ・外周を借りて 「座標 X,Y・値 Z・外周 bx,by」を返し、あとはプロット側が pcolormesh / contour するだけ。 一方 fix_unitary_time_reversal_gauge! と global_phase_fix_mode! はバンド表示・実部プロットを綺麗にする前処理で、 前者は U(k) と U(-k) の相対位相を、後者は mode ごとの全体位相をそろえる。 ゲージ系は必ず fix_unitary_gauge! を先に済ませてから使うのが約束。
