Eliashberg — 線形化ギャップ方程式と固有値問題

— ペアポテンシャル・異常グリーン関数からギャップ写像 Δ→Δ を組み、最大固有値 λ を解く  |  関数名をクリックで詳細 —

線形化 Eliashberg 方程式のコア。FLEX で得た G・χ0 と Anomalous の初期ギャップ Δ を土台に、ペアポテンシャル Vpair（χs,χc の線形結合、singlet/triplet で係数が違う）を組み、 異常グリーン関数 F=GΔG*(-k) とギャップ更新 Δ=-T/N Σ VpairF を合成した 線形写像 Δ→Δ の最大固有値 λ を Lanczos / べき乗法で解く。 λ=1 で超伝導転移（そこが Tc）、λ が大きいほど不安定＝高い Tc。

init_DELTA_band!→ calc_PairPotential!→ _matvec!: calc_GREEN_anomalous! → calc_DELTA!↻ eigs / power→ λ, φ
このページの規約：異常項は k と -k を結ぶ（Anomalous と同じ [1; N:-1:2] の k→-k 写像）。Vpair のボゾン周波数の並びは FLEX の Veff と同じ（iν=0 先頭・Nw+1 折り返し・負側は †）。 F=GΔG*(-k) の G* は複素共役であって随伴 † ではない点に注意。 線形化 Eliashberg を Δ→Δ の線形写像とみなし、その最大実固有値 λ を求める。 数値ロジックは検証済み実装をそのまま移植。

# eliashberg.jl
# 線形化 Eliashberg 方程式のコア。
#   ペアポテンシャル  Vpair = f(χ_s, χ_c, U)   （singlet / triplet で係数が違う）
#   異常グリーン関数  F(k,iω) = G(k,iω) Δ(k,iω) G*(-k,iω)
#   ギャップ更新      Δ(k,iω) = -T/N Σ Vpair(r,τ) F(r,τ)
# これを線形写像 Δ → Δ とみなし、その最大固有値 λ を Lanczos / べき乗法で解く。
# λ=1 で超伝導転移。λ が大きいほど不安定（Tc が高い）。

概要

既存 Fortran 実装の数値パラメータ（psym=ペア対称性、ssym=スピン対称性）を、Julia 側で使う 対称性文字列（"random"/"spm"/"dx2-y2"/"dxy"、 "singlet"/"triplet"）に翻訳する互換シム。_parse_Lanczos_which は ARPACK の which 指定を Symbol に正規化する。

コード

eliashberg.jl · 入力変換ヘルパ
function _psym_to_init_symmetry(psym::Integer)
    psym == 4 && return "random"
    (psym == 0 || psym == 2) && return "spm"
    (psym == 1 || psym == 3) && return "dx2-y2"
    (psym == 5 || psym == 6) && return "dxy"
    @warn "Unknown psym=$psym. Using random initialization."
    return "random"
end

_ssym_to_spin_symmetry(ssym::Integer) = (ssym == 1) ? "singlet" : "triplet"

_parse_Lanczos_which(x) = x isa Symbol ? x : (x isa AbstractString ? Symbol(x) : :LR)

読み方

  • psym の数値 → 対称性名（4→random, 0/2→spm, 1/3→dx2-y2, 5/6→dxy）。ここで作った文字列が init_DELTA_band! の symmetry 引数になる。
  • 未知の psym は @warn して random にフォールバック（落とさない）。
  • _ssym_to_spin_symmetry — ssym==1 で singlet、それ以外は triplet。calc_PairPotential! の係数分岐に効く。
  • _parse_Lanczos_which — Symbol はそのまま、String は Symbol() に、いずれでもなければ既定 :LR（Largest Real＝実部最大）。
役割： 旧 Fortran の入力デック（数値フラグ）をそのまま渡しても Julia 側の文字列 API に橋渡しできるようにするアダプタ。物理計算はしない、純粋な入力変換。
関連：init_DELTA_band!（symmetry/spin_symmetry を受ける）／ Eliashberg_pipeline!（which を使う）
calc_PairPotential!▶ χ0 からペアポテンシャル Vpair を作り CHI に上書き（singlet/triplet で係数が違う）
calc_PairPotential!(CHI, U_spin, U_charge; spin_symmetry="singlet") # CHI: χ0 → Vpair

概要

RPA 感受率 χs=χ0(1-Usχ0)-1・ χc=χ0(1+Ucχ0)-1 からペアポテンシャル Vpair を組み、同じ CHI に上書きする。calc_Veff! と RPA 部分は同型だが、係数が singlet/triplet で異なり、自己エネルギー用の -¼χ0 項が無いのが違い。

コード

eliashberg.jl · calc_PairPotential!
function calc_PairPotential!(CHI::Array{ComplexF64,6}, U_spin::Array{Float64,2}, U_charge::Array{Float64,2}; spin_symmetry::String="singlet")
    Nw2, Nqx, Nqy, Nqz, Nco, _ = size(CHI)
    Nw = Nw2 ÷ 2
    Nq = Nqx * Nqy * Nqz
    CHI_view = reshape(CHI, Nw2, Nq, Nco, Nco)

    dind = diagind(U_spin)
    if spin_symmetry == "singlet"
        U_spin_scale, U_charge_scale = 1.5 .* U_spin, -0.5 .* U_charge
        U_term = 0.5 .* (U_spin .+ U_charge)
    elseif spin_symmetry == "triplet"
        U_spin_scale, U_charge_scale = -0.5 .* U_spin, -0.5 .* U_charge
        U_term = -0.5 .* (U_spin .- U_charge)
    else
        throw(ArgumentError("spin_symmetry must be either \"singlet\" or \"triplet\"."))
    end

    @threads for q in 1:Nq
        chi_S = Array{ComplexF64}(undef, Nco, Nco)
        chi_C = Array{ComplexF64}(undef, Nco, Nco)
        tmp = Array{ComplexF64}(undef, Nco, Nco)
        chi0 = Array{ComplexF64}(undef, Nco, Nco)
        for w in 1:Nw+1
            @views chi0 .= CHI_view[w, q, :, :]

            tmp .= -U_spin * chi0            # chi_S = chi0 (1 - U_S chi0)^-1
            tmp[dind] .+= 1.0
            chi_S .= chi0
            rdiv!(chi_S, lu(tmp))

            tmp .= U_charge * chi0           # chi_C = chi0 (1 + U_C chi0)^-1
            tmp[dind] .+= 1.0
            chi_C .= chi0
            rdiv!(chi_C, lu(tmp))

            CHI_view[w, q, :, :] .= (U_spin_scale * chi_S * U_spin) .+
                                    (U_charge_scale * chi_C * U_charge) .+ U_term
        end
        # Nw+1 に (Vpair(iν)+Vpair(-iν))/2 を入れ、残りは Vpair(-iν)=Vpair†(iν)
        @views tmp .= CHI_view[Nw+1, q, :, :]
        CHI_view[Nw+1, q, :, :] .+= tmp'
        CHI_view[Nw+1, q, :, :] .*= 0.5
        for jj in 1:Nco, ii in 1:Nco
            @views CHI_view[2*Nw:-1:Nw+2, q, ii, jj] .= conj(CHI_view[2:Nw, q, jj, ii])
        end
    end
end

読み方

  • singlet： Vpair = 3/2 UsχsUs - 1/2 UcχcUc + 1/2(Us+Uc)。スピン揺らぎが引力に効く一重項の係数。
  • triplet： Vpair = -1/2 UsχsUs - 1/2 UcχcUc - 1/2(Us-Uc)。三重項では符号・係数が変わる。
  • tmp=-Usχ0; tmp[dind].+=1 → rdiv!(chi_S, lu(tmp)) — χs=χ0(1-Usχ0)-1。calc_Veff! と同じ右割り算だが、こちらは is_Uchi0_scale（固有値縮小）が無い。
  • CHI_view[w,q,:,:] .= U_spin_scale·χs·Us + U_charge_scale·χc·Uc + U_term — 分岐で決めた係数を掛けて Vpair をその場で上書き。
  • Nw+1 の対称化・負側 2Nw:-1:Nw+2 ← conj(2:Nw) — ボゾン周波数の折り返しは calc_Veff! と同じ規約。
calc_Veff! との違い： 自己エネルギー用 Veff は -¼(Us+Uc)χ0(Us+Uc) の項を含むが、ペアポテンシャルには無い。また係数が spin_symmetry で切り替わる。同じ RPA 部品でも「自己エネルギー用」か「対形成用」かで組み方が違うので混同しない。
関連：calc_Veff!（自己エネルギー用の類似関数）／ Eliashberg_pipeline!（これを呼んで Vpair(r,τ) に）
calc_GREEN_anomalous!▶ 異常グリーン関数 F(k,iω)=G(k)Δ(k)G*(-k) を作り DELTA に上書き（in-place）
calc_GREEN_anomalous!(DELTA, G) # DELTA: Δ(k,iω) → F(k,iω)

概要

ギャップ Δ から異常（Gor'kov）グリーン関数 F(k,iω) = G(k,iω) · Δ(k,iω) · G*(-k,iω) を各 k・各周波数で作り、DELTA に上書きする。 G* は複素共役（conj）で随伴 † ではないのが要点。負周波数側は G(-iω)=G†(iω) を利用して、正周波数の G ブロックの随伴・転置から組む。

コード

eliashberg.jl · calc_GREEN_anomalous!
function calc_GREEN_anomalous!(DELTA::Array{ComplexF64,6}, G::Array{ComplexF64,6})
    Nw2, Nqx, Nqy, Nqz, No, _ = size(G)
    Nw = Nw2 ÷ 2
    Nq = Nqx * Nqy * Nqz

    x_, y_, z_ = map(N -> [1; N:-1:2], (Nqx, Nqy, Nqz))
    xyz_ind2sub = CartesianIndices(Array{Int}(undef, Nqx, Nqy, Nqz))
    @threads for q in 1:Nq
        G_local1 = Array{ComplexF64}(undef, No, No)
        G_local2 = Array{ComplexF64}(undef, No, No)
        tmp = Array{ComplexF64}(undef, No, No)
        x, y, z = Tuple(xyz_ind2sub[q])
        xx, yy, zz = x_[x], y_[y], z_[z]
        for w in 1:Nw
            @views G_local1 .= G[w, x, y, z, :, :]
            @views G_local2 .= G[w, xx, yy, zz, :, :]
            @views tmp .= DELTA[w, x, y, z, :, :]
            DELTA[w, x, y, z, :, :] .= G_local1 * tmp * conj(G_local2)
            @views tmp .= DELTA[2*Nw+1-w, x, y, z, :, :]
            DELTA[2*Nw+1-w, x, y, z, :, :] .= G_local1' * tmp * transpose(G_local2)
        end
    end
end

読み方

  • G_local1 = G[w, k]・G_local2 = G[w, -k] — k と -k の G を取り出す（xx,yy,zz が -k）。
  • 正周波数： DELTA[w,k] .= G_local1 * Δ * conj(G_local2) ＝ F(k,iω)=G(k)Δ(k)conj(G(-k))。第 3 因子が conj（複素共役）で '（随伴）ではない。
  • 負周波数（2Nw+1-w）： DELTA[…] .= G_local1' * Δ * transpose(G_local2)。G(k,-iω)=G(k,iω)† と conj(G(-k,-iω))=transpose(G(-k,iω)) を使い、正周波数の G を随伴・転置で流用して負側の F を作る（だから w は 1:Nw だけ回せば足りる）。
  • x_,y_,z_ = map(N -> [1; N:-1:2], …) — Anomalous と同じ k→-k 写像。
† と conj/transpose の取り違え厳禁： F の定義は G Δ G*(-k) で、G* は要素ごとの複素共役。随伴 '（=共役転置）や転置 transpose は負周波数側を「正周波数の G から再構成する」ために使い分けている。ここを混ぜると異常項の対称性が壊れる。
関連：Anomalous（Δ の基底変換・k↔-k）／ calc_GREEN!（入力 G）／ calc_DELTA!（この F を使う）
calc_DELTA!▶ ギャップ更新 Δ = -T/N Σ Vpair(r,τ) F(r,τ) を FFT 畳み込みで（in-place）
calc_DELTA!(DELTA, CHI, temperature, FFT_plan; mask_inds=nothing) # DELTA: F(k,iω) → Δ(k,iω)

概要

異常グリーン関数 F とペアポテンシャル Vpair から新しいギャップ Δ13(r,τ) = -T/N Σ24 V1234(r,τ) F24(r,τ) を (r,τ) の積で作り、 (k,iω) に戻す。入力は DELTA=F(k,iω) と CHI=Vpair(r,τ)。 calc_SIGMA! と似るが軌道添字の配線と符号が違う。

コード

eliashberg.jl · calc_DELTA!
function calc_DELTA!(DELTA::Array{ComplexF64,6}, CHI::Array{ComplexF64,6}, temperature::Float64, FFT_plan; mask_inds=nothing)
    Nw2, Nqx, Nqy, Nqz, No, _ = size(DELTA)
    Nw = Nw2 ÷ 2
    Nq = Nqx * Nqy * Nqz
    mask_inds = (mask_inds === nothing) ? (1:No*No) : mask_inds
    Nco = size(CHI)[5]
    Nco == length(mask_inds) || throw(ArgumentError("Argument mask_inds is missing!"))

    CHI_view = reshape(CHI, 2 * Nw, Nq, Nco, Nco)
    DELTA_view = reshape(DELTA, 2 * Nw, Nq, No, No)
    coef = temperature / Nq

    kw2rt!(DELTA, FFT_plan)   # F(k,iω) -> F(r,τ)
    i1_list = j1_list = (mask_inds .- 1) .÷ No .+ 1
    i2_list = j2_list = (mask_inds .- 1) .% No .+ 1
    for q in 1:Nq
        DELTA_rt_tmp = zeros(ComplexF64, 2 * Nw, No, No)
        for jj in 1:Nco, ii in 1:Nco
            # Δ_13(r,τ) = T/N Σ_24 V_1234(r,τ) F_24(r,τ)
            DELTA_rt_tmp[:, i1_list[ii], j2_list[jj]] .+= CHI_view[:, q, ii, jj] .* DELTA_view[:, q, i2_list[ii], j1_list[jj]]
        end
        DELTA_view[:, q, :, :] .= -DELTA_rt_tmp .* coef
    end
    rt2kw!(DELTA, FFT_plan)
end

読み方

  • kw2rt!(DELTA) — F を (k,iω)→(r,τ) に変換。CHI（Vpair）は呼び出し側で既に (r,τ)。
  • DELTA_rt_tmp[:, i1, j2] .+= CHI[ii,jj] .* F[i2, j1] — 軌道の配線が calc_SIGMA! と違う（出力 i1,j2／入力 i2,j1）。異常項の頂点構造を反映。
  • DELTA_view[:,q,:,:] .= -DELTA_rt_tmp .* coef — マイナス符号付きで Δ=-T/N Σ VpairF。coef=T/N。
  • rt2kw!(DELTA) — 新しい Δ(r,τ) を (k,iω) に戻す。
  • ここは @threads ではなく逐次 for q（calc_SIGMA! は並列だった点と対照的）。
calc_SIGMA! との対比： どちらも「V(r,τ)·(グリーン関数)(r,τ) の積 → FFT で戻す」畳み込みだが、 通常自己エネルギーは Σ=+T/N Σ VeffG、ギャップは Δ=-T/N Σ VpairF と符号と添字の組み方が異なる。畳み込みの「向き」の違いに注意。
関連：calc_GREEN_anomalous!（入力 F）／ calc_PairPotential!（Vpair）／ calc_SIGMA!（対になる通常項）
Eliashberg_pipeline!▶ 線形写像 Δ→Δ の最大固有値 λ を Lanczos / べき乗法で解く（駆動関数）
Eliashberg_pipeline!(DELTA, G, CHI, U_spin, U_charge, temperature, FFT_plan; solver="Lanczos", howmany=1, …) → (λ, φ)

概要

線形化 Eliashberg 方程式を Δ→Δ の線形写像とみなし、その最大固有値 λ と固有ギャップ φ を解く駆動関数。まず Vpair を用意（calc_PairPotential! → kw2rt! で (r,τ) へ）、写像本体 _matvec! は Δ→(calc_GREEN_anomalous!)→F→(calc_DELTA!)→Δ。Lanczos（ARPACK eigs）または PowerMethod（べき乗法）で最大固有値を求める。λ=1 が Tc。

コード

eliashberg.jl · Eliashberg_pipeline!
function Eliashberg_pipeline!(DELTA, G, CHI, U_spin, U_charge, temperature, FFT_plan;
        mask_inds=nothing, spin_symmetry="singlet", projection_func=nothing,
        solver="Lanczos", howmany=1, Lanczos_ncv=10, Lanczos_maxiter=100, Lanczos_which=:LR,
        Power_maxiter=1000, tol=1e-5, return_half=true)
    shape = size(DELTA)
    Nw = shape[1] ÷ 2
    No = shape[5]
    mask_inds = (mask_inds === nothing) ? (1:No*No) : mask_inds
    Nco = size(CHI)[5]
    Nco == length(mask_inds) || throw(ArgumentError("Argument mask_inds is missing!"))

    calc_PairPotential!(CHI, U_spin, U_charge; spin_symmetry=spin_symmetry)  # chi0 -> Vpair(k,iν)
    kw2rt!(CHI, FFT_plan)                                                    # Vpair(k,iν) -> Vpair(r,τ)

    # 線形化 Eliashberg 演算子 Δ -> Δ
    function _matvec!(DELTA)
        DELTA = Array(reshape(DELTA, shape...))
        calc_GREEN_anomalous!(DELTA, G)                                      # Δ -> F
        calc_DELTA!(DELTA, CHI, temperature, FFT_plan; mask_inds=mask_inds)  # F, Vpair -> Δ
        projection_func === nothing || projection_func(DELTA)
        return vec(DELTA)
    end

    function _power_method!(DELTA; shift=0)
        λ_old = 0.0 + 0.0im
        for iter in 1:Power_maxiter
            DELTA ./= norm(DELTA)
            DELTA_old = copy(DELTA)
            DELTA = _matvec!(DELTA)
            shift == 0 || (DELTA .-= shift .* DELTA_old)
            λ = vec(DELTA_old)' * vec(DELTA)
            dλ = abs(real(λ - λ_old))
            println(@sprintf("Iter %4d: λ=%.10f  Δλ=%.3e", iter, real(λ + shift), dλ))
            if isapprox(λ, λ_old, rtol=tol)
                log_banner("ELIASHBERG CONVERGED")
                λ += shift
                println(@sprintf("Iter=%d  λ=%.10f", iter, real(λ)))
                break
            elseif iter == Power_maxiter
                log_banner("ELIASHBERG NOT CONVERGED")
                println(@sprintf("Reached Power_maxiter=%d  last λ=%.10f", Power_maxiter, real(λ + shift)))
            end
            λ_old = λ
        end
        return λ, DELTA
    end

    if solver == "Lanczos"
        log_section("Lanczos/ARPACK")
        A = LinearMap{ComplexF64}(_matvec!, prod(shape); ishermitian=true)
        λ, φ, nconv, niter, nmult = eigs(A; nev=howmany, ncv=Lanczos_ncv, which=Lanczos_which, maxiter=Lanczos_maxiter, tol=tol, v0=vec(DELTA))
    elseif solver == "PowerMethod"
        log_section("PowerMethod")
        howmany == 1 || throw(ArgumentError("Error: Argument howmany must be 1!"))
        DELTA = vec(DELTA)
        DELTA_init = vec(DELTA)
        λ, φ = _power_method!(DELTA)
        if real(λ) < 0   # 絶対値最大が負ならシフトして再計算
            DELTA .= DELTA_init
            φ = nothing; DELTA_init = nothing; GC.gc()
            λ, φ = _power_method!(DELTA; shift=λ)
        end
    else
        throw(ArgumentError("solver must be either \"Lanczos\" or \"PowerMethod\"."))
    end

    φ = reshape(φ, shape..., howmany)
    return return_half ? (λ, φ[1:Nw, :, :, :, :, :, :]) : (λ, φ)
end

読み方

  • calc_PairPotential!(CHI, …) → kw2rt!(CHI) — 反復前に Vpair を作って (r,τ) にしておく（毎回変わらないので 1 度だけ）。
  • _matvec! — 写像 Δ→Δ の本体。reshape で 6 階に戻し、calc_GREEN_anomalous!（Δ→F）→ calc_DELTA!（F→Δ）→ 任意の projection_func（対称性射影）→ vec で 1 次元に。
  • Lanczos： LinearMap{ComplexF64}(_matvec!, …; ishermitian=true) で行列を作らず写像として ARPACK eigs に渡す。which=:LR（実部最大）で λ に収束。演算子はエルミートとして扱う。
  • PowerMethod： DELTA ./= norm で正規化しつつ反復、λ = ⟨Δold, AΔold⟩（Rayleigh 商）。howmany==1 限定。
  • if real(λ) < 0 … _power_method!(DELTA; shift=λ) — べき乗法は絶対値最大に収束するので、それが負の固有値だったらスペクトルシフト A-λI で正の最大実固有値を取り直す。
  • return_half ? φ[1:Nw, …] : φ — 既定では固有ギャップの正周波数半分だけ返す（負側は対称性で決まる）。
  • log_banner/log_section — 整形出力用のヘルパ（別ファイル定義）。
λ の意味： λ=1 でギャップ方程式が自明でない解を持つ＝超伝導転移温度 Tc。温度を下げながら λ(T) を追い、λ=1 を横切る T が Tc。λ が大きいほど対形成が強く不安定（高い Tc）。固有ギャップ φ の k 依存がギャップの対称性（s±・d 波…）を与える。
Lanczos と PowerMethod： Lanczos（ARPACK）は複数固有値（howmany>1）や縮退の分離に強く既定。PowerMethod は最大 1 個だけで、負の主固有値にはシフトで対処する簡便版。どちらも行列を陽に作らず _matvec! の反復で解く（メモリを食わない）。
関連：calc_PairPotential!・calc_GREEN_anomalous!・calc_DELTA!（写像の部品）／ init_DELTA_band!（初期 Δ）
全体の流れ： FLEX で収束させた G・χ0 を用意 → init_DELTA_band! で対称性を指定した初期 Δ → Eliashberg_pipeline! が calc_PairPotential! で Vpair を作り、 Δ→F→Δ（calc_GREEN_anomalous!→calc_DELTA!）の反復で最大固有値 λ と固有ギャップ φ を得る。 λ=1 となる温度が Tc。異常項の k↔-k・conj と † の使い分けがこのファイルの肝。
