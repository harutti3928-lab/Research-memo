Anomalous — 超伝導ギャップと異常項の基底変換

— 超伝導ギャップ Δ の初期化と、k と -k が絡む異常項のバンド↔軌道基底変換  |  関数名をクリックで詳細 —

超伝導の異常項（Cooper 対＝k と -k を結ぶ量）を扱うファイル。線形化 Eliashberg 方程式を解く前に、ギャップ関数 Δ(k,iω) の初期値を対称性（s±・d 波・ランダム）を指定して用意し （init_DELTA_band!）、SCF/固有値反復のたびに必要になる軌道基底 ↔ バンド基底の変換 （orb2band_anomalous! / band2orb_anomalous!）を提供する。通常項（Green 関数など）が U(k) … U†(k) と同じ k で挟むのに対し、異常項は片脚が -k になる （U†(k) … conj(U(-k))）のが肝。Nonint の UNITARY と fix_unitary_gauge! がそのまま土台になる。

このページの規約：k → -k のインデックス写像は [1; N:-1:2] （k=0 は自分自身、残りは反転）で、fftfreq 並びの運動量を符号反転させる定番。 周波数軸は 2Nw（松原周波数の全域）、ギャップはバンド基底で対角（軌道の非対角は 0）。 singlet / triplet で iω 折り返しの符号を ±1 に切り替える。軌道ループの ブロック順は for j, for i（j が外, i が内）で他ファイルと揃える。

# anomalous.jl
# 超伝導ギャップ Δ の初期化と、異常項（k と -k が絡む量）のバンド↔軌道基底変換。

using LinearAlgebra
using Base.Threads
using Random
_check_arr_shape▶ 配列の階数（5/6/7）から (NW, Nqx, Nqy, Nqz, M, Nv) を統一的に取り出す内部ヘルパ
_check_arr_shape(arr::Array) → (NW, Nqx, Nqy, Nqz, M, Nv)

概要

入力配列の次元数で場合分けし、周波数点数 NW・k メッシュ・軌道数 M・ 固有ベクトル本数 Nv を共通の形で返す小さなヘルパ。5 次元（ENERGY 形＝ 周波数なし）、6 次元（iω 分解あり）、7 次元（Eliashberg 出力＝末尾に Nv）の 3 通りを受け付け、以降の変換関数がどの形でも同じコードで回せるようにする。

コード

anomalous.jl · _check_arr_shape
function _check_arr_shape(arr::Array)
    shape = size(arr)
    if length(shape) == 5      # ENERGY 形
        Nqx, Nqy, Nqz, M, _ = shape
        NW = 1; Nv = 1
    elseif length(shape) == 6
        NW, Nqx, Nqy, Nqz, M, _ = shape
        Nv = 1
    elseif length(shape) == 7  # Eliashberg 出力形
        NW, Nqx, Nqy, Nqz, M, _, Nv = shape
    else
        throw(ArgumentError("Dimension of arr must be 5, 6, or 7."))
    end
    return NW, Nqx, Nqy, Nqz, M, Nv
end

読み方

  • 関数名頭の _ は Julia の慣習で 「内部用（外から呼ばない）ヘルパ」を表す。
  • length(shape) == 5（ENERGY 形）— [kx,ky,kz,i,j]。周波数も Nv も無いので NW=1, Nv=1 を補う。
  • == 6 — [iw,kx,ky,kz,i,j]。周波数分解あり、Nv=1。
  • == 7（Eliashberg 出力形）— [iw,kx,ky,kz,i,j,v]。末尾 v は固有ベクトル（ギャップ候補）の本数 Nv。
  • いずれも軌道の 2 軸のうち片方は _ で捨てる（i,j が同じ M）。
  • それ以外は ArgumentError で即停止。想定外の形を静かに通さない防御。
なぜ必要か： orb2band_anomalous! / band2orb_anomalous! は「バンド計算の ENERGY」から 「Eliashberg の Nv 本のギャップ」まで色々な形の配列を受け取る。ここで (NW, …, Nv) に正規化しておくことで、 本体側は reshape(arr, NW, Nq, M, M, Nv) の一本道で書ける。
関連：orb2band_anomalous! / band2orb_anomalous!（この形情報を使う）
init_DELTA_band!▶ バンド基底で初期ギャップ Δ0(k,iω) を対称性指定で作る（対角のみ・最後に規格化）
init_DELTA_band!(DELTA::Array{ComplexF64,6}; symmetry="random", spin_symmetry="singlet", seed=42) # 破壊的

概要

線形化 Eliashberg 方程式（固有値問題）の初期ギャップをバンド基底で作る。バンド対角成分 (i,i) のみに値を入れ（軌道非対角は 0）、symmetry で k 依存の フォームファクタ（random / spm / dx2-y2 / dxy）を選ぶ。 spin_symmetry が singlet/triplet かで iω 折り返しの符号を ±1 に変える。最後に全体を Frobenius ノルムで規格化する。

コード

anomalous.jl · init_DELTA_band!
function init_DELTA_band!(DELTA::Array{ComplexF64,6}; symmetry::String="random", spin_symmetry::String="singlet", seed::Int=42)
    Nw2, Nqx, Nqy, Nqz, No, _ = size(DELTA)
    Nw = Nw2 ÷ 2
    Nq = Nqx * Nqy * Nqz
    DELTA_view = reshape(DELTA, 2 * Nw, Nq, No, No)

    Random.seed!(seed)
    sign = spin_symmetry == "singlet" ? 1.0 :
           spin_symmetry == "triplet" ? -1.0 :
           throw(ArgumentError("spin_symmetry must be either \"singlet\" or \"triplet\"."))

    x_, y_, z_ = map(N -> [1; N:-1:2], (Nqx, Nqy, Nqz))
    xyz_ind2sub = CartesianIndices(Array{Int}(undef, Nqx, Nqy, Nqz))
    for j in 1:No, i in 1:No
        if i != j
            @threads for q in 1:Nq
                DELTA_view[:, q, i, j] .= 0
            end
            continue
        end
        @threads for q in 1:Nq
            x, y, z = Tuple(xyz_ind2sub[q])
            if symmetry == "random"
                xx, yy, zz = x_[x], y_[y], z_[z]
                DELTA[1:Nw, x, y, z, i, i] .= rand(Float64, Nw) .+ 0im
                @views DELTA[2*Nw:-1:Nw+1, xx, yy, zz, i, i] .= sign .* conj(DELTA[1:Nw, x, y, z, i, i])
            else
                if symmetry == "spm"
                    val = cos(2π * (x - 1) / Nqx) * cos(2π * (y - 1) / Nqy) + 0im
                elseif symmetry == "dx2-y2"
                    val = (cos(2π * (x - 1) / Nqx) - cos(2π * (y - 1) / Nqy)) * cos(2π * (x - 1) / Nqx) * cos(2π * (y - 1) / Nqy) + 0im
                elseif symmetry == "dxy"
                    val = sin(2π * (x - 1) / Nqx) * sin(2π * (y - 1) / Nqy) + 0im
                else
                    throw(ArgumentError("symmetry must be one of [\"spm\", \"dx2-y2\", \"dxy\"]."))
                end
                DELTA[:, x, y, z, i, i] .= val
            end
        end
    end
    DELTA_norm = norm(DELTA)
    @threads for i in eachindex(DELTA)
        DELTA[i] /= DELTA_norm
    end
end

読み方

  • Nw2, …, No, _ = size(DELTA) / Nw = Nw2 ÷ 2 — 周波数軸は 2Nw（全松原窓）。Nw はその半分（正周波数側の本数）。÷ は整数除算。
  • DELTA_view = reshape(DELTA, 2*Nw, Nq, No, No) — k を 1 本に潰したビュー。軌道非対角を 0 埋めするときに使う。
  • Random.seed!(seed) — random 初期化を再現可能にするための乱数シード固定。
  • sign = singlet ? 1.0 : triplet ? -1.0 : throw(...) — スピン一重項/三重項で符号を決める三項。ここが後段の iω 折り返しの ± になる。
  • x_, y_, z_ = map(N -> [1; N:-1:2], …) — k → -k のインデックス写像。[1, N, N-1, …, 2] で、x_[x] が「x 番目の kx に対する -kx の番号」を返す。
  • xyz_ind2sub = CartesianIndices(...) — 線形 q を (x,y,z) 添字に戻す索引。
  • for j, for i … if i != j … DELTA_view[:,q,i,j] .= 0; continue — バンド対角のみギャップを入れ、軌道非対角は 0。バンド基底ではギャップは対角という前提。
  • random 分岐： DELTA[1:Nw, k, i,i] .= rand(Nw) で正周波数側を乱数で埋め、DELTA[2Nw:-1:Nw+1, -k, i,i] .= sign · conj(…) で負周波数側かつ -k を「±複素共役」で貼る。これは異常項の対称性 Δ-k(-iω) = ± Δk(iω)* を手で課す操作。2Nw:-1:Nw+1 の逆順が 1:Nw と iω ↔ -iω で対応する。
  • 解析フォーム分岐： spm=cos kx cos ky、dx2-y2=(cos kx - cos ky)·cos kx cos ky、dxy=sin kx sin ky（k = 2π(x-1)/N）。こちらは周波数によらず DELTA[:, k, i,i] .= val で全周波数に同じ形を入れる。
  • DELTA_norm = norm(DELTA) → @threads … DELTA[i] /= DELTA_norm — 全体を Frobenius ノルムで割り ‖Δ‖ = 1 に規格化。固有値反復（べき乗法）の種は正規化しておく必要があるため。
符号と −k の折り返しは random 専用： 解析フォーム（spm/dx2-y2/dxy）は k 依存が既に定符号のパリティを持つので、sign と -k 反転は使わない。乱数初期化のときだけ、 Δ-k(-iω) = ± Δk(iω)* を明示的に貼って対称性を担保する。spin_symmetry の綴り違いは 即 throw になる。
関連：orb2band_anomalous!（この Δ をバンド↔軌道で行き来）／ Eliashberg のギャップ方程式（この Δ を種に λ を反復）
orb2band_anomalous!▶ 異常項の軌道→バンド変換 U†(k) φ conj(U(-k))（in-place）
orb2band_anomalous!(arr::Array{ComplexF64}, UNITARY::Array{ComplexF64,5}) # 破壊的：軌道基底 → バンド基底

概要

異常項 arr を軌道基底からバンド基底へ変換する。各 k・各周波数 w の M×M ブロックに対し φband(k) = U†(k) · φorb(k) · conj(U(-k)) を掛ける。 通常項と違い右脚が -k の共役になるのが異常項の特徴。k についてスレッド並列。

コード

anomalous.jl · orb2band_anomalous!
function orb2band_anomalous!(arr::Array{ComplexF64}, UNITARY::Array{ComplexF64,5})
    NW, Nqx, Nqy, Nqz, M, Nv = _check_arr_shape(arr)
    Nq = Nqx * Nqy * Nqz
    arr_view = reshape(arr, NW, Nq, M, M, Nv)

    x_, y_, z_ = map(N -> [1; N:-1:2], (Nqx, Nqy, Nqz))
    xyz_ind2sub = CartesianIndices(Array{Int}(undef, Nqx, Nqy, Nqz))
    for v in 1:Nv
        @threads for q in 1:Nq
            x, y, z = Tuple(xyz_ind2sub[q])
            xx, yy, zz = x_[x], y_[y], z_[z]
            arr_local = Array{ComplexF64}(undef, M, M)
            U_dag_k = UNITARY[x, y, z, :, :]'
            U_minus_k_conj = conj(UNITARY[xx, yy, zz, :, :])
            for w in 1:NW
                @views arr_local .= arr_view[w, q, :, :, v]
                arr_view[w, q, :, :, v] .= U_dag_k * arr_local * U_minus_k_conj
            end
        end
    end
end

読み方

  • NW, …, Nv = _check_arr_shape(arr) — 5/6/7 次元のどれでも受け、統一形に。arr_view は [NW, Nq, M, M, Nv] のビュー。
  • x_,y_,z_ と xyz_ind2sub — init_DELTA_band! と同じ k → -k 写像・索引。xx,yy,zz が -k の添字。
  • for v … @threads for q — 固有ベクトル本数 v の外ループ、k をスレッド並列。各 q は独立ブロックなので競合しない。
  • U_dag_k = UNITARY[x,y,z,:,:]' — k の固有ベクトル行列の随伴（共役転置） U†(k)。
  • U_minus_k_conj = conj(UNITARY[xx,yy,zz,:,:]) — -k の固有ベクトル行列の要素ごとの複素共役 conj(U(-k))。
  • arr_local .= arr_view[w,q,:,:,v] → arr_view[…] .= U_dag_k * arr_local * U_minus_k_conj — ブロックを一時退避してから U†(k) φ conj(U(-k)) でその場更新。arr_local は上書き前の値を保持するための作業行列。
なぜ両脚で U が違うのか： 異常項は k と -k（対を組む 2 粒子）を結ぶので、左脚は k、右脚は -k の変換を使う。しかも右脚は「生成×生成」に対応して U(k) ではなく conj(U(-k)) が入る。 通常項（U(k) … U†(k)）との違いはここ。k と -k の固有ベクトルの相対位相（ゲージ）が 揃っていないと連続性が崩れるので、事前に fix_unitary_gauge! でゲージを固定しておく。
関連：band2orb_anomalous!（逆変換）／ Nonint の UNITARY・fix_unitary_gauge!
band2orb_anomalous!▶ 異常項のバンド→軌道変換 U(k) φ Uᵀ(-k)（orb2band_anomalous! の逆・in-place）
band2orb_anomalous!(arr::Array{ComplexF64}, UNITARY::Array{ComplexF64,5}) # 破壊的：バンド基底 → 軌道基底

概要

orb2band_anomalous! の逆変換。各ブロックに φorb(k) = U(k) · φband(k) · UT(-k) を掛けて軌道基底へ戻す。 構造は順変換と同じで、掛ける行列が U†(k)→U(k)、conj(U(-k))→UT(-k) に替わるだけ。

コード

anomalous.jl · band2orb_anomalous!
function band2orb_anomalous!(arr::Array{ComplexF64}, UNITARY::Array{ComplexF64,5})
    NW, Nqx, Nqy, Nqz, M, Nv = _check_arr_shape(arr)
    Nq = Nqx * Nqy * Nqz
    arr_view = reshape(arr, NW, Nq, M, M, Nv)

    x_, y_, z_ = map(N -> [1; N:-1:2], (Nqx, Nqy, Nqz))
    xyz_ind2sub = CartesianIndices(Array{Int}(undef, Nqx, Nqy, Nqz))
    for v in 1:Nv
        @threads for q in 1:Nq
            x, y, z = Tuple(xyz_ind2sub[q])
            xx, yy, zz = x_[x], y_[y], z_[z]
            arr_local = Array{ComplexF64}(undef, M, M)
            U_local = copy(UNITARY[x, y, z, :, :])
            U_minus_k_t_local = copy(transpose(UNITARY[xx, yy, zz, :, :]))
            for w in 1:NW
                @views arr_local .= arr_view[w, q, :, :, v]
                arr_view[w, q, :, :, v] .= U_local * arr_local * U_minus_k_t_local
            end
        end
    end
end

読み方

  • 枠組みは orb2band_anomalous! と完全に同型（形の正規化・k→-k 写像・並列化まで同じ）。
  • U_local = copy(UNITARY[x,y,z,:,:]) — k の U(k)（左脚）。copy で連続な行列にしておく。
  • U_minus_k_t_local = copy(transpose(UNITARY[xx,yy,zz,:,:])) — -k の転置 UT(-k)（右脚）。transpose は遅延ラッパなので copy で実体化する。
  • arr_view[…] .= U_local * arr_local * U_minus_k_t_local — U(k) φ UT(-k) でその場更新。
厳密に逆になる理由： U はユニタリ（U U† = I）なので、左脚は U(k) U†(k) = I。 右脚も conj(U(-k)) · UT(-k) = conj(U(-k) U†(-k)) = I。よって band2orb ∘ orb2band = 恒等。transpose（UT）と adjoint（U†、コード上は '）は 共役の有無で別物なので取り違え注意。
関連：orb2band_anomalous!（順変換）／ Nonint の UNITARY
全体の流れ： Nonint で H(k) を対角化して UNITARY・ゲージ固定 → init_DELTA_band! でバンド基底の初期ギャップ Δ0 を用意 → Eliashberg 反復の各ステップで band2orb_anomalous!／orb2band_anomalous! により 有効相互作用（軌道基底）とギャップ（バンド基底）を行き来させ、固有値 λ が 1 に達する Tc を探す。異常項が k/-k を結ぶこと、そのため U の 相対ゲージが効くことが、このファイル全体を貫く注意点。
