6. Plot Eliashberg — 超伝導ギャップ φ(k)

— ギャップ φ を軌道/バンド表示（Re・abs）とフェルミ面重ねで描く。TR ゲージ固定込み  |  関数名をクリックで詳細 —

Eliashberg 結果の超伝導ギャップ φ(k) を可視化する。 eliashberg_result/{channel}/{lambda, phi_iwpm1_mode1to2} を読み、 チャネル(singlet/triplet)・mode ごとに +iω1 スライスのギャップを 4種（軌道 Re/abs、バンド Re/abs、バンド対角+FS）で描く。φ は軌道基底で保存されており、 バンド表示は異常項変換 φband(k)=U†(k) φorb(k) conj(U(-k)) で得る（U(k),U(-k) の相対位相をそろえる時間反転ゲージ固定を先に適用）。

使い方 julia --project=. 6_plot_eliashberg.jl（HDF5 の小スライスだけで動く）。 入力 simulation.h5 の eliashberg_result。 出力（Eliashberg_results/{channel}/mode{m}/） gap_orb_real.png・gap_orb_abs.png・gap_band_real.png・gap_band_diag_fs.png・gap_band_abs.png。 依存 functions/nonint.jl（fix_unitary_gauge! 等）・ functions/anomalous.jl（orb2band_anomalous!）・ functions/kplot.jl（bz_map, fix_unitary_time_reversal_gauge!, global_phase_fix_mode!）・ PyPlot(Agg)。
simulation.h5→ φ スライス読み込み→ ゲージ固定 (U(1) + 時間反転)→ 位相固定 → orb2band 変換 → 位相固定→ 4種プロット→ Eliashberg_results/*.png

概要

開いた HDF5 ハンドル f から、描画に必要なメタ情報をまとめて読み出し NamedTuple で返す。分割数 Nqx/Nqy/Nqz・軌道数 Norb・格子型・ 逆格子ベクトル b1,b2・非相互作用バンド ENERGY_diag・化学ポテンシャル mu0・バンド変換用の UNITARY を取り出す。UNITARY は 相互作用込みの flex_result/UNITARY_corrected があればそれを優先し、 なければ非相互作用の nonint/diag/UNITARY を使う。

コード

6_plot_eliashberg.jl · _read_ctx
function _read_ctx(f)
    p = f["params"]
    Nqx = Int(read(p["Nqx"])); Nqy = Int(read(p["Nqy"])); Nqz = Int(read(p["Nqz"])); Norb = Int(read(p["Norb"]))
    gl = f["nonint/lattice"]
    lattice_type = String(read(gl["lattice_type"]))
    b1 = _as3(read(gl["b1"])); b2 = _as3(read(gl["b2"]))
    ENERGY_diag = read(f["nonint/diag/ENERGY_diag"])
    mu0 = Float64(read(f["nonint/chem/mu0"]))
    # バンド変換用のユニタリ（相互作用込みがあればそれを優先）
    UNITARY = haskey(f, "flex_result") && haskey(f["flex_result"], "UNITARY_corrected") ?
        read(f["flex_result/UNITARY_corrected"]) : read(f["nonint/diag/UNITARY"])
    return (Nqx=Nqx, Nqy=Nqy, Nqz=Nqz, Norb=Norb, lattice_type=lattice_type,
            b1=b1, b2=b2, ENERGY_diag=ENERGY_diag, mu0=mu0, UNITARY=UNITARY)
end

読み方

  • p = f["params"] → Nqx/Nqy/Nqz/Norb — メッシュ寸法と軌道数を Int にして取る。以降の bz_map や配列スライスの形を決める基礎量。
  • lattice_type・b1=_as3(...)・b2=_as3(...) — bz_map が BZ 境界を描くのに使う格子情報。_as3 はベクトルを 3 成分に整える補助（_as3）。
  • ENERGY_diag = read(f["nonint/diag/ENERGY_diag"]) — 非相互作用バンド。フェルミ面（E-μ=0 の等高線）を重ねる gap_band_diag_fs で使う。
  • mu0 = read(f["nonint/chem/mu0"]) — 非相互作用の化学ポテンシャル。FS を ENERGY_diag - mu0 の 0 等高線として引くための基準。
  • UNITARY = haskey(...) ? UNITARY_corrected : nonint/diag/UNITARY — 相互作用込みのユニタリを優先。三項演算で flex_result/UNITARY_corrected があればそれ、なければ非相互作用版。バンド基底への異常項変換に使う。
関連：fix_unitary_gauge!（読んだ UNITARY のゲージを固定）／ _as3（b1,b2 整形）／ ギャップを解く 3_run_eliashberg.jl（eliashberg_result を書く側）
plot_phi_matrix▶ Norb×Norb 行列プロット（軌道 or バンド、real=bwr 対称／abs=magma）
plot_phi_matrix(ctx, phi, iw, mode; component::Symbol, out_png, suptitle_str) # PNG を保存

概要

ギャップ φ の Norb×Norb 成分（非対角込み）を、各 (i,j) を 1 枚のサブプロットにした 行列レイアウトで描く。component=:real なら実部を対称カラースケール bwr （vmin=-vmax）で、component=:abs なら絶対値を magma（vmin=0）で塗る。 各 (i,j) の 2 次元 (Nqx,Nqy) データを bz_map(...; supercell_range=2, mask_to_bz=false) でタイル展開し、BZ 境界を破線で重ねる。軌道基底 phi_orb・バンド基底 phi_band の どちらにも同じ関数を使う（渡す配列が違うだけ）。

コード

6_plot_eliashberg.jl · plot_phi_matrix（抜粋：マップ生成とカラースケール）
function plot_phi_matrix(ctx, phi, iw, mode; component::Symbol, out_png, suptitle_str)
    Nqx, Nqy, Norb = ctx.Nqx, ctx.Nqy, ctx.Norb
    maps = Matrix{Any}(undef, Norb, Norb)
    allv = Float64[]
    for i in 1:Norb, j in 1:Norb
        d = @view phi[iw, :, :, 1, i, j, mode]           # (Nqx,Nqy)
        data = component === :abs ? abs.(d) : real.(d)
        m = bz_map(Float64.(data), Nqx, Nqy;
            b1=ctx.b1, b2=ctx.b2, lattice_type=ctx.lattice_type,
            axis_unit=:pi, supercell_range=2, mask_to_bz=false)
        maps[i, j] = m
        append!(allv, filter(isfinite, vec(m.Z)))
    end
    if component === :abs
        vmax = isempty(allv) ? 1.0 : maximum(allv); vmax = vmax > 0 ? vmax : 1.0
        vmin = 0.0; cmap = "magma"
    else
        vmax = isempty(allv) ? 1.0 : maximum(abs.(allv)); vmax = vmax > 0 ? vmax : 1.0
        vmin = -vmax; cmap = "bwr"
    end

    fig, axs = subplots(Norb, Norb, figsize=(2.9 * Norb + 1.0, 2.7 * Norb), squeeze=false)
    local pc
    for i in 1:Norb, j in 1:Norb
        ax = axs[i, j]; m = maps[i, j]
        pc = ax.pcolormesh(m.X, m.Y, m.Z, cmap=cmap, vmin=vmin, vmax=vmax, shading="auto")
        ax.plot(m.bx, m.by, color="k", linestyle="--", linewidth=0.7, alpha=0.7)
        ax.set_aspect("equal"); ax.set_xlim(-1.5, 1.5); ax.set_ylim(-1.5, 1.5)
        ax.set_title(@sprintf("(%d,%d)", i, j), fontsize=9)
        ax.tick_params(labelsize=7)
        i == Norb ? ax.set_xlabel("k_x/π", fontsize=8) : ax.set_xticklabels([])
        j == 1 ? ax.set_ylabel("k_y/π", fontsize=8) : ax.set_yticklabels([])
    end
    fig.subplots_adjust(left=0.06, right=0.88, bottom=0.08, top=0.90, wspace=0.15, hspace=0.25)
    cax = fig.add_axes([0.90, 0.12, 0.02, 0.74])
    fig.colorbar(pc, cax=cax)
    fig.suptitle(suptitle_str, fontsize=13)
    savefig(out_png, dpi=180, bbox_inches="tight")
    close(fig)
    println("Saved: $out_png")
end

読み方

  • d = @view phi[iw, :, :, 1, i, j, mode] — 7 次元配列 (2,Nqx,Nqy,Nqz,Norb,Norb,nmodes) から、周波数 iw（=1=+iω1）・kz=1・軌道ペア (i,j)・mode を固定した (Nqx,Nqy) スライス。
  • data = component === :abs ? abs.(d) : real.(d) — abs なら絶対値、real なら実部。プロット種を component シンボル 1 つで切り替える。
  • bz_map(...; axis_unit=:pi, supercell_range=2, mask_to_bz=false) — (Nqx,Nqy) を k/π 軸のメッシュにタイル展開し、BZ 境界線 m.bx,m.by も返す。mask_to_bz=false で BZ 外も塗り、周期を見せる（bz_map）。
  • allv にすべての有限値を集めて全成分共通の vmax を決める — 成分ごとに色スケールがバラバラにならないよう、行列全体で 1 つの vmax。
  • real は対称 vmin=-vmax, cmap="bwr"（白=ゼロで符号が見える）／abs は片側 vmin=0, cmap="magma"。
  • subplots(Norb, Norb; squeeze=false) — 常に 2 次元の axs にして axs[i,j] で回せるようにする。外周だけ軸ラベル、内側は set_xticklabels([]) で間引く。
  • i == Norb ? ax.set_xlabel(...) : ax.set_xticklabels([]) — 最下行だけ k_x/π ラベル、j==1 の左端列だけ k_y/π ラベル。三項演算でレイアウトを制御。
  • 右端に共有カラーバー（add_axes+colorbar）→ savefig(dpi=180) → close(fig)。
関連：bz_map（各成分のタイル展開）／ plot_phi_band_diag_fs（対角＋FS 版）
plot_phi_band_diag_fs▶ バンド対角 Re[φband]bb を 1×Norb で描き、非相互作用フェルミ面を重ねる
plot_phi_band_diag_fs(ctx, phi_band, iw, mode; out_png, suptitle_str, vscale) # PNG を保存

概要

バンド基底ギャップの対角成分 Re[φband(k)]bb（バンド内ギャップ）を 1×Norb の横並びで描き、各パネルに非相互作用フェルミ面（全バンド）を同じメッシュ上に重ねる。 カラースケールは自動最大ではなく引数 vscale（バンドギャップ全体の |φ| 最大）で固定する。 こうすると、対角がインターバンド相殺で ≈0 のバンドでも「白（=ゼロ）」として正しく表示され、 重ねた FS 等高線がそのまま読める。

コード

6_plot_eliashberg.jl · plot_phi_band_diag_fs（抜粋：対角マップ・FS・vscale）
function plot_phi_band_diag_fs(ctx, phi_band, iw, mode; out_png, suptitle_str, vscale)
    Nqx, Nqy, Norb = ctx.Nqx, ctx.Nqy, ctx.Norb
    diagmaps = Vector{Any}(undef, Norb)
    for b in 1:Norb
        data = real.(@view phi_band[iw, :, :, 1, b, b, mode])
        m = bz_map(Float64.(data), Nqx, Nqy;
            b1=ctx.b1, b2=ctx.b2, lattice_type=ctx.lattice_type,
            axis_unit=:pi, supercell_range=2, mask_to_bz=false)
        diagmaps[b] = m
    end
    vmax = vscale > 0 ? vscale : 1.0; vmin = -vmax

    # 非相互作用 FS（全バンド）を同じメッシュ上にタイル+マスクして重ねる
    fsmaps = Vector{Any}(undef, Norb)
    for bb in 1:Norb
        E = Float64.(ctx.ENERGY_diag[:, :, 1, bb]) .- ctx.mu0
        fsmaps[bb] = bz_map(E, Nqx, Nqy;
            b1=ctx.b1, b2=ctx.b2, lattice_type=ctx.lattice_type,
            axis_unit=:pi, supercell_range=2, mask_to_bz=false)
    end

    fig, axs = subplots(1, Norb, figsize=(4.6 * Norb, 4.2), squeeze=false)
    for b in 1:Norb
        ax = axs[1, b]; m = diagmaps[b]
        pc = ax.pcolormesh(m.X, m.Y, m.Z, cmap="bwr", vmin=vmin, vmax=vmax, shading="auto")
        ax.plot(m.bx, m.by, color="k", linestyle="--", linewidth=0.9, alpha=0.8)
        for bb in 1:Norb
            mE = fsmaps[bb]
            ax.contour(mE.X, mE.Y, mE.Z, levels=[0.0], colors="k", linewidths=0.9, alpha=0.45)
        end
        ax.set_aspect("equal"); ax.set_xlim(-1.5, 1.5); ax.set_ylim(-1.5, 1.5)
        ax.set_title(@sprintf("band %d", b), fontsize=11)
        ax.set_xlabel("k_x/π", fontsize=9)
        b == 1 && ax.set_ylabel("k_y/π", fontsize=9)
        colorbar(pc, ax=ax, fraction=0.046, pad=0.04)
    end
    fig.suptitle(suptitle_str, fontsize=13)
    tight_layout()
    savefig(out_png, dpi=200, bbox_inches="tight")
    close(fig)
    println("Saved: $out_png")
end

読み方

  • data = real.(@view phi_band[iw, :, :, 1, b, b, mode]) — 対角 (b,b) だけ取り出す。これがバンド b 内の超伝導ギャップ。
  • vmax = vscale > 0 ? vscale : 1.0; vmin = -vmax — 色スケールを外から固定。各バンドの自動最大を使わない（下の tip 参照）。
  • E = ctx.ENERGY_diag[:, :, 1, bb] .- ctx.mu0 → bz_map(E, ...) — 各バンド bb の E-μ を同じメッシュにタイル展開。contour(..., levels=[0.0]) の 0 等高線がフェルミ面。
  • 内側の for bb in 1:Norb — 全バンドの FS を各パネルに重ねる（対角ギャップとフェルミ面の位置関係を一目で見るため）。
  • b == 1 && ax.set_ylabel(...) — 左端パネルだけ k_y/π ラベル。&& の短絡評価を「条件付き実行」に使う Julia 定石。
  • colorbar(pc, ax=ax, fraction=0.046, pad=0.04) — 各パネルに個別カラーバー → savefig(dpi=200)。
vscale 固定の設計意図： バンド対角 φband,bb はインターバンド相殺で ≈0 になることがある。 ここで各バンドの自動最大でスケールすると、ほぼゼロのノイズが色いっぱいに拡大されて「模様」に見えてしまう。 そこで バンドギャップ全体の |φ| 最大 = vscale でスケールを固定すると、 対角が小さいバンドは正しく白（=ゼロ）のまま残り、重ねた FS 等高線が主役として読める。
関連：bz_map（対角マップ・FS のタイル展開）／ _read_ctx（ENERGY_diag, mu0 を供給）

                plot_phi_matrix(ctx, phi_band, iw, mode; component=:real,
                    out_png=joinpath(mode_dir, "gap_band_real.png"),
                    suptitle_str=@sprintf("Re φ_band(+iω1,k)  [%s] mode=%d  λ=%.5f  grid=%s", ch, mode, lam, gridstr))

                # 3) バンド表示 対角 + FS（カラースケールはバンドギャップ全体の |φ| で固定）
                band_vscale = maximum(abs.(@view phi_band[iw, :, :, 1, :, :, mode]))
                plot_phi_band_diag_fs(ctx, phi_band, iw, mode; vscale=band_vscale,
                    out_png=joinpath(mode_dir, "gap_band_diag_fs.png"),
                    suptitle_str=@sprintf("Re diag φ_band(+iω1,k) +FS(all)  [%s] mode=%d  λ=%.5f  grid=%s", ch, mode, lam, gridstr))

                # 4) バンド表示 絶対値（非対角込み）
                plot_phi_matrix(ctx, phi_band, iw, mode; component=:abs,
                    out_png=joinpath(mode_dir, "gap_band_abs.png"),
                    suptitle_str=@sprintf("|φ_band(+iω1,k)|  [%s] mode=%d  λ=%.5f  grid=%s", ch, mode, lam, gridstr))
            end
        end
    end
    println("Done. Outputs under: $OUTDIR/")
end

関連：plot_phi_matrix／plot_phi_band_diag_fs（描画本体）／ orb2band_anomalous!（バンド変換）／ global_phase_fix_mode!・fix_unitary_time_reversal_gauge!
TR ゲージ固定を先に： バンド表示の異常項変換 φband(k)=U†(k) φorb(k) conj(U(-k)) は U(k) と U(-k) の 相対位相が効く。各 k の U(1) ゲージ（fix_unitary_gauge!）だけでは +k と -k の 位相が独立にバラつくので、fix_unitary_time_reversal_gauge! で U(-k)≈conj(U(k)) に揃えてから orb2band_anomalous! を呼ぶ必要がある。これを飛ばすとバンドギャップ（特に対角）が位相ノイズで汚れる。
実部プロットの符号安定化： Eliashberg のギャップは全体位相 eiθ の自由度を持つため、 global_phase_fix_mode! で mode 全体の位相を 1 つ固定してから Re φ を描く。 軌道基底・バンド基底それぞれで（変換の前後で）掛けることで、bwr の赤/青（符号）が run 間・mode 間で ちらつかず、ノードの位置が読みやすくなる。diag+FS の vscale をバンド全体で固定するのも同じ「見やすさ優先」の設計。
