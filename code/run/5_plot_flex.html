5. Plot FLEX — 感受率マップ

— χ0/χ_s/χ_c の静的(ν=0)感受率を対角化・軌道・バンド表示で BZ 充填マップに描く  |  関数名をクリックで詳細 —

FLEX の感受率を可視化する。χ0・χs・χc それぞれについて Flex_results/<name>/ を作り、静的（ν=0）の軌道密度-密度感受率行列 Mij(q) = χ(i,i),(j,j)(q) を、対角化（主固有値・回転不変）マップ／軌道表示 Re・abs／ バンド表示 Re・abs の 5 枚で描く。バンド表示は q 点のユニタリ U(q) で回す簡易診断 （厳密な form-factor 版ではない）。

使い方： 推奨は plot.jl 経由（simulation.h5 の ν=0 スライスから描画）。 単体なら julia --project=. 5_plot_flex.jl。
データ源： フル配列 χ0/χs/χc は __FLEX_CACHE__（連結セッションがあれば優先）。 単体実行時は HDF5 の ν=0 スライス flex_result/{chi_0_w0, chi_s_w0, chi_c_w0} を使う。
出力： Flex_results/{chi0, chi_s, chi_c}/ に diag_leadingeig.png・orb_real.png・band_real.png・orb_abs.png・band_abs.png。
依存： functions/nonint.jl（_build_kmesh_cart 等）・ functions/kplot.jl（bz_map）・PyPlot（Agg バックエンド）。
simulation.h5 (+__FLEX_CACHE__)→ χ の ν=0 スライス→ M_ij(q) 軌道行列→ 対角化 / 軌道 / バンド表示→ Flex_results/*.png

概要

開いた HDF5 ハンドル f から、感受率マップを描くのに必要なコンテキストを名前付きタプルにまとめて返す。 メッシュ寸法 Nqx/Nqy/Norb、逆格子ベクトル b1/b2 と lattice_type、複合添字 mask_inds、 バンド回転用の UNITARY を読む。UNITARY は相互作用込みの UNITARY_corrected があればそれを優先し、 無ければ非相互作用対角化の nonint/diag/UNITARY を使う。

コード

5_plot_flex.jl · _read_ctx
function _read_ctx(f)
    p = f["params"]
    Nqx = Int(read(p["Nqx"])); Nqy = Int(read(p["Nqy"])); Norb = Int(read(p["Norb"]))
    gl = f["nonint/lattice"]
    lattice_type = String(read(gl["lattice_type"]))
    b1 = _as3(read(gl["b1"])); b2 = _as3(read(gl["b2"]))
    mask_inds = Int.(read(f["flex_result/mask_inds"]))
    UNITARY = haskey(f, "flex_result") && haskey(f["flex_result"], "UNITARY_corrected") ?
        ComplexF64.(read(f["flex_result/UNITARY_corrected"])) : ComplexF64.(read(f["nonint/diag/UNITARY"]))
    return (Nqx=Nqx, Nqy=Nqy, Norb=Norb, lattice_type=lattice_type, b1=b1, b2=b2, mask_inds=mask_inds, UNITARY=UNITARY)
end

読み方

  • Nqx/Nqy/Norb — params グループからメッシュ分割数と軌道数を Int で取り出す。
  • b1 = _as3(read(gl["b1"])) — 逆格子ベクトルを _as3 で必ず 3 成分ベクトルに整形（lattice のヘルパ）。bz_map の座標変換に渡す。
  • mask_inds — FLEX が実際に計算した複合添字の一覧。感受率行列の軌道対角ブロックを引くための索引に使う。
  • UNITARY = ... UNITARY_corrected ... : ... nonint/diag/UNITARY — 相互作用込みユニタリを優先する三項演算。バンド表示 U(q)† M U(q) の回転に使う。
関連：_as3（ベクトル整形）／ Nonint の UNITARY（対角化で生成）
_w0_slice▶ ν=0 スライスを取り出す（cache は 6 階 → 先頭を切る、HDF5 は 5 階そのまま）

chi_orb_matrix▶ 軌道密度ブロック Mij(q) = χ(ii)(jj)(q) を (Nqx,Nqy,Norb,Norb) で構築
chi_orb_matrix(chi_w0, Norb, mask_inds) → M[qx,qy,i,j]（ComplexF64, Nqx×Nqy×Norb×Norb）

概要

複合添字で格納された感受率 χ(ν=0) から、軌道の密度-密度ブロック Mij(q) = χ(i,i),(j,j)(q) だけを抜き出して Norb×Norb 行列（各 q ごと）に組み直す。 軌道 i の対角複合添字を diag_index(i) で作り、mask_inds 内の位置を lookup（findfirst）で引く。 mask に無い成分は 0 で埋める。

コード

5_plot_flex.jl · chi_orb_matrix
# χ(ν=0) の軌道密度ブロック M_ij(q)=χ_{(ii)(jj)}(q) を (Nqx,Nqy,Norb,Norb) で作る。
function chi_orb_matrix(chi_w0, Norb, mask_inds)
    Nqx, Nqy = size(chi_w0, 1), size(chi_w0, 2)
    diag_index(i) = (i - 1) * Norb + i
    lookup(idx) = findfirst(==(idx), mask_inds)
    M = zeros(ComplexF64, Nqx, Nqy, Norb, Norb)
    for qx in 1:Nqx, qy in 1:Nqy, i in 1:Norb, j in 1:Norb
        I = lookup(diag_index(i)); J = lookup(diag_index(j))
        M[qx, qy, i, j] = (I === nothing || J === nothing) ? 0.0 : chi_w0[qx, qy, 1, I, J]
    end
    return M
end

読み方

  • diag_index(i) = (i-1)*Norb + i — 軌道 i の対角複合添字 (i,i)（calc_CHI0! と同じ複合添字規約）。
  • lookup(idx) = findfirst(==(idx), mask_inds) — その複合添字が mask_inds の何番目にあるか。計算されていなければ nothing。
  • M[qx,qy,i,j] = (I === nothing || J === nothing) ? 0.0 : chi_w0[qx,qy,1,I,J] — mask に無い対角ブロックは 0、あれば χ の該当要素を格納。第 3 軸 1 は Nqz=1（2 次元 BZ）を潰す添字。
  • 結果 M は各 q で Norb×Norb の（一般に非対称・複素）行列。非対角 i≠j も含む。
関連：FLEX の mask_inds（複合添字）／ chi_band_matrix・leading_eig_map（この M を受ける）
chi_band_matrix▶ バンド表示 Mband(q) = U(q)† Morb(q) U(q)（q 点のユニタリで回す簡易診断）
chi_band_matrix(Morb, UNITARY) → Mb[qx,qy,i,j]（Morb と同形）

概要

軌道行列 Morb(q) を、その q 点の固有ベクトル行列 U(q) で Mband(q) = U(q)† Morb(q) U(q) と回転してバンド基底の行列を作る。 あくまで 各 q 点のユニタリで軌道行列を相似変換する簡易診断で、感受率本来の form-factor U(k)U(k+q) を厳密に畳んだものではない点に注意。

コード

5_plot_flex.jl · chi_band_matrix
# バンド表示: M_band(q) = U(q)† M_orb(q) U(q)（q 点のユニタリで回転する簡易診断）。
function chi_band_matrix(Morb, UNITARY)
    Nqx, Nqy, Norb, _ = size(Morb)
    Mb = similar(Morb)
    for qx in 1:Nqx, qy in 1:Nqy
        U = @view UNITARY[qx, qy, 1, :, :]
        Mb[qx, qy, :, :] .= U' * (@view Morb[qx, qy, :, :]) * U
    end
    return Mb
end

読み方

  • U = @view UNITARY[qx,qy,1,:,:] — その q の Norb×Norb 固有ベクトル行列を参照（コピーなし）。第 3 軸 1 は Nqz=1。
  • Mb[...] .= U' * Morb * U — U†MU の相似変換。U' は共役転置。
  • この関数は real・abs 両方のバンドマップ（band_real.png／band_abs.png）の入力になる。
簡易診断であることに注意： ここでの回転は q 点の U(q) 1 枚を掛けるだけで、感受率の厳密なバンド表現に必要な U(k)・U(k+q) の form-factor 畳み込みではない。ピーク位置の当たりを付ける定性的な図として読む。
関連：chi_orb_matrix（入力 Morb）／ _read_ctx の UNITARY（回転行列）
leading_eig_map▶ Morb(q) のエルミート部の主固有値マップ（回転不変で orb/band 共通）
leading_eig_map(Morb) → out[qx,qy]（Float64, Nqx×Nqy）

概要

各 q 点で Morb(q) の実部のエルミート部を作り、その最大固有値を並べた 2 次元マップを返す。 主固有値はユニタリ相似変換 U†MU で不変（回転不変）なので、軌道表示でもバンド表示でも同じ値になり、 diag_leadingeig.png は両者に共通の「対角化した感受率」として描ける。

コード

5_plot_flex.jl · leading_eig_map
# M_orb(q) の主固有値（エルミート部）マップ（回転不変なので orb/band 共通）。
function leading_eig_map(Morb)
    Nqx, Nqy, Norb, _ = size(Morb)
    out = zeros(Nqx, Nqy)
    for qx in 1:Nqx, qy in 1:Nqy
        M = real.(@view Morb[qx, qy, :, :])
        Mh = (M .+ transpose(M)) .* 0.5
        out[qx, qy] = maximum(eigvals(Hermitian(Mh)))
    end
    return out
end

読み方

  • M = real.(@view Morb[qx,qy,:,:]) — 実部を取り出す。密度感受率の対角ブロックは実対称に近い。
  • Mh = (M .+ transpose(M)) .* 0.5 — ½(M + Mᵀ) で対称化してから固有値を取る（数値誤差でずれた非対称成分をならす）。
  • maximum(eigvals(Hermitian(Mh))) — Hermitian で包んで実固有値を得て、その最大を主固有値に。
  • 主固有値は相似変換で不変なので、orb・band で同一のマップになる（対角化表示として 1 枚で済む）。
回転不変： U†MU の固有値は M の固有値と一致する。だから diag_leadingeig.png は軌道／バンドどちらの見方でも変わらず、 感受率の最も強く応答するモードの大きさを q 面上で示す 1 枚として使える。
関連：chi_orb_matrix（入力 M）／ plot_chi_diag（このマップを描画）

コード

5_plot_flex.jl · plot_chi_diag
# 対角化した χ(q) マップ（主固有値）を窓いっぱいに（並進複製、六角形は破線ガイド）。
function plot_chi_diag(ctx, chimap, title_str; out_png)
    m = bz_map(chimap, ctx.Nqx, ctx.Nqy;
        b1=ctx.b1, b2=ctx.b2, lattice_type=ctx.lattice_type,
        axis_unit=:pi, supercell_range=2, mask_to_bz=false)
    fig = figure(figsize=(5.6, 4.8))
    pc = pcolormesh(m.X, m.Y, m.Z, cmap="viridis", shading="auto")
    plot(m.bx, m.by, color="w", linestyle="--", linewidth=1.0)
    colorbar(pc, label="leading eigenvalue")
    gca().set_aspect("equal"); xlim(-1.5, 1.5); ylim(-1.5, 1.5)
    xlabel("q_x/π"); ylabel("q_y/π"); title(title_str)
    tight_layout()
    savefig(out_png, dpi=200, bbox_inches="tight")
    close(fig)
    println("Saved: $out_png")
end

読み方

  • bz_map(chimap, Nqx, Nqy; …, supercell_range=2, mask_to_bz=false) — 並進複製して周期を跨いで敷き詰め、BZ でマスクせず窓全体を埋める。axis_unit=:pi で軸は q/π 単位。
  • pcolormesh(m.X, m.Y, m.Z, cmap="viridis") — 変換後グリッド (X,Y,Z) をそのまま塗る。
  • plot(m.bx, m.by, color="w", linestyle="--") — bz_map が返す境界線 (bx,by) を白破線で重ねる（六角形ガイド）。
  • xlim(-1.5, 1.5); ylim(-1.5, 1.5) と set_aspect("equal") — 等方・固定ウィンドウで複製された BZ を見せる。
関連：bz_map（並進複製と境界線）／ leading_eig_map（入力マップ）
plot_chi_matrix▶ Norb×Norb 行列プロット（:real は bwr 対称スケール、:abs は magma で 0..max）
plot_chi_matrix(ctx, Mmat, title_str; component::Symbol, out_png) # component=:real or :abs

概要

軌道またはバンド行列 Mij(q) の 全 (i,j) 成分を Norb×Norb のサブプロット格子で並べて描く。 各 (i,j) を bz_map で並進複製し、component=:real なら bwr の対称スケール（vmin=-vmax）、 :abs なら magma で 0..max。全成分で共通のカラースケールを取り、右端に 1 本の colorbar を付ける。

コード

5_plot_flex.jl · plot_chi_matrix
# Norb×Norb 行列プロット（軌道 or バンド、real or abs、非対角込）。
function plot_chi_matrix(ctx, Mmat, title_str; component::Symbol, out_png)
    Nqx, Nqy, Norb = ctx.Nqx, ctx.Nqy, ctx.Norb
    maps = Matrix{Any}(undef, Norb, Norb)
    allv = Float64[]
    for i in 1:Norb, j in 1:Norb
        d = @view Mmat[:, :, i, j]
        data = component === :abs ? abs.(d) : real.(d)
        m = bz_map(Float64.(data), Nqx, Nqy;
            b1=ctx.b1, b2=ctx.b2, lattice_type=ctx.lattice_type,
            axis_unit=:pi, supercell_range=2, mask_to_bz=false)
        maps[i, j] = m
        append!(allv, filter(isfinite, vec(m.Z)))
    end
    if component === :abs
        vmax = isempty(allv) ? 1.0 : maximum(allv); vmax = vmax > 0 ? vmax : 1.0
        vmin = 0.0; cmap = "magma"
    else
        vmax = isempty(allv) ? 1.0 : maximum(abs.(allv)); vmax = vmax > 0 ? vmax : 1.0
        vmin = -vmax; cmap = "bwr"
    end
    fig, axs = subplots(Norb, Norb, figsize=(2.9 * Norb + 1.0, 2.7 * Norb), squeeze=false)
    local pc
    for i in 1:Norb, j in 1:Norb
        ax = axs[i, j]; m = maps[i, j]
        pc = ax.pcolormesh(m.X, m.Y, m.Z, cmap=cmap, vmin=vmin, vmax=vmax, shading="auto")
        ax.plot(m.bx, m.by, color="k", linestyle="--", linewidth=0.7, alpha=0.7)
        ax.set_aspect("equal"); ax.set_xlim(-1.5, 1.5); ax.set_ylim(-1.5, 1.5)
        ax.set_title(@sprintf("(%d,%d)", i, j), fontsize=9)
        ax.tick_params(labelsize=7)
        i == Norb ? ax.set_xlabel("q_x/π", fontsize=8) : ax.set_xticklabels([])
        j == 1 ? ax.set_ylabel("q_y/π", fontsize=8) : ax.set_yticklabels([])
    end
    fig.subplots_adjust(left=0.06, right=0.88, bottom=0.08, top=0.90, wspace=0.15, hspace=0.25)
    cax = fig.add_axes([0.90, 0.12, 0.02, 0.74])
    fig.colorbar(pc, cax=cax)
    fig.suptitle(title_str, fontsize=13)
    savefig(out_png, dpi=180, bbox_inches="tight")
    close(fig)
    println("Saved: $out_png")
end

読み方

  • data = component === :abs ? abs.(d) : real.(d) — 表示量の切替。:abs は絶対値、:real は実部。
  • append!(allv, filter(isfinite, vec(m.Z))) — 全 (i,j) 成分の有限値を集めて共通スケールを決める材料に。
  • :abs → vmin=0, cmap="magma"／:real → vmin=-vmax, cmap="bwr" — abs は 0 起点、real は0 対称の発散カラーマップ。vmax = vmax > 0 ? vmax : 1.0 でゼロ割れ・平坦データを保護。
  • subplots(Norb, Norb; squeeze=false) — Norb×Norb の格子。squeeze=false で Norb=1 でも 2 次元配列を保つ。
  • i == Norb ? … : ax.set_xticklabels([]) / j == 1 ? … : ax.set_yticklabels([]) — 最下行・最左列だけに軸ラベル・目盛りを残して見やすくする。
  • add_axes([0.90, 0.12, 0.02, 0.74]) + fig.colorbar(pc, cax=cax) — 右端に共通の colorbar を 1 本。
real と abs の描き分け： :real は符号（同相／逆相の応答）を bwr の赤青で、:abs は強度だけを magma で見る。 非対角 (i,j)（i≠j）も含めて全ブロックを同一スケールで並べるので、軌道間の相対的な大きさが読み取れる。
関連：bz_map（各成分の並進複製）／ chi_orb_matrix・chi_band_matrix（入力行列）
plot_one_chi▶ 1 つの χ についてフォルダを作り diag／orb・band × real・abs の 5 枚を出力
plot_one_chi(ctx, chi_w0, name, peak) # Flex_results/<name>/ に 5 枚保存

概要

1 種類の感受率 χ(ν=0) を受け取り、出力フォルダ Flex_results/<name>/ を作ってから chi_orb_matrix で軌道行列、chi_band_matrix でバンド行列を組み、対角化 1 枚＋（orb・band）×（real・abs）4 枚の 計 5 枚を描く。peak（最大固有値）はタイトルに埋め込む。

# 1つの χ について、フォルダを作って diag / orb・band の real・abs を描く。
function plot_one_chi(ctx, chi_w0, name, peak)
    outdir = joinpath(OUTDIR, name); mkpath(outdir)
    Morb = chi_orb_matrix(chi_w0, ctx.Norb, ctx.mask_inds)
    Mband = chi_band_matrix(Morb, ctx.UNITARY)
    tag = @sprintf("%s(q,ν=0)  grid=%dx%d  peak=%.3f", name, ctx.Nqx, ctx.Nqy, peak)

    plot_chi_diag(ctx, leading_eig_map(Morb), "$name leading-eig (ν=0)  peak=$(@sprintf("%.3f", peak))";
        out_png=joinpath(outdir, "diag_leadingeig.png"))
    plot_chi_matrix(ctx, Morb, "Re $tag  (orbital)"; component=:real, out_png=joinpath(outdir, "orb_real.png"))
    plot_chi_matrix(ctx, Mband, "Re $tag  (band)"; component=:real, out_png=joinpath(outdir, "band_real.png"))
    plot_chi_matrix(ctx, Morb, "|$tag|  (orbital)"; component=:abs, out_png=joinpath(outdir, "orb_abs.png"))
    plot_chi_matrix(ctx, Mband, "|$tag|  (band)"; component=:abs, out_png=joinpath(outdir, "band_abs.png"))
end

読み方

  • outdir = joinpath(OUTDIR, name); mkpath(outdir) — Flex_results/chi0 など名前ごとのサブフォルダを用意。

main() # simulation.h5 を開き、χ0/χ_s/χ_c のマップ群を Flex_results/ に出力

概要

エントリポイント。出力ルート Flex_results/ を作り、__FLEX_CACHE__ があればそのフル配列から ν=0 スライスを取り（cache 優先）、無ければ HDF5 の chi_*_w0 スライスを読む。最大固有値 chi_0/chi_s/chi_c_maxeigval を peak として渡し、plot_one_chi を chi0・chi_s・chi_c の順に呼ぶ。 HDF5 に chi_s_w0／chi_c_w0 が無ければその χ はスキップして警告を出す。

5_plot_flex.jl · main
function main()
    println("--- Plot FLEX susceptibilities from $SIM_FILENAME ---")
    mkpath(OUTDIR)
    cache = (isdefined(Main, :__FLEX_CACHE__) && Main.__FLEX_CACHE__ isa AbstractDict) ? Main.__FLEX_CACHE__ : nothing

    h5open(SIM_FILENAME, "r") do f
        ctx = _read_ctx(f)
        chi0_max = Float64(read(f["flex_result/chi_0_maxeigval"]))
        Us_max = Float64(read(f["flex_result/chi_s_maxeigval"]))
        Uc_max = Float64(read(f["flex_result/chi_c_maxeigval"]))
        println(@sprintf("chi0 max-eig=%.4f  chi_s max-eig=%.4f  chi_c max-eig=%.4f", chi0_max, Us_max, Uc_max))

        # χ0 / χ_s / χ_c の ν=0 スライスを用意（cache 優先、無ければ HDF5 スライス）
        if cache !== nothing && haskey(cache, :chi_s) && haskey(cache, :chi_c) && haskey(cache, :chi_0)
            println("Using __FLEX_CACHE__ (chi_0/chi_s/chi_c full arrays)")
            chi0_w0 = _w0_slice(cache[:chi_0]); chis_w0 = _w0_slice(cache[:chi_s]); chic_w0 = _w0_slice(cache[:chi_c])
        else
            println("__FLEX_CACHE__ not available -> read ν=0 slices from HDF5")
            chi0_w0 = read(f["flex_result/chi_0_w0"])
            chis_w0 = haskey(f["flex_result"], "chi_s_w0") ? read(f["flex_result/chi_s_w0"]) : nothing
            chic_w0 = haskey(f["flex_result"], "chi_c_w0") ? read(f["flex_result/chi_c_w0"]) : nothing
        end

        plot_one_chi(ctx, chi0_w0, "chi0", chi0_max)
        if chis_w0 !== nothing
            plot_one_chi(ctx, chis_w0, "chi_s", Us_max)
        else
            println("chi_s_w0 not found in HDF5 (run FLEX to regenerate) -> skip chi_s/")
        end
        if chic_w0 !== nothing
            plot_one_chi(ctx, chic_w0, "chi_c", Uc_max)
        else
            println("chi_c_w0 not found in HDF5 (run FLEX to regenerate) -> skip chi_c/")
        end
    end
    println("Done. Outputs under: $OUTDIR/{chi0,chi_s,chi_c}/")
end

読み方

  • cache = (isdefined(Main, :__FLEX_CACHE__) && … isa AbstractDict) ? … : nothing — 連結セッションのフル配列 cache を検出。無ければ nothing。
  • chi0_max/Us_max/Uc_max — 各感受率の最大固有値を HDF5 から読み、peak として図タイトルに使う。
  • if cache !== nothing && haskey(cache, :chi_0/:chi_s/:chi_c) — cache に 3 つ揃っていれば _w0_slice で ν=0 を取り出す（優先）。
  • else ブロック — HDF5 の chi_0_w0 を読み、chi_s_w0／chi_c_w0 は haskey であれば読む・無ければ nothing。
  • plot_one_chi(ctx, …, "chi0"/"chi_s"/"chi_c", peak) — 3 種を順に描画。χs/χc が nothing のときはスキップして警告（FLEX 再実行で再生成できる旨）。
関連：FLEX の calc_CHIS_CHIC!（χs/χc を作って保存）／ _read_ctx・_w0_slice・plot_one_chi
2 つの読み方： diag_leadingeig.png（主固有値）は相似変換で不変なので軌道表示・バンド表示で共通の 1 枚。 一方 band_*.png は q 点のユニタリ U(q) で Morb を回した簡易診断で、感受率本来の form-factor（U(k)U(k+q)）を厳密に畳んだバンド表現ではない。ピーク q の当たりを付ける定性図として読む。
バックエンド設定の順序： ENV["MPLBACKEND"] = "Agg" は必ず using PyPlot の前に置く。 PyPlot は読み込み時にバックエンドを確定するため、順序が逆だと画面出力を試みて GUI の無い環境で失敗し得る（Agg はファイル出力専用の非対話バックエンド）。
関連： ここで描く感受率そのものを作る計算は 2_run_FLEX.jl（FLEX の calc_CHIS_CHIC! ほか）。同じ FLEX 結果から超伝導ギャップの可視化に進むなら 6_plot_eliashberg.jl。格子座標変換・BZ 充填の詳細は lattice と kplot を参照。
