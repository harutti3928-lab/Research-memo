2. FLEX — 自己無撞着計算

— G→χ0→Veff→Σ→μ の SCF ループで自己エネルギーを収束させ、感受率・Stoner を診断する  |  関数名をクリックで詳細 —

FLEX（揺らぎ交換近似）の自己無撞着計算を回すドライバ。simulation.h5（1_setup.jl の出力）から H(k)・U を読み、G → χ0 → Veff → Σ → μ 更新のループを 収束まで回す。大配列は HDF5 に書かず __FLEX_CACHE__（メモリ）に置き、同一セッションの 3_run_eliashberg.jl へそのまま連結する——この「省ストレージ連結」が設計の肝。

使い方： 単体なら julia --project=. 2_run_FLEX.jl、連結なら同一 Julia セッションで include("1_setup.jl"); include("2_run_FLEX.jl"); include("3_run_eliashberg.jl")。
入力： simulation.h5（1_setup.jl が書き出した H(k)・対角化結果・パラメータ）。
出力： simulation.h5 の flex_result グループ（小さい診断量と ν=0 スライスのみ）＋ メモリ上の __FLEX_CACHE__（G・SIGMA・χ0/χs/χc などの大配列）。
依存： include("functions/flex_lib.jl")（FLEX コア関数群をまとめて読み込む）。
simulation.h5→ 相互作用行列・配列 初期化→ SCF: G → χ0 → Uχ0診断 → χs/χc → Veff → Σ → μ↻ → 後処理→ __FLEX_CACHE__ + flex_result

中央の SCF ブロックが 1 反復（calc_GREEN! → calc_CHI0! → eval_Uchi0 → calc_CHIS_CHIC! → calc_Veff! → calc_SIGMA! → μ更新）。 誤差が閾値を切れば収束、切らなければ maxiter か over-stoner で停止する。

ドライバ本体。ライブラリ関数（flex.jl ほか）を flex_lib.jl 経由で読み込み、 run_flex() 一本で「読み込み → SCF → 後処理 → 保存」までを実行する。

max_eigenmode_diag_static▶ 静的(ν=0)・軌道対角ブロックの最大固有値を全 q で探し、χ の主要モードを診断
max_eigenmode_diag_static(CHI, Norb, mask_inds; w0=1, qz_fixed=1) → (best_val, best_vec, best_q)

概要

感受率配列 CHI の静的成分（ν=0、先頭周波数 w0=1）から、軌道対角ブロック Mij(q) = Re[χ(w0, q, (i,i), (j,j))] を作り、そのエルミート部の最大固有値を全ての面内 q で探して、最大値・固有ベクトル・その q を返す。χ0/χs/χc の 「どの波数・どの軌道の組み合わせが一番育っているか（主要モード）」を診断するための後処理関数。

コード

2_run_FLEX.jl · max_eigenmode_diag_static
function max_eigenmode_diag_static(CHI::Array{ComplexF64,6}, Norb::Int, mask_inds; w0::Int=1, qz_fixed::Int=1)
    _, Nqx, Nqy, Nqz, _, _ = size(CHI)
    1 <= qz_fixed <= Nqz || throw(ArgumentError("qz_fixed out of range: $qz_fixed (Nqz=$Nqz)"))

    diag_index(i) = (i - 1) * Norb + i
    lookup_masked(index) = (mask_inds === nothing) ? index : findfirst(==(index), mask_inds)

    best_val = -Inf
    best_vec = zeros(Float64, Norb)
    best_q = (1, 1, qz_fixed)

    M = Matrix{Float64}(undef, Norb, Norb)
    for qx in 1:Nqx, qy in 1:Nqy
        for i in 1:Norb, j in 1:Norb
            I = lookup_masked(diag_index(i))
            J = lookup_masked(diag_index(j))
            M[i, j] = (I === nothing || J === nothing) ? 0.0 : real(CHI[w0, qx, qy, qz_fixed, I, J])
        end
        Mh = (M .+ transpose(M)) .* 0.5
        e = eigen(Hermitian(Mh))
        if e.values[end] > best_val
            best_val = e.values[end]
            best_vec .= e.vectors[:, end]
            best_q = (qx, qy, qz_fixed)
        end
    end
    return best_val, copy(best_vec), best_q
end

読み方

  • 1 <= qz_fixed <= Nqz || throw(...) — 面 qz を 1 枚に固定して 2 次元 (qx,qy) を走査する。範囲外なら即エラー。
  • diag_index(i) = (i-1)*Norb + i — 軌道 i の対角成分 (i,i) の複合線形インデックス。χ の複合添字は「軌道ペア」を 1 本に潰したもの。
  • lookup_masked(index) — mask_inds で圧縮された配列内での位置を findfirst(==(index), mask_inds) で引く。マスクに無い成分は nothing。
  • M[i,j] = (…) ? 0.0 : real(CHI[w0, qx, qy, qz_fixed, I, J]) — 対角ブロックのみ拾い、マスク外は 0。実部を取って実行列 M に。
  • Mh = (M .+ transpose(M)) .* 0.5 → eigen(Hermitian(Mh)) — エルミート（対称）化してから対角化。eigen の固有値は昇順なので values[end] が最大。
  • if e.values[end] > best_val — 全 q を通じて最大固有値を更新し、固有ベクトルと q=(qx,qy,qz_fixed) を記録。

(1) simulation.h5 から読み込み

1_setup.jl が書いた H(k)・対角化結果・非相互作用の化学ポテンシャル/占有数と、全パラメータを読み込む。

Nqx, Nqy, Nqz = Int(params["Nqx"]), Int(params["Nqy"]), Int(params["Nqz"])
U, Uprime = Float64(params["U"]), Float64(params["Uprime"])
Nfilling  = Float64(params["Nfilling"])            # per-spin filling（= rfill）
sub_self0  = Bool(get(params, "sub_self0", true))
mix_factor = Float64(get(params, "mix_factor", 0.2))
is_RPA     = (Int(get(params, "RPA", 0)) == 1)

# Stoner ガード（Uχ0 の閾値・動作）
Uchi0_action           = String(get(params, "flex_Uchi0_action", "abort"))
Uchi0_warn_threshold   = Float64(get(params, "flex_Uchi0_warn_threshold", 0.99))
Uchi0_over_threshold   = Float64(get(params, "flex_Uchi0_over_threshold", 0.999))

  • h5open(…, "r") do file … end — params を Dict に全キー展開し、ENERGY・ENERGY_diag・UNITARY・非相互作用の mu0・占有数を読む。
  • Nfilling はスピンあたりの filling（rfill）。全電子数は 2·Nfilling。calc_mu の目標値になる。
  • get(params, key, 既定) — sub_self0・mix_factor・is_RPA などの動作フラグを、キーが無ければ既定値で読む。
  • Stoner ガード各値 — flex_Uchi0_action（abort/scale/continue）、warn_threshold(0.99)、over_threshold(0.999)、over_consecutive(10)。Uχ0 が 1 に近づいた（磁気不安定）ときの挙動を決める。

(3) FLEX 自己無撞着ループ

1 反復で G→χ0→（Stoner 診断）→χs/χc→Veff→Σ→μ を回し、誤差が閾値を切るまで繰り返す。

2_run_FLEX.jl · run_flex (3) SCF ループ（抜粋）
# ===== 3. FLEX 自己無撞着ループ =====
dmu = (maximum(ENERGY_diag) - minimum(ENERGY_diag)) * 0.5
is_converged = false; is_aborted_overstoner = false
Uchi0_over_count = 0; Uchi0_max_last = NaN; Uchi0_status = "unknown"

for iter in 1:maxiter
    # (A) G(k,iω)
    calc_GREEN!(G, SIGMA, ENERGY, MATSUBARA, mu)
    # (B) χ0(q,iν)  ※ G は r,τ 表示に変わる（副作用）
    calc_CHI0!(CHI0, G, temp, FFT_plan, mask_inds)

    # (B2) Uχ0（Stoner 診断・ガード）: 間隔ごと + 初回のみ評価
    did_eval = (iter % eval_Uchi0_interval == 0) || iter == 1
    if did_eval
        Uchi0_max_last, _ = eval_Uchi0(CHI0, U_spin)
        Uchi0_max_last >= Uchi0_over_threshold && (Uchi0_over_count += 1)
        Uchi0_status =
            Uchi0_over_count >= Uchi0_over_consecutive ? "over_stoner" :
            Uchi0_max_last  >= Uchi0_over_threshold   ? "near_over_stoner" :
            Uchi0_max_last  >= Uchi0_warn_threshold   ? "near_stoner" : "ok"
        if Uchi0_status == "over_stoner"
            if lowercase(Uchi0_action) == "abort"
                is_aborted_overstoner = true; break         # 安全停止
            elseif lowercase(Uchi0_action) == "scale"
                is_Uchi0_scale = true                        # 以降スケール
            end
        end
    end

    # (C) χ_s / χ_c（保持用に別配列） / (D) Veff（CHI_work に）
    calc_CHIS_CHIC!(CHI_S, CHI_C, CHI0, U_spin, U_charge; is_Uchi0_scale=is_Uchi0_scale, maxeigval_tol=maxeigval_tol)
    CHI_work .= CHI0
    calc_Veff!(CHI_work, U_spin, U_charge; is_Uchi0_scale=is_Uchi0_scale, maxeigval_tol=maxeigval_tol)

    if is_RPA   # RPA 分岐：1 パスで終了
        calc_SIGMA!(CHI_work, G, SIGMA, temp, FFT_plan; mask_inds=mask_inds, sub_self0=sub_self0, mix_factor=1.0, RPA=true, return_dself=false)
        mu_new = calc_mu(mu, SIGMA, ENERGY, MATSUBARA, ENERGY_diag, temp, Nfilling)
        mu_new != "Failed-to-converge" && (mu = Float64(mu_new))
        is_converged = true; break
    end

    # (E) Σ 更新 → 誤差 a_err / (F) μ 更新
    a_err, _ = calc_SIGMA!(CHI_work, G, SIGMA, temp, FFT_plan; mask_inds=mask_inds, sub_self0=sub_self0, mix_factor=mix_factor)
    mu, dmu, ok_mu = calc_mu_autoselect(mu, dmu, a_err)

    if a_err < tol
        is_converged = true; break         # 収束
    end
end
  • (A)/(B) calc_GREEN! で G を作り、calc_CHI0! で χ0。calc_CHI0! は G を (r,τ) 表示のまま残す副作用があり、次段 calc_SIGMA! がそれを使う。
  • (B2) eval_Uchi0 で Uχ0 の最大固有値を診断。over_threshold 超えの回数を数え、status を ok／near_stoner／near_over_stoner／over_stoner に分類。
  • ガードの action： over_stoner かつ abort なら break（安全停止）、scale なら is_Uchi0_scale=true にして以降 Veff の固有値を縮小、continue ならそのまま続行。
  • did_eval = (iter % eval_Uchi0_interval == 0) || iter == 1 — Uχ0 評価は重いので間隔ごと＋初回だけに間引く。
  • (C)/(D) calc_CHIS_CHIC! で χs/χc を別配列に保持、calc_Veff! で有効相互作用を CHI_work に上書き。
  • RPA 分岐： is_RPA なら calc_SIGMA!(…, RPA=true) を 1 回だけ回し、μ を 1 回更新して break（自己無撞着ループを回さない）。
  • (E)/(F) calc_SIGMA! が誤差 a_err を返し、calc_mu_autoselect で μ を更新。
  • 収束判定： a_err < tol で is_converged=true して break。切らなければ maxiter まで、over_stoner なら途中で停止する。

μ 更新のヘルパ（ネスト定義） — 誤差の大小でソルバを切り替え、次の探索幅 dmu をクランプする。

2_run_FLEX.jl · run_flex 内 · calc_mu_autoselect
# μ 更新（誤差が大きいと Brent、小さいと Secant）
function calc_mu_autoselect(mu, dmu, a_err)
    solver = a_err > switch_solver_tol ? "Brent" : "Secant"
    mu_new = calc_mu(mu, SIGMA, ENERGY, MATSUBARA, ENERGY_diag, temp, Nfilling; solver=solver, dmu=dmu)
    mu_new == "Failed-to-converge" && return mu, dmu, false
    dmu_new = clamp(sqrt(a_err) * abs(mu_new - mu), min_dmu, max_dmu)
    return Float64(mu_new), dmu_new, true
end
  • solver = a_err > switch_solver_tol ? "Brent" : "Secant" — 誤差が大きい序盤は堅牢な Brent、小さくなったら速い Secant。calc_mu にそのまま渡す。
  • mu_new == "Failed-to-converge" && return mu, dmu, false — 求根失敗なら μ・dmu を据え置き、フラグ false を返す（ログに mu_fail）。
  • dmu_new = clamp(sqrt(a_err) * abs(mu_new - mu), min_dmu, max_dmu) — 次回の探索幅を誤差に応じて調整し、[min_dmu, max_dmu] にクランプ。

(4) 後処理（保存用に整合した量を作る）

収束後の Σ・μ で各配列を作り直し、filling・Uχ0・χ の静的最大固有モードを最終評価する。

2_run_FLEX.jl · run_flex (4) 後処理（抜粋）
# ===== 4. 後処理（保存用に整合した量を作る）=====
G_save = similar(G)
calc_GREEN!(G, SIGMA, ENERGY, MATSUBARA, mu)
calc_CHI0!(CHI0, G, temp, FFT_plan, mask_inds)                 # G は r,τ 表示に
calc_CHIS_CHIC!(CHI_S, CHI_C, CHI0, U_spin, U_charge; is_Uchi0_scale=is_Uchi0_scale, maxeigval_tol=maxeigval_tol)
calc_GREEN!(G_save, SIGMA, ENERGY, MATSUBARA, mu)              # 保存用 G(k,iω)

# Uχ0 を最終 CHI0 で再評価（ループ間隔で古くなるのを防ぐ）
Uchi0_max, Uchi0_ind, Uchi0_eigvec = eval_Uchi0(CHI0, U_spin; return_eigvec=true)

# 相互作用込み filling
if !sub_self0
    ENERGY_diag_corr, UNITARY_corr = diagonalize_Hamiltonian(ENERGY; SIGMA=SIGMA)
    fix_unitary_gauge!(UNITARY_corr)
else
    ENERGY_diag_corr, UNITARY_corr = ENERGY_diag, UNITARY
end
Ne_band_int, Ne_orb_int = get_Ne_w_interaction(mu, SIGMA, ENERGY, MATSUBARA, ENERGY_diag, temp, UNITARY_corr)

# χ の静的最大固有モード
chi0_val, chi0_vec, chi0_q = max_eigenmode_diag_static(CHI0,  Norb, mask_inds)
chis_val, chis_vec, chis_q = max_eigenmode_diag_static(CHI_S, Norb, mask_inds)
chic_val, chic_vec, chic_q = max_eigenmode_diag_static(CHI_C, Norb, mask_inds)
  • 収束後の SIGMA・mu で G/CHI0/CHI_S/CHI_C を作り直し、保存する量どうしを整合させる。G_save は (k,iω) 表示の保存用（G は calc_CHI0! で (r,τ) になるため別に確保）。
  • eval_Uchi0(CHI0, U_spin; return_eigvec=true) — Uχ0 を最終 CHI0 で再評価（ループ間引きで古い値になるのを防ぐ）。固有ベクトルも取得し、status を付け直す。
  • sub_self0=false のとき diagonalize_Hamiltonian(ENERGY; SIGMA=SIGMA) で繰り込みバンドを作り、fix_unitary_gauge! でゲージ固定。true なら非相互作用の対角化結果を流用。
  • get_Ne_w_interaction(…) — 相互作用込みの filling（band 別・orb 別）。目標 Nfilling とのズレをサマリーで確認する。
  • max_eigenmode_diag_static を χ0/χs/χc に適用し、静的（ν=0）の最大固有モードと波数 q を取得。
