4. Plot nonint — バンド/DOS/フェルミ面

— simulation.h5 から非相互作用のバンド+DOS・DOS・フェルミ面(E=μ₀)を PNG 出力する  |  関数名をクリックで詳細 —

simulation.h5 を読み、非相互作用のバンド（k-path）+DOS、DOS 単体、 フェルミ面（E-μ0=0 の等高線）を描く可視化スクリプト。DOS/FS は保存済みメッシュではなく 細かい k メッシュで H(k) を作り直して滑らかにする。描画は PyPlot（Agg バックエンドで画面を使わず PNG に落とす）。 土台の H(k) 構築・対角化は Nonint、BZ メッシュ幾何は lattice の関数を利用する。

使い方：julia --project=. 4_plot_nonint.jl  |  入力：simulation.h5  |  出力（Noint/）：band_kpath_dos.png・dos.png・fs.png  |  依存：include("functions/nonint.jl")、using PyPlot （ENV["MPLBACKEND"]="Agg" を using の前に設定）。
simulation.h5→ 細メッシュで ENERGY_diag 再計算→ band+DOS / DOS / FS(等高線)→ Noint/*.png

4_plot_nonint.jlJulia

保存済みの simulation.h5 を読み、非相互作用の 3 枚の図を PNG 出力する可視化ドライバ。冒頭の依存パッケージと設定定数は次のとおり。

4_plot_nonint.jl — 冒頭
using HDF5
using Printf
using LinearAlgebra

ENV["MPLBACKEND"] = "Agg"   # 画面を使わず PNG 出力
using PyPlot

include("functions/nonint.jl")

const SIM_FILENAME = "simulation.h5"
const OUTDIR = "Noint"

const DOS_NGRID   = 1200
const DOS_SIGMA   = 0.02
const DOS_EPAD    = 0.10
const DOS_PLOT_NQ = 256
const FS_PLOT_NQ  = 256

定数群の読み方：DOS_NGRID は DOS を評価するエネルギー格子点数、DOS_SIGMA は DOS の ガウス広がり σ（バンドと同じエネルギー単位）、DOS_EPAD はプロット範囲を上下に広げる余白。 DOS_PLOT_NQ／FS_PLOT_NQ は DOS/FS を描くために 再計算する細メッシュの 1 辺の点数（Nq×Nq×1）。 SIM_FILENAME が入力、OUTDIR（Noint/）が出力先ディレクトリ。 ENV["MPLBACKEND"]="Agg" は using PyPlot より前に置くのがポイント（後述）。

_gauss▶ 正規化ガウス N(0,σ)。DOS のブロードニング核（1 行関数）
_gauss(x::Real, sigma::Real) → Float64

概要

平均 0・標準偏差 σ の正規化ガウス exp(-x2/2σ2) / (√(2π)·σ) を返す 1 行関数。離散的なバンド固有値 Ei を「幅 σ のガウス」に置き換えて足し込むことで、なめらかな状態密度 DOS を作るための核（カーネル）として使う。

コード

4_plot_nonint.jl · _gauss
_gauss(x::Real, sigma::Real) = exp(-0.5 * (Float64(x) / Float64(sigma))^2) / (sqrt(2π) * Float64(sigma))

読み方

  • exp(-0.5 * (x/σ)^2) — ガウスの山。x = grid - Ei（評価点と固有値の差）を入れて使う。
  • / (sqrt(2π) * σ) — 面積が 1 になる正規化因子。これで DOS の積分が状態数と一致する。
  • Float64(...) — 整数や有理数が来ても確実に浮動小数で計算する保険。
関連：plot_band_and_dos・plot_dos（この核を全固有値に畳んで DOS を作る）
_read_basic▶ simulation.h5 から mu0/Nqx../Norb/hopping_path/rfill をまとめて読む
_read_basic(f) → NamedTuple(mu0, Nqx, Nqy, Nqz, Norb, hopping_path, rfill)

概要

開いた HDF5 ファイルハンドル f から、非相互作用の描画に必要な基本情報を 名前付きタプルにまとめて返すヘルパ。 化学ポテンシャル mu0、k メッシュ分割 Nqx/Nqy/Nqz、軌道数 Norb、ホッピングファイルのパス hopping_path、目標フィリング rfill を 1 か所で読み出す。

コード

4_plot_nonint.jl · _read_basic
function _read_basic(f)
    p = f["params"]
    return (
        mu0 = read(f["nonint/chem/mu0"]),
        Nqx = Int(read(p["Nqx"])), Nqy = Int(read(p["Nqy"])), Nqz = Int(read(p["Nqz"])),
        Norb = Int(read(p["Norb"])),
        hopping_path = String(read(p["hopping_path"])),
        rfill = Float64(read(p["rfill"])),
    )
end

読み方

  • p = f["params"] — パラメータ群のグループを 1 度だけ取り出して以降使い回す。
  • mu0 = read(f["nonint/chem/mu0"]) — 非相互作用の化学ポテンシャル μ0。全図で E-μ0 の基準に使う。
  • Int(read(...))／String(read(...))／Float64(read(...)) — HDF5 から読んだ値を期待する型に明示変換（後段の配列確保や行列積で型を揃える）。
  • 返り値は名前付きタプルなので、呼び出し側は b.mu0・b.Norb のようにフィールド名でアクセスできる。
関連：3 つの plot_* 関数（いずれも冒頭でこれを呼ぶ）／ _recompute_energy_diag（hopping_path・Norb を渡す）
_recompute_energy_diag▶ 細かい k メッシュ（Nq×Nq×1）で H(k) を作り直して対角化 → 滑らかな ENERGY_diag
_recompute_energy_diag(hopping_path, Norb, Nq) → ENERGY_diag[Nq,Nq,1,Norb]

概要

DOS やフェルミ面をなめらかに描くために、保存済みの粗いメッシュではなく 細かい k メッシュ Nq×Nq×1 で H(k) を作り直して対角化する。hopping_path のホッピングファイルから load_Hamiltonian で格子 H(k) を組み、 diagonalize_Hamiltonian でバンド固有値 ENERGY_diag を得る（固有ベクトルは使わないので捨てる）。

コード

4_plot_nonint.jl · _recompute_energy_diag
function _recompute_energy_diag(hopping_path, Norb, Nq)
    ENERGY = load_Hamiltonian(hopping_path, Nq, Nq, 1, Norb)
    ENERGY_diag, _ = diagonalize_Hamiltonian(ENERGY)
    return ENERGY_diag
end

読み方

  • load_Hamiltonian(hopping_path, Nq, Nq, 1, Norb) — 2 次元系を想定し Nqz=1 の Nq×Nq×1 メッシュで H(k) を構築。Nq に DOS_PLOT_NQ（=256）を渡すと保存メッシュより細かくなる。
  • diagonalize_Hamiltonian(ENERGY) — 各 k で対角化。SIGMA を渡さないので純粋な一体バンド（非相互作用）。
  • ENERGY_diag, _ = ... — 固有ベクトル UNITARY は使わないので _ で捨て、バンド固有値だけ返す。
  • 返り値の形は Nq×Nq×1×Norb（最後の軸がバンド）。DOS はこれを全 k・全バンドで平坦化し、FS は等高線に使う。
関連：load_Hamiltonian／diagonalize_Hamiltonian（Nonint の構築・対角化）／ plot_dos・plot_fermi_surface（この細メッシュ結果を使う）
plot_band_and_dos▶ 左に DOS（縦向き）・右に k-path バンドを手動 axes 配置で 1 枚に描く
plot_band_and_dos(simfile; out_png, ngrid=DOS_NGRID, sigma=DOS_SIGMA, epad=DOS_EPAD, plot_Nq=DOS_PLOT_NQ)

概要

nonint/kpath に保存された高対称点を結ぶ バンド（k-path）と、細メッシュから作った DOS を、 1 枚の図に横並びで描く。左に DOS を縦向き（横軸 DOS・縦軸エネルギー）、右にバンドを配置して、 同じ E-μ0 スケールで縦軸を揃える。kpath が無いファイルはスキップする。

コード

4_plot_nonint.jl · plot_band_and_dos
function plot_band_and_dos(simfile; out_png,
        ngrid=DOS_NGRID, sigma=DOS_SIGMA, epad=DOS_EPAD, plot_Nq=DOS_PLOT_NQ)
    local b, bandE, kdist, tick_pos, tick_label, ENERGY_diag
    h5open(simfile, "r") do f
        b = _read_basic(f)
        haskey(f, "nonint/kpath") || (println("No kpath; skip band+DOS."); return)
        g = f["nonint/kpath"]
        bandE = read(g["band_energy"]); kdist = read(g["kdist"])
        tick_pos = Int.(read(g["tick_pos"])); tick_label = String.(read(g["tick_label"]))
        ENERGY_diag = read(f["nonint/diag/ENERGY_diag"])
    end

    Nk, Norb = size(bandE)
    Eb = bandE .- b.mu0
    emin = minimum(Eb) - epad
    emax = maximum(Eb) + epad

    # DOS 用に細かいメッシュで再計算
    ED = plot_Nq === nothing ? ENERGY_diag : _recompute_energy_diag(b.hopping_path, b.Norb, plot_Nq)
    Nk_mesh = size(ED, 1) * size(ED, 2)
    E = vec(@view ED[:, :, 1, :]) .- b.mu0
    grid = collect(range(emin, emax; length=ngrid))
    dos = zeros(Float64, ngrid)
    @inbounds for ei in E, ig in 1:ngrid
        dos[ig] += _gauss(grid[ig] - ei, sigma)
    end
    dos ./= Nk_mesh

    # 左に DOS（細）、右にバンド（広）を手動配置
    fig = figure(figsize=(10.6, 4.4))
    left, right, bottom, top, gap, dos_w = 0.07, 0.985, 0.14, 0.88, 0.04, 0.14
    band_w = (right - left) - dos_w - gap
    ax_dos = fig.add_axes([left, bottom, dos_w, top - bottom])
    ax_band = fig.add_axes([left + dos_w + gap, bottom, band_w, top - bottom])

    ax_dos.plot(dos, grid, color="tab:blue", linewidth=1.4)
    ax_dos.axhline(0.0, color="k", linewidth=0.6, alpha=0.6)
    ax_dos.set_xlabel(@sprintf("DOS (σ=%.3g)", sigma))
    ax_dos.set_ylabel("E - μ₀")
    ax_dos.grid(alpha=0.15)
    ax_dos.set_ylim(emin, emax)
    ax_band.set_ylim(emin, emax)

    for ib in 1:Norb
        ax_band.plot(kdist, Eb[:, ib], linewidth=1.0, color="crimson")
    end
    ax_band.axhline(0.0, color="k", linewidth=0.6)
    ax_band.set_xlim(kdist[1], kdist[end])
    if !isempty(tick_pos)
        ax_band.set_xticks(kdist[tick_pos]); ax_band.set_xticklabels(tick_label)
        for p in tick_pos
            ax_band.axvline(kdist[p], color="gray", linestyle=":", linewidth=0.8, alpha=0.6)
        end
    end
    ax_band.set_xlabel("k-path")
    ax_band.tick_params(axis="y", labelleft=false)
    fig.suptitle("Non-interacting band + DOS", fontsize=12)
    savefig(out_png, dpi=240, bbox_inches="tight", pad_inches=0.06)
    close(fig)
    println("Saved: $out_png")
end

読み方（段階）

  • ① 読み込み： h5open(simfile, "r") do f … end で _read_basic・k-path のバンド band_energy・k 距離 kdist・高対称点の tick_pos/tick_label・格子の ENERGY_diag を取り出す。haskey(f, "nonint/kpath") || (…; return) で kpath が無ければ即スキップ。local で変数を do ブロック外へ持ち出す。
  • ② DOS 計算： ED = plot_Nq === nothing ? ENERGY_diag : _recompute_energy_diag(...) — 既定は細メッシュ再計算、plot_Nq=nothing のときだけ保存メッシュを流用。E = vec(@view ED[:, :, 1, :]) .- b.mu0 で全固有値を E-μ0 の 1 次元に平坦化し、_gauss を全点に足して dos ./= Nk_mesh で k 数で規格化。
  • ③ レイアウト： fig.add_axes([left, bottom, w, h]) を 2 回呼び、DOS 用（細幅 dos_w）とバンド用（残り幅 band_w）を手動配置。band_w = (right-left) - dos_w - gap で隙間 gap を空けて割り付ける。両軸とも set_ylim(emin, emax) で縦軸を共有。
  • ④ バンド描画： for ib in 1:Norb で各バンドを ax_band.plot(kdist, Eb[:, ib])。tick_pos があれば set_xticks/set_xticklabels で高対称点ラベルを付け、axvline で縦の区切り線を引く。tick_params(axis="y", labelleft=false) で右パネルの縦目盛りラベルを消して DOS 側と重複させない。
  • savefig(out_png, dpi=240, bbox_inches="tight") → close(fig) — PNG 保存して図を閉じる（メモリ解放）。
関連：_recompute_energy_diag（DOS 用の細メッシュ）／ _gauss（ブロードニング核）／ plot_dos（DOS 単体版）
plot_dos▶ DOS 単体。細メッシュで再計算した全固有値をガウスで畳んで描く
plot_dos(simfile; out_png, ngrid=DOS_NGRID, sigma=DOS_SIGMA, epad=DOS_EPAD, plot_Nq=DOS_PLOT_NQ)

概要

DOS だけを 1 枚に描くシンプル版。plot_band_and_dos の DOS 計算と同じ手順 （細メッシュ再計算 → 全固有値をガウスで畳む）だが、k-path バンドは描かず 横軸 E-μ0・縦軸 DOS の通常向きで表示する。タイトルに σ と rfill を添える。

コード

function plot_dos(simfile; out_png,
        ngrid=DOS_NGRID, sigma=DOS_SIGMA, epad=DOS_EPAD, plot_Nq=DOS_PLOT_NQ)
    local b
    h5open(simfile, "r") do f
        b = _read_basic(f)
    end
    ED = _recompute_energy_diag(b.hopping_path, b.Norb, plot_Nq)
    Nk_mesh = size(ED, 1) * size(ED, 2)
    E = vec(@view ED[:, :, 1, :]) .- b.mu0
    emin = minimum(E) - epad; emax = maximum(E) + epad
    grid = collect(range(emin, emax; length=ngrid))
    dos = zeros(Float64, ngrid)
    @inbounds for ei in E, ig in 1:ngrid
        dos[ig] += _gauss(grid[ig] - ei, sigma)
    end
    dos ./= Nk_mesh

    fig = figure(figsize=(5.6, 4.2))
    plot(grid, dos, color="crimson", linewidth=1.6)
    axvline(0.0, color="k", linewidth=0.8, alpha=0.7)
    xlabel("E - μ₀"); ylabel("DOS (per k-sum)")
    title(@sprintf("Non-int DOS (σ=%.3g)  rfill=%.3f", sigma, b.rfill), fontsize=11)
    tight_layout()
    savefig(out_png, dpi=240, bbox_inches="tight", pad_inches=0.06)
    close(fig)
    println("Saved: $out_png")
end

読み方

  • _read_basic だけ読めば十分なので do ブロックは短い。以降は必ず _recompute_energy_diag で細メッシュ再計算（plot_Nq 分岐なし）。
  • DOS の作り方（E を平坦化 → _gauss を全点に加算 → Nk_mesh で規格化）は plot_band_and_dos の②と同一。
  • plot(grid, dos) — こちらは横軸エネルギー・縦軸 DOSの通常向き。axvline(0.0) でフェルミ準位 E-μ0=0 を示す。
  • title(@sprintf("… σ=%.3g rfill=%.3f", sigma, b.rfill)) — Printf の書式でパラメータを埋め込む。
関連：plot_band_and_dos（バンドと併記する版）／ _gauss・_recompute_energy_diag
plot_fermi_surface▶ E(k)-μ0=0 の等高線でフェルミ面を描く（BZ 外周・高対称点つき）
plot_fermi_surface(simfile; out_png, plot_Nq=FS_PLOT_NQ, axis_unit=:pi, force_lim=(-1.5, 1.5), supercell_range=1)

概要

各バンドの E(k)-μ0 を 2 次元の kx-ky 平面に並べ、 0 の等高線（contour(levels=[0.0])）を引くことでフェルミ面を描く。 lattice の幾何ヘルパで BZ メッシュと外周を作り、circshift で Γ を中心に置き、隣接 BZ を supercell_range だけタイル複製して連続したフェルミ面を見せる。 高対称点も散布する。

コード

4_plot_nonint.jl · plot_fermi_surface
function plot_fermi_surface(simfile; out_png, plot_Nq=FS_PLOT_NQ,
        axis_unit=:pi, force_lim=(-1.5, 1.5), supercell_range=1)
    local b, lattice_type, b1, b2, has_kpath, kfrac, tick_pos, tick_label
    h5open(simfile, "r") do f
        b = _read_basic(f)
        gl = f["nonint/lattice"]
        lattice_type = String(read(gl["lattice_type"]))
        b1 = _as3(read(gl["b1"])); b2 = _as3(read(gl["b2"]))
        has_kpath = haskey(f, "nonint/kpath")
        if has_kpath
            gk = f["nonint/kpath"]
            kfrac = read(gk["k_frac"])
            tick_pos = Int.(read(gk["tick_pos"])); tick_label = String.(read(gk["tick_label"]))
        end
    end

    ED = _recompute_energy_diag(b.hopping_path, b.Norb, plot_Nq)  # Nq×Nq×1×Norb
    Nqx = size(ED, 1); Nqy = size(ED, 2); Norb = b.Norb

    # k=(0,0) を中央に来るよう circshift
    shiftx, shifty = Nqx ÷ 2, Nqy ÷ 2
    ENERGY_plot = circshift(ED, (shiftx, shifty, 0, 0))
    mesh = _build_kmesh_cart(Nqx, Nqy; b1=b1, b2=b2, supercell_range=0, center_bz=true)

    scale = axis_unit == :pi ? (1/π) : 1.0
    Xp = mesh.X .* scale; Yp = mesh.Y .* scale
    bz = _build_bz_mask(mesh.X, mesh.Y; lattice_type=lattice_type, b1=b1, b2=b2, mask_to_bz=false)
    bx, by = bz.bx .* scale, bz.by .* scale
    shifts = [(m, n) for m in -supercell_range:supercell_range, n in -supercell_range:supercell_range]

    fig = figure(figsize=(5.6, 4.8))
    for ib in 1:Norb
        Z = permutedims(ENERGY_plot[:, :, 1, ib] .- b.mu0, (2, 1))  # (Nqy,Nqx)
        for (m, n) in shifts
            dx = (m*b1[1] + n*b2[1]) * scale
            dy = (m*b1[2] + n*b2[2]) * scale
            contour(Xp .+ dx, Yp .+ dy, Z; levels=[0.0], colors="crimson", linewidths=1.6)
        end
    end
    plot(bx, by, color="k", linestyle="--", linewidth=1.2, alpha=0.9)  # BZ 境界

    # 高対称点
    if has_kpath && !isempty(tick_pos)
        for (p, lab) in zip(tick_pos, tick_label)
            (1 <= p <= size(kfrac, 1)) || continue
            xk = (kfrac[p, 1]*b1[1] + kfrac[p, 2]*b2[1]) * scale
            yk = (kfrac[p, 1]*b1[2] + kfrac[p, 2]*b2[2]) * scale
            scatter([xk], [yk], s=30, c="k", zorder=10)
            isempty(lab) || text(xk, yk, lab, fontsize=10, ha="left", va="bottom")
        end
    end

    if force_lim !== nothing
        xlim(force_lim...); ylim(force_lim...)
    end
    gca().set_aspect("equal", adjustable="box")
    title(@sprintf("Non-int FS (E=μ₀)  lattice=%s  rfill=%.3f", lattice_type, b.rfill), fontsize=11)
    xlabel(axis_unit == :pi ? "k_x/π" : "k_x")
    ylabel(axis_unit == :pi ? "k_y/π" : "k_y")
    tight_layout()
    savefig(out_png, dpi=240, bbox_inches="tight", pad_inches=0.08)
    close(fig)
    println("Saved: $out_png")
end

読み方（段階）

  • ① 読み込み： _read_basic に加え nonint/lattice から格子種 lattice_type と逆格子ベクトル b1, b2（_as3 で 3 成分に整形）を読む。k-path があれば分数座標 k_frac と高対称点情報も取得。
  • ② 細メッシュ再計算＋Γ 中心化： _recompute_energy_diag で Nq×Nq×1×Norb の固有値を作り、circshift(ED, (Nqx÷2, Nqy÷2, 0, 0)) で k=(0,0) を配列の中央へ移動（fftfreq 並びの原点を絵の中心に持ってくる）。
  • ③ BZ メッシュ・外周： _build_kmesh_cart でカルテシアン格子 X, Y を、_build_bz_mask（mask_to_bz=false）で BZ 外周 bx, by を得る。scale = axis_unit==:pi ? 1/π : 1.0 で軸を k/π 単位に換算。
  • ④ 等高線＝フェルミ面： 各バンドで Z = permutedims(ENERGY_plot[…] .- b.mu0, (2,1))（contour の (row,col)=(y,x) 規約に合わせて転置）を作り、contour(...; levels=[0.0]) で E-μ0=0 の 1 本の等高線を引く。shifts で隣接 BZ 分だけ (m·b1+n·b2) ずらしてスーパーセル的にタイル複製し、切れ目のないフェルミ面にする。
  • ⑤ 高対称点： tick_pos/tick_label があれば (1 <= p <= size(kfrac, 1)) の範囲チェック後、k_frac を b1, b2 でカルテシアンに変換して scatter＋text でラベル表示。
  • ⑥ 仕上げ： force_lim で表示範囲を固定、set_aspect("equal") で縦横比を 1:1 に（フェルミ面の形が歪まない）。タイトルに格子種と rfill、軸ラベルは axis_unit に応じて k_x/π か k_x。
関連：_as3／_build_kmesh_cart／_build_bz_mask（BZ 幾何）／ _recompute_energy_diag（細メッシュ固有値）
main▶ Noint/ を作り、band+DOS・DOS・FS の 3 枚を順に出力するエントリポイント
main() # simulation.h5 → Noint/ に 3 枚の PNG

概要

スクリプトのエントリポイント。mkpath(OUTDIR) で出力ディレクトリ Noint/ を用意し、 plot_band_and_dos・plot_dos・plot_fermi_surface を順に呼んで band_kpath_dos.png・dos.png・fs.png を出力する。ファイル末尾で main() を実行する。

コード

4_plot_nonint.jl · main
function main()
    println("--- Plot non-interacting from $SIM_FILENAME ---")
    mkpath(OUTDIR)
    plot_band_and_dos(SIM_FILENAME; out_png=joinpath(OUTDIR, "band_kpath_dos.png"))
    plot_dos(SIM_FILENAME;          out_png=joinpath(OUTDIR, "dos.png"))
    plot_fermi_surface(SIM_FILENAME; out_png=joinpath(OUTDIR, "fs.png"))
end

main()

読み方

  • mkpath(OUTDIR) — Noint/ が無ければ作る（既にあっても失敗しない）。
  • joinpath(OUTDIR, "….png") — OS に依らないパス連結で出力先を組み立て、各 plot_* に out_png として渡す。
  • 3 関数はいずれも同じ simulation.h5 を独立に開いて読む（状態を共有しない素直な構成）。
  • 末尾の main() — julia 4_plot_nonint.jl で読み込むと同時に実行される。
関連：3 つの plot_* 関数（出力の実体）
なぜ細メッシュで描き直すのか： DOS とフェルミ面は、保存済みの粗い k メッシュのままだと ガウス幅より粗くてギザギザになったり等高線が途切れたりする。そこで _recompute_energy_diag で DOS_PLOT_NQ／FS_PLOT_NQ（=256）の細メッシュに H(k) を作り直してから対角化することで、 なめらかな DOS 曲線と連続したフェルミ面が得られる。バンド（k-path）だけは元々連続なので再計算しない。
ENV["MPLBACKEND"]="Agg" は using PyPlot の前に： Matplotlib のバックエンドは インポート時に確定するため、Agg（画面を持たないファイル出力用バックエンド）を選ぶ設定は必ず using PyPlot より前に置く。順序を逆にすると GUI バックエンドが選ばれ、ディスプレイの無い サーバ（ヘッドレス環境）で figure() が失敗し得る。バッチで PNG を吐くだけならこの設定が必須。
