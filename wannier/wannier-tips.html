ディスエンタングルメント・初期射影のコツ

— frozen / outer window 設定と収束Tips —

ディスエンタングルメントとは

対象バンドが他のバンドと交差・混成している場合、単純なユニタリ変換では分離できない。Souza, Marzari, Vanderbilt (2001) のディスエンタングルメント手続きにより、エネルギーウィンドウ内のバンドから最適なサブスペースを選び出す。

outer window (dis_win_min ～ dis_win_max)
  ↑ この範囲のバンドを混ぜてよい

  ┌─────────────────────────────────────┐
  │  frozen window (dis_froz_min ～ max) │  ← この範囲は必ず含む
  └─────────────────────────────────────┘
  ↓ outer にあって frozen 外のバンドは取捨選択される

ウィンドウの設定指針

Frozen window の決め方

フェルミ面を正確に再現したい場合は、フェルミエネルギーを完全に含む範囲に frozen window を設定する。

dis_froz_min = -1.5   # フェルミ面の下（eV）
dis_froz_max =  1.0   # フェルミ面の上（eV）
frozen window を広くしすぎると不要なバンドまで固定されてスプレッドが増加する。VASP の DOS を見ながら対象軌道の占有域に合わせて設定する。

Outer window の決め方

対象バンドが完全に収まるよう設定する。ディスエンタングルメントに使うバンド数（num_bands）はウィンドウ内の全バンド数を指定する。

dis_win_min  = -6.0   # 価電子帯の下端より少し低く
dis_win_max  =  4.0   # 対象バンドの上端より少し高く
num_bands    = 20     # ウィンドウ内のバンド総数

初期射影の設定

軌道の指定方法

begin projections
  # 元素:軌道[:磁気量子数]
  Fe : d          # 全 d 軌道（5 本）
  Fe : d,eg       # eg のみ（2 本）
  Fe : d,t2g      # t2g のみ（3 本）
  O  : p          # 全 p 軌道（3 本）
  C  : pz         # π 軌道のみ
  Si : sp3        # sp3 混成（4 本）
end projections

座標を使った指定

begin projections
  # f=0.5,0.5,0.5 の位置に d 軌道を置く（原子がない位置にも設定可）
  f=0.5,0.5,0.5 : dxy
end projections

収束しないときのチェックリスト

スプレッド Ω が減らない・発散する

  • 初期射影を変える（より化学的に自然な軌道に）
  • frozen window を狭くして自由度を増やす
  • dis_num_iter（ディスエンタングルメントのイテレーション数）を増やす（デフォルト: 200）
  • num_iter（局在化のイテレーション数）を増やす（デフォルト: 100）
  • k グリッドを細かくする

バンドが DFT 結果と合わない

  • outer window を広げて、ずれているバンドを取り込む
  • num_wann を増やす（近接バンドとの混成を考慮）
  • Wannier 関数のプロットで形状を確認し、物理的に妥当かチェック
  • SOC がある場合は spinors = true を設定しているか確認

Wannier 関数の形状を確認する

wannier_plot = true
wannier_plot_supercell = 3   # スーパーセル数

# 出力: seedname_00001.xsf など → VESTA で表示
収束の確認は .wout 内の "Cycle:" 行でスプレッド Ω の推移を見る。最後の数イテレーションで変化が 10⁻⁸ 以下になれば十分収束している。
