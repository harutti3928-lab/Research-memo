バンド補間・有効ハミルトニアン

— タイトバインディング展開と k 点補間 —

Wannier 有効ハミルトニアン

Wannier 関数を基底とした実空間ハミルトニアン H(R) は、第一原理計算のバンド構造を正確に再現するタイトバインディングモデルとして機能する：

H_{mn}(R) = ⟨w_m0| H |w_nR⟩

任意の k 点でのバンドエネルギーは：

H(k) = Σ_R e^{ik·R} H(R)

E_n(k) : H(k) の固有値

H(R) は seedname_hr.dat に格納される。実空間で減衰するため、十分遠くの R での値はほぼゼロになる。

_hr.dat ファイルの読み方

# seedname_hr.dat の形式
# コメント行
# Wannier 関数の数
# 縮退度の行
# Rx  Ry  Rz  n  m  Re(H)  Im(H)

import numpy as np

def read_hr(filename):
    with open(filename) as f:
        f.readline()          # コメント
        nwann = int(f.readline())
        nrpts = int(f.readline())
        # 縮退度を読む
        degen = []
        while len(degen) < nrpts:
            degen += list(map(int, f.readline().split()))
        # ホッピングを読む
        hoppings = np.loadtxt(f)
    return nwann, nrpts, np.array(degen), hoppings
