VASPとの連携手順

— LWANNIER90 フラグ・wannier90.win の設定 —

全体の流れ

1. VASP SCF 計算（稠密 k グリッド）
2. VASP NSCF 計算（Wannier90 用 k グリッド）
   INCAR に LWANNIER90 = .TRUE.
3. wannier90.win の作成・編集
4. wannier90 -pp seedname  （前処理：NNKP ファイル生成）
5. VASP を再度実行（vaspwann 計算）
6. wannier90 seedname       （Wannier 関数の最局在化）
7. 出力ファイルの確認・可視化

VASP 側の設定

1

INCAR の設定

LWANNIER90 = .TRUE.     # Wannier90 インターフェースを有効化
LWRITE_MMN_AMN = .TRUE. # MMN・AMN ファイルの出力
NSW    = 0
IBRION = -1
ICHARG = 11   # SCF の CHGCAR を使用
2

KPOINTS の設定

Wannier90 では Monkhorst-Pack グリッドを使う。高対称点パスは不可。

Automatic
0
Gamma
  8 8 8
  0 0 0
k 点数は wannier90.win の mp_grid と一致させる必要がある。

wannier90.win の書き方

最小限の設定（SrVO₃ の t₂g モデルの例）

num_wann   = 3          # Wannier 関数の数
num_bands  = 16         # 考慮するバンド数（全価電子バンド）

# エネルギーウィンドウ（eV, フェルミ面基準）
dis_win_max  =  2.5
dis_win_min  = -5.0
dis_froz_max =  1.0     # Frozen window の上端
dis_froz_min = -0.5

# 初期射影（原子番号・軌道を指定）
begin projections
  V : d,t2g
end projections

# k 点グリッド（KPOINTS と一致させる）
mp_grid = 8 8 8

# 格子定数と原子座標
begin unit_cell_cart
bohr
  7.26  0.00  0.00
  0.00  7.26  0.00
  0.00  0.00  7.26
end unit_cell_cart

begin atoms_frac
  Sr  0.0  0.0  0.0
  V   0.5  0.5  0.5
  O   0.5  0.5  0.0
  O   0.5  0.0  0.5
  O   0.0  0.5  0.5
end atoms_frac

出力ファイルの確認

seedname.wout        ← ログ。スプレッド Ω の収束を確認
seedname_hr.dat      ← ホッピングパラメータ（メインの出力）
seedname_band.dat    ← バンド補間の結果（bands_plot = true の場合）
seedname.chk         ← チェックポイント（中断・再開用）

収束の確認方法

# .wout の末尾を確認
grep "Final State" seedname.wout
grep "WF centre" seedname.wout | tail -5

# スプレッド Ω が安定して減少していれば収束
初期射影が悪いと Ω が収束しないか、意図しない軌道に収束する。wannier_plot = true で Wannier 関数の形状（XSF ファイル）を VESTA で確認すること。
