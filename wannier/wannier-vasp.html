VASPとの連携手順

— LWANNIER90 フラグ・wannier90.win の設定 —

全体の流れ

VASP は Wannier90 をライブラリとしてリンク済みとする。LWANNIER90_RUN を使うと、VASP の対角化に続けてワニエ化までを 1 回の投入（qsub）でインライン実行できる。別途 wannier90 -pp を回す必要はない。

1. SCF 計算をしたフォルダを cp -r でコピー（例: wan）。以降は wan 内で作業。
2. wan/INCAR を書き換える
     ICHARG = 1 / ISYM = -1 / NBANDS / NELMIN を設定
     LWANNIER90 / LWANNIER90_RUN / LWRITE_MMN_AMN = .TRUE.
     NUM_WANN と WANNIER90_WIN（win の中身）を追記
3. qsub で投入（memory に余裕のある node を指定）
     → VASP 対角化 ＋ ワニエ化がインラインで一括実行される
4. wannier90_band.dat と第一原理バンドを重ねてフィットを確認
5. ウィンドウを調整（wannier90.win だけ編集して wannier90 単独で再実行。VASP は回さない）

INCAR の書き換え

SCF フォルダをコピーした前提で、追記・変更するタグは次のとおり。

ICHARG = 1              # SCF の charge density を読み込んで start
ISYM   = -1             # 結晶対称性を使わない（w90 の仕様上、必須）
NBANDS = 48             # 念のため多め（unoccupied band まで確保）
NELMIN = 6              # unoccupied まで収束させるため最低 6 回 SCF ループを回す

LWANNIER90     = .TRUE. # ワニエ化を有効化
LWANNIER90_RUN = .TRUE. # w90 をインライン実行
LWRITE_MMN_AMN = .TRUE. # MMN・AMN ファイルを出力
NUM_WANN = 4            # Wannier の本数
ISYM = -1 は必須。Wannier90 は対称化していない一様な k メッシュ上の波動関数を要求するため、対称性を切る。KPOINTS は Γ 中心の一様メッシュにする。

WANNIER90_WIN（win の中身を INCAR に埋め込む）

VASP 6.2 以降は独立した wannier90.win の読み込みが壊れているため、win の中身を WANNIER90_WIN タグに直接埋め込む。以下は BC₃（B:pz の 4 軌道モデル）の例。

WANNIER90_WIN = "
Begin Projections
B:pz
End Projections
exclude_bands : 1-30
dis_win_min = -2.7
dis_win_max = 4.0
dis_froz_min = -2.6
dis_froz_max = -1.0
dis_num_iter = 10000
num_iter = 0
guiding_centres = true
write_hr = true
bands_plot   = true
begin kpoint_path
G 0.0 0.0 0.0 M 0.5 0.0 0.0
M 0.5 0.0 0.0  K 0.33333333 0.33333333 0.0
K 0.33333333 0.33333333 0.0 G 0.0 0.0 0.0
end kpoint_path
bands_num_points 50
bands_plot_format gnuplot
"
埋め込み時の注意：
・" は必ず半角のクォーテーションにする（全角 “” はエラー）。
・WANNIER90_WIN = " 〜 閉じ " の間に他の INCAR パラメータを挟まない。
・コピペ時に Slack の (edited) のようなコメントが混入しないよう注意。
・K の座標が 1/3, 1/3, 0 でない場合は、バンド計算時の KPOINTS を見て kpoint_path を直す。

投入時のメモ

memory をそこそこ使う可能性があるので、qhost で使用量に余裕のある node を確認し、それを指定して投げるほうが無難。

ウィンドウの調整

ワニエ化のウィンドウは、まず仮の値で回してから、バンドの重なり具合を見て調整する。理論的な背景は ディスエンタングルメント・初期射影のコツ も参照。

outer window（dis_win_min / dis_win_max）

outer window は、この範囲にあるバンドの線型結合でワニエ軌道を表す。したがって再現したいバンドを含むように取る必要がある。広すぎてもうまくいかないので、いろいろ試すとよい。動かすのは通常 dis_win_max 側で、dis_win_min をいじる必要はないはず。

frozen window（dis_froz_min / dis_froz_max）

frozen（inner）window は、この中に入ったバンドをなるべく厳密に再現するように局在化が行われる。したがって関係ないバンドをこの窓に入れてはいけない。必然的に outer window より狭くなり、そうしないとエラーで止まる。こちらも動かすのは dis_froz_max 側で、min を動かす必要はないはず。

VASP の場合、ウィンドウのエネルギーは EF を引く前の絶対値（wannier90.eig の値）で指定する。バンド図で EF を引いてプロットしている場合は、その分を足し戻した値を使うこと。

調整の回し方

ウィンドウを変えるだけなら VASP を回す意味はない。INCAR は変更せず、wannier90.win の該当パラメータだけを書き換えて、ワニエ化だけを再実行する。VASP は回さないので、今までの qsub ファイルは使わない。

# wannier90 を単独で再実行（VASP は回さない）
wannier90.x wannier90

フィットの確認

ワニエ化で得た tight-binding バンド wannier90_band.dat と、第一原理バンドを重ねてフィットを確認する。frozen window の中は厳密一致であるべき。ずれていたらウィンドウか射影を調整する。

wannier90.wout        ← スプレッド Ω の収束を確認（pz なら数 Å² 程度）
wannier90_hr.dat      ← 実空間ホッピング H(R)（FLEX の入力）
wannier90_band.dat    ← ワニエ補間バンド（1 列目が k 経路の座標）
wannier90_band.gnu    ← 特殊 k 点の位置（縦線）が分かる。重ね描きの目盛りに使う
wannier90_band.dat の 1 列目（k 点座標）だけでは、どこが G / M / K か分からない。wannier90_band.gnu の xtics を見れば、各特殊 k 点が経路上のどの位置に対応するか分かるので、DFT バンドと横軸を揃えて重ねられる。
