Wannier関数とは

— Bloch 関数と最局在 Wannier 関数 (MLWF) —

Wannier 関数の定義

Bloch 関数 ψ_{nk}(r) を逆格子空間からフーリエ変換することで、実空間に局在した Wannier 関数 w_n(r - R) が得られる：

w_n(r - R) = V/(2π)³ ∫_BZ dk e^{-ik·R} ψ_{nk}(r)

R : 格子ベクトル
n : バンド（Wannier 軌道）インデックス

逆に Bloch 関数は Wannier 関数のフーリエ変換として書ける：

ψ_{nk}(r) = Σ_R e^{ik·R} w_n(r - R)

ゲージ自由度と局在化

Bloch 関数は位相（ゲージ）の自由度を持つ。複数バンドが縮退または混在する場合は、バンド間のユニタリ変換（混合）も許される：

|ũ_{nk}⟩ = Σ_m U_{mn}(k) |u_{mk}⟩

この自由度を使って、Wannier 関数の空間的広がり（スプレッド）を最小化するのが 最局在 Wannier 関数（MLWF） である。

スプレッド汎関数

Ω = Σ_n [ ⟨r²⟩_n - ⟨r⟩_n² ]

Ω = Ω_I + Ω̃

Ω_I : ゲージ不変部分（バンドの本質的な広がり）
Ω̃  : ゲージ依存部分（最小化でゼロに近づける）

Wannier90 は Marzari-Vanderbilt (1997) の手法でこの汎関数を勾配降下法で最小化する。

Wannier 関数と原子軌道の対応

MLWF は、d 軌道・p 軌道・sp³ 混成軌道などと対応することが多く、化学的な直観と結びつけやすい。これが Wannier 関数を有効ハミルトニアンや DMFT 計算のベースに使う理由でもある。

例：
  SrVO₃（ペロブスカイト）→ V の t_{2g} 軌道（3 本の Wannier 関数）
  グラフェン          → C の π 軌道（2 本）
  Si（ダイヤモンド構造）→ sp³ 混成（4 本）

Wannier 関数の用途

  • バンド補間：粗い k グリッドの第一原理計算から稠密な k パス上のバンドを再構成
  • 有効ハミルトニアン：タイトバインディングモデルのホッピングパラメータの抽出
  • Berry 位相・トポロジカル量：Chern 数、表面状態のサーフェス Green 関数
  • DMFT への入力：低エネルギー有効モデルとして DMFT・FLEX 計算に使う
  • 輸送特性：BoltzWann モジュールによる電気伝導率・Seebeck 係数の計算
Wannier90 の出力ファイル seedname_hr.dat がホッピングパラメータ t_{ij} を格納する。これが多体計算（FLEX, DMFT）や輸送計算の入力として最もよく使われる。
