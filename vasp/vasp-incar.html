INCARタグまとめ

— よく使うタグと設定の目安  |  タグ名をクリックで詳細表示 —

基本設定

タグ説明典型値
SYSTEM ▶計算の説明文（任意）自由記述
ISTART ▶ジョブの開始モード。0: ゼロから開始、1: WAVECAR を読んで初期値に利用0
ICHARG ▶初期電荷密度の取得方法。2: 原子重ね合わせ（デフォルト）、11: CHGCAR 固定（バンド計算）2 / 11
ENCUT ▶平面波カットオフエネルギー（eV）。POTCAR の ENMAX の 1.3 倍が目安400–600
EDIFF ▶SCF 収束判定のエネルギー閾値（eV）1E-6
EDIFFG ▶構造最適化の収束判定。負値にするとイオン力の閾値（eV/Å）-0.01
NSW ▶イオン最適化のステップ数。0 で静的計算0 / 100
IBRION ▶イオン更新アルゴリズム。2: CG、3: damped MD、-1: 固定2
ISIF ▶体積・形状の最適化フラグ。2: 原子位置のみ、3: 全最適化2 / 3
LATTICE_CONSTRAINTS ▶格子ベクトルの変化を方向ごとに制限する。2D材料や液体 NpT-MD に有用.TRUE. .TRUE. .FALSE.

電子構造・収束設定

タグ説明典型値
ISMEAR ▶スメアリング手法。金属: 1（Methfessel-Paxton）、絶縁体: 0（Gaussian）、DOS: -5（テトラへドロン）1 / 0 / -5
SIGMA ▶スメアリング幅（eV）。小さすぎると収束不安定0.1–0.2
NELM ▶SCF 最大ループ数100–200
NELMIN ▶SCF 最小ループ数（初期振動を防ぐ）6
ALGO ▶電子最適化アルゴリズム。Normal: RMM-DIIS、Fast: RMM+DIAG、All: blocked DavidsonNormal / Fast
PREC ▶計算精度プリセット。Normal で大半は OK、Accurate で FFT グリッド倍密度Normal / Accurate
LREAL ▶実空間射影。Auto: 自動選択（大系では True が速い）Auto
ISYM ▶対称性の使い方。2: PAW 標準（推奨）、-1: 完全無効化2
ADDGRID ▶.TRUE. で補助グリッドを追加。磁性・d/f 電子系でラップアラウンドエラーを抑制.TRUE.
GGA_COMPAT ▶PAW 1 中心項の勾配計算方式。.FALSE. が新しく正確な実装.FALSE.
LASPH ▶.TRUE. で PAW 1 中心項の非球面補正を有効化。d/f 電子に重要.TRUE.

スピン・磁性

タグ説明典型値
ISPIN ▶スピン分極計算。1: 非スピン分極、2: スピン分極1 / 2
MAGMOM ▶各原子の初期磁気モーメント（μB）例: 3 0 0
LSORBIT ▶.TRUE. でスピン軌道結合 (SOC) を有効化.TRUE.
SAXIS ▶SOC での量子化軸方向0 0 1

汎関数・ハイブリッド・DFT+U

タグ説明典型値
GGA ▶交換相関汎関数の種類。PE: PBE、PS: PBEsolPE
LDAU ▶.TRUE. で DFT+U を有効化.TRUE.
LDAUTYPE ▶+U の形式。2: Dudarev (単一 U-J パラメータ)2
LDAUU ▶各種の U 値（eV）例: 0 4 0
HFSCREEN ▶HSE06 のスクリーニング長。0.2 Å⁻¹ が HSE060.2
AEXX ▶交換汎関数の HF 混合率。HSE06: 0.250.25
IVDW ▶van der Waals 分散力補正。12: DFT-D3(BJ)（一般推奨）、0: 無効0 / 12

出力制御

タグ説明典型値
LORBIT ▶投影 DOS の出力。11: lm 成分あり、10: l 成分のみ11
NEDOS ▶DOS のエネルギーグリッド数2000
LWAVE ▶.FALSE. で WAVECAR の出力を抑制（ディスク節約）.FALSE.
LCHARG ▶.FALSE. で CHGCAR 出力を抑制.FALSE.
NWRITE ▶OUTCAR への出力頻度。0: 最小限、2: 標準2

バンド構造計算用 INCAR 例

SYSTEM = band structure calc
ENCUT  = 500
PREC   = Accurate
EDIFF  = 1E-6

NSW    = 0
IBRION = -1
GGA = PE
ISIF = 8
EDIFFG = -0.01
IVDW = 12 

ISMEAR = 0
SIGMA  = 0.05

ICHARG = 2
ISTART = 0

ISPIN = 1
LORBIT = 11
LWAVE  = .FALSE.
LCHARG = .FALSE.

ISYM = 2
LREAL = .FALSE.
ADDGRID = .TRUE.
GGA_COMPAT = .FALSE.
LASPH = .TRUE.
バンド計算では事前にSCF計算で CHGCAR を作成し、本計算で ICHARG = 11（電荷密度を固定）を指定する。KPOINTS には高対称点パスを手書きか vaspkit/pymatgen で生成する。
