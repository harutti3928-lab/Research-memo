IBRIONイオン更新アルゴリズム。2: CG、3: damped MD、-1: 固定2

バンド構造計算用 INCAR 例

SYSTEM = band structure calc
ENCUT  = 500
PREC   = Normal
EDIFF  = 1E-6
NSW    = 0
IBRION = -1

ISMEAR = 0
SIGMA  = 0.05

LORBIT = 11
LWAVE  = .FALSE.
LCHARG = .FALSE.
バンド計算では事前にSCF計算で CHGCAR を作成し、本計算で ICHARG = 11（電荷密度を固定）を指定する。KPOINTS には高対称点パスを手書きか vaspkit/pymatgen で生成する。
