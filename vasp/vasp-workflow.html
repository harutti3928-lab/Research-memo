計算の流れ

— 構造最適化 → 電子構造 → DOS —

ファイル構成の確認

VASP の計算には最低 4 つの入力ファイルが必要。

計算ディレクトリ/
├── POSCAR   ← 結晶構造（格子定数・原子座標）
├── INCAR    ← 計算パラメータ
├── KPOINTS  ← k 点サンプリング設定
└── POTCAR   ← PAW ポテンシャル（各元素を連結）

Step 1 : 構造最適化

1

POSCAR の準備

CIF ファイルから pymatgen や VESTA で変換するのが一般的。Direct 座標（分率座標）で記述するのが推奨。

Si_diamond
   5.47
   0.5 0.5 0.0
   0.0 0.5 0.5
   0.5 0.0 0.5
Si
2
Direct
  0.00 0.00 0.00
  0.25 0.25 0.25
2

INCAR の設定（構造最適化用）

ENCUT  = 500
EDIFF  = 1E-6
EDIFFG = -0.01   # 力の閾値 eV/Å
NSW    = 100
IBRION = 2       # CG 法
ISIF   = 3       # セル形状も最適化
ISMEAR = 1
SIGMA  = 0.1
3

収束の確認

OUTCAR の末尾の "reached required accuracy" を確認。または：

grep "reached required" OUTCAR
grep "TOTEN" OUTCAR | tail -5

最適化後の構造は CONTCAR に書き出される。次のステップでは CONTCAR を POSCAR に改名して使う。

Step 2 : セルフコンシステント計算 (SCF)

バンド構造・DOS 計算の前に、稠密な k グリッドで SCF を行い CHGCAR を作成する。

INCAR (SCF 用の変更点)
-----------------------
NSW    = 0
IBRION = -1
ICHARG = 2   # 重ね合わせ電荷密度から開始（デフォルト）
LCHARG = .TRUE.
LWAVE  = .FALSE.
KPOINTS (Monkhorst-Pack)
-----------------------
Automatic
0
Gamma
  8 8 8
  0 0 0

Step 3 : バンド構造計算

1

高対称点パスの準備

KPOINTS に line-mode で記述する。pymatgen の HighSymmKpath や vaspkit (option 302) で自動生成できる。

k-points along high symmetry lines
40         # 各セグメントの分割数
Line-mode
Reciprocal
  0.0 0.0 0.0   ! Γ
  0.5 0.0 0.0   ! X

  0.5 0.0 0.0   ! X
  0.5 0.5 0.0   ! M
...
2

INCAR (バンド計算用)

NSW    = 0
ICHARG = 11   # SCF の CHGCAR を読み込み、電荷固定
LORBIT = 11
LWAVE  = .FALSE.
LCHARG = .FALSE.
3

プロット

EIGENVAL と KPOINTS から pymatgen (BSPlotter) や vaspkit でプロットする。

Step 4 : 状態密度 (DOS) 計算

INCAR (DOS 用)
--------------
NSW    = 0
ICHARG = 11
ISMEAR = -5   # 改良テトラへドロン法（DOS に適切）
SIGMA  = 0.1
LORBIT = 11
NEDOS  = 2000
EMIN   = -10
EMAX   =  10

KPOINTS は SCF より稠密なグリッドを推奨（例: 12×12×12）。出力は DOSCAR および vasprun.xml から読む。

DOS 計算で ISMEAR = -5 にする場合は k グリッドをガンマ中心かつ十分稠密にすること。金属で k 数が少ないと不正確な結果が出る。
