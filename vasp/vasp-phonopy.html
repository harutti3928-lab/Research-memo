フォノン計算（phonopy）

— 有限変位法, フォノンバンド, 不安定モード —

そもそもフォノン計算とは

結晶中の原子は絶対零度でも平衡位置の周りで振動している。この格子振動を量子化したものがフォノンである。フォノン計算とは、「どんな振動モードが、どの振動数で存在するか」を第一原理から求める計算のことを指す。

出発点は結晶の全エネルギー E を、各原子の平衡位置からの変位 u について Taylor 展開することにある。平衡点では 1 次の項（力）がゼロなので、2 次の項までで打ち切る（調和近似）：

E = E₀ + (1/2) Σ Φ_{iα,jβ} u_{iα} u_{jβ} + …

Φ_{iα,jβ} = ∂²E / ∂u_{iα} ∂u_{jβ}   ← 力の定数（force constants）

ここで i, j は原子、α, β はデカルト方向。力の定数 Φ は「原子 i を α 方向に動かしたとき、原子 j に β 方向へどれだけ力（の傾き）が生じるか」を表す。

周期系では波数 q のフォノンを考え、力の定数から動力学行列 D(q) を組む。これを対角化すると、固有値が振動数の 2 乗、固有ベクトルが各原子の変位パターン（偏光ベクトル）になる：

D(q) e = ω²(q) e

  固有値 ω²(q) → 振動数（フォノンバンド）
  固有ベクトル e → 各原子がどう動くか（変位パターン）

何のために計算するのか

  • 格子の熱力学量：自由エネルギー・比熱・熱膨張などをフォノン状態密度から求める。
  • 構造の安定性判定：すべての ω² > 0 なら力学的に安定。ω² < 0（＝振動数が虚数）のモードがあれば、その構造は不安定。
  • 電子–フォノン結合・超伝導：α²F(ω) や λ の計算（Eliashberg 方程式）の入力になる。
虚の振動数（イマジナリーモード）とは、D(q) の固有値が負になり ω が虚数になったモードのこと。バンド図では慣習的にマイナス側に描かれる。このモードに沿って原子を動かすとエネルギーが下がる＝より安定な構造（相転移先）が存在することを意味する。後半で扱う。

有限変位法（スーパーセル法）の考え方

力の定数 Φ を解析的に求めるのは難しいので、実際に原子を少しずらして、生じる力を VASP で測るという素朴な方法を使う。これが有限変位法（frozen phonon 法）。

原子 i を u だけ変位 → 各原子に働く力 F_j を VASP で計算
                     → Φ_{ij} ≈ − F_j / u   （Hellmann-Feynman 力）

ただし単位胞 1 個だけで原子を動かすと、周期境界条件のせいで「変位した原子」と「その周期像」が近すぎて干渉してしまう。そこで単位胞を何個か並べたスーパーセルを組み、遠くまで届く力の定数を拾えるようにする。

スーパーセルの大きさと波数の関係

  • 長波長（小さな q、Γ 点近傍）のフォノン → 原子がゆっくり波打つので、小さいスーパーセルでも十分。
  • 短波長（大きな q）のフォノン → 隣り合う原子が逆位相で動くような細かい振動まで表現するには、大きいスーパーセルが必要。
  • スーパーセルを 2×2×2 → 3×3×3 と大きくすると、独立な変位構造は増えるが、その分だけ遠方の力の定数まで正確になる。
  • 結晶の対称性を使うと、独立に計算すべき変位は少数に減る（等価な変位は 1 つ計算すれば済む）。phonopy が自動で判定してくれる。

計算の流れ

SCF 計算が済んだ（構造最適化後の）ディレクトリを起点にする。以下は 2×2×2 スーパーセルの例。

1

元ディレクトリを用意して変位構造を生成

SCF を回したフォルダの中に作業用ディレクトリ（名前は任意、ここでは start）を作り、その中で phonopy を実行する。

mkdir start && cd start
# INCAR / POTCAR / KPOINTS / 最適化後の POSCAR をここに置いておく

phonopy -d --dim 2 2 2 -c POSCAR
#   2×2×2 スーパーセルに対する独立な変位構造を生成する
#   → POSCAR-001, POSCAR-002, … （対称性から必要な数だけ）
#   → SPOSCAR（変位なしのスーパーセル）, phonopy_disp.yaml も生成

-d が変位生成モード、--dim がスーパーセルの次元、-c が元となる単位胞ファイルの指定。生成された phonopy_disp.yaml はどの原子をどう動かしたかの記録なので、消さずに残しておく。

2

KPOINTS をスーパーセルに合わせる

セルが大きくなった分、逆空間は小さくなるので k メッシュは粗くてよい。単位胞での k メッシュをスーパーセルの倍率で割る（端数は切り上げ）。

vi KPOINTS
#   例：単位胞で 12×12×12 だった → 2×2×2 セルなら 6×6×6
#       割り切れないときは切り上げる（8×8×8 → 4×4×4 など）
3

各変位構造を VASP で計算

変位構造ごとにディレクトリを作り、POSCAR-00x を POSCAR として計算する。これを全変位構造ぶん繰り返す。

cp -r start/ 001
cd 001
cp POSCAR-001 POSCAR
qsub vasp.csh          # ← 力（force）を出す SCF 計算
cd ..
#   002, 003, … も同様に繰り返す
力の精度がそのままフォノンの精度になるので、この SCF は構造を動かさず（NSW=0, IBRION=-1）、EDIFF を厳しく（1E-8 程度）、PREC=Accurate・ADDGRID=.TRUE. にしておくとよい。vasprun.xml に力が書き出される。
4

力を集めて FORCE_SETS を作る

全計算が終わったら start ディレクトリに戻り、各 vasprun.xml から力を回収する。

cd start
phonopy -f ../{001..022}/vasprun.xml
#   番号の範囲は変位構造の数に合わせて変える
#   → FORCE_SETS が生成される（力の定数のもとになるデータ）

{001..022} は bash のブレース展開。変位構造が 22 個なら 022、10 個なら 010 のように末尾を合わせる。ここまでで力の定数の材料がそろう。

フォノンバンドを描く

高対称点をつないだ経路に沿って ω(q) を計算し、バンド図にする。設定は band.conf に書く。

band.conf の中身

DIM = 2 2 2
#   スーパーセルの次元（変位生成時の --dim と同じにする）

BAND = 0 0 0  0 0.5 0.5  0 0 0.5  0 0 0  0.5 0 0  0.5 0.5 0.5  0.5 0 0.5
#   経路上の高対称点（分率座標）を順につなぐ

BAND_LABELS = G Y S G Z T R
#   各点のラベル（Γ は G）

BAND_POINTS = 101
#   経路 1 本あたりの分割数（default 51）
phonopy -p band.conf
#   計算してその場でプロット

phonopy band.conf --eigenvectors
#   band.yaml に各モードの固有ベクトル（原子変位）まで書き出す
--eigenvectors を付けないと band.yaml に固有ベクトルが出力されない。あとで不安定モードに沿って原子を動かす（modulation）には固有ベクトルが必要なので、こちらで実行しておくのが安全。

画像として出力

phonopy-bandplot band.yaml -o band.png
#   band.yaml から直接プロット（gnuplot 用の生データも band.yaml にある）
バンド図の横軸の間隔は、実際のブリルアンゾーン内の経路長とは対応しない（phonopy の仕様で各セグメントを等間隔に並べる）。論文用に厳密な比率で描きたいときは、自分で経路長に応じて横軸を調整する必要がある。

不安定モードに沿って原子を動かす（modulation）

バンド図に虚の振動数（マイナス側のブランチ）が出たら、その不安定モードの固有ベクトルに沿って原子を変位させた構造を作れる。エネルギーが下がる方向＝相転移先の構造を探す第一歩になる。設定は modulation.conf に書く。

modulation.conf の中身

DIM = 3 3 1
#   作りたい変調構造のスーパーセル次元

Q-POINT = 0.0 0.0 0.0
#   不安定モードが現れたフォノンの q 点

MODULATION = 1 2 3 4
#   動かすモードの番号（band.yaml で確認したバンド index）

MODULATION_AMPLITUDES = 0.06 0.06 0.02 0.02
#   各モードへの変位の大きさ（振幅）

上の例では、mode 1, 2 は虚の振動数が大きく（不安定性が強い）、mode 3, 4 はそれほど強くなかったため、振幅を 0.06 / 0.06 / 0.02 / 0.02 と差をつけている。強く不安定なモードほど大きく動かす、という配分。

phonopy -p modulation.conf
#   → 指定モードに沿って変位させた構造ファイルが出力される

各モードに対応する「どの原子がどの向きにどれだけ動くか」の変位ベクトルは、先に --eigenvectors 付きで作った band.yaml に書かれている。これを見てモード番号と振幅を決める。

MODULATION 系タグの書式は phonopy のバージョンによって異なることがある（q 点・モード番号・振幅を 1 行にまとめて書く形式もある）。手元の phonopy のドキュメントで確認しておくと安心。
